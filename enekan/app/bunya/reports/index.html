報告と計画エネルギー管理士(熱)課目Ⅰ

課目Ⅰ エネルギー総合管理及び法規 ・ 5論点 ・ 問題 5問

指定された事業者が毎年国に出す「通知表」と「今後の計画」。
たとえると: 学校の通知表(実績)と、来年度の目標シート(計画)を毎年出す。
  1. 使用量が基準を超えたら届け出る → 国が指定する。
  2. 毎年、定期報告書(実績)と中長期計画書(これからの取組)を提出する。
  3. 国は判断基準に照らして指導・助言。取組が著しく不十分なら合理化計画の作成を指示 → 従わなければ公表・命令。
  4. 国は報告を求めたり、立入検査をしたりできる。
試験のねらい目: 提出物の期限と、指導・助言 → 指示 → 公表 → 命令 の順番。

論点(ひとことで要点)

届出・計画・報告の期限

使用量の届出と、毎年の定期報告・中長期計画にはそれぞれ提出期限がある。いつ・何を出すかをセットで覚える。

指導助言・合理化計画の指示と命令

国の対応は段階的に強くなる:指導・助言 → 合理化計画の指示 → 公表 → 命令。

非化石転換の中長期計画と勧告

非化石エネルギーへの転換も中長期計画を出す。取組が不十分だと国が勧告する。

定期報告の内容

毎年出す通知表。使用量、原単位の推移、設備の状況、取組の内容などを書く。

報告徴収と立入検査

国は必要に応じて報告を求めたり、工場に立ち入って検査したりできる。

課目Ⅰのほかの分野

目的と定義
省エネ法が「何のための法律か」と「何をエネルギーと呼ぶか」を決めている部分。
指定と原油換算
燃料・熱・電気の使用量を「原油何kL分か」にそろえ、多い事業者を国が指定する。
管理体制
指定されたら、会社と工場に「省エネの担当者」を置く決まり。
判断基準
国が示す「省エネの模範解答」。事業者はこれを基準に取り組む。
機械器具
家電や自動車など、売られる製品の省エネ性能を底上げする制度(トップランナー制度)。
エネルギー概論・単位
エネルギーの「量」と「質」を測るための共通のものさし。
エネルギー情勢・政策
日本と世界のエネルギー事情と、脱炭素に向けた政策。
電気の基礎
工場の電気のムダを数字で出すための計算道具。
