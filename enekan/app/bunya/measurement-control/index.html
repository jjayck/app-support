計測と制御エネルギー管理士(熱)課目Ⅳ

課目Ⅳ 熱利用設備及びその管理 ・ 23論点(うち計算 7) ・ 問題 72問

温度・圧力・流量を測り、目標とずれたら自動で調整するしくみ。
たとえると: シャワーの温度調整。手で温度を感じ(計測)、熱すぎたら水を足す(制御)。
  1. 測る:温度は熱電対・測温抵抗体、圧力は圧力計、流量は差圧式(流量は差圧の平方根に比例)など。
  2. 比べる:目標値と測った値の差(偏差)を出す。
  3. 動かす:調節計が P(比例)・I(積分)・D(微分)で操作量を決め、調節弁などを動かす。
  4. これを繰り返すのがフィードバック制御。外乱を先に測って動かすのがフィードフォワード。
試験のねらい目: 計測器の原理・特徴の語句と、PID の各動作の働き。

論点(ひとことで要点)

PID制御の各動作

P=ずれに比例して動かす、I=ずれの合計を見てずれを消す、D=ずれの変化の速さを見て先回りする。

練習問題

比例動作だけの制御では、目標値と制御量の間に A が残ることがある。これを取り除くのが B 動作である。偏差の C に応じた操作を加えるのが微分動作で、応答の行き過ぎを抑える効果がある。
A解答群
  1. アハンチング
  2. イむだ時間
  3. ウオフセット(定常偏差)
  4. エオーバーシュート
B解答群
  1. ア積分
  2. イオンオフ
  3. ウ比例
  4. エ微分
C解答群
  1. ア変化の速さ
  2. イ積算値
  3. ウ大きさ
  4. エ符号
答えと解説を見る
  • Aウ オフセット(定常偏差)
  • Bア 積分
  • Cア 変化の速さ
AP(比例):偏差に比例して操作。単独ではオフセットが残る。
BI(積分):偏差を時間で積算して操作し、オフセットを除く。効かせすぎると振動しやすい。
D(微分):偏差の変化速度に応じて先回りして操作し、行き過ぎを抑える。

カスケード・比率・フィードフォワード制御

カスケード=一方の調節計の出力を別の調節計の目標にする。比率=2つの流量の比を一定に保つ。フィードフォワード=外乱を先に測って動かす。

熱電対と差圧式流量計

熱電対=2種類の金属の接点の温度差で電圧が出る。差圧式=絞りの前後の圧力差から流量を出す(流量は差圧の平方根に比例)。

絶対圧・ゲージ圧と真空計

絶対圧=真空を0とした圧力。ゲージ圧=大気圧を0とした圧力。絶対圧 = ゲージ圧 + 大気圧。

調節弁の容量係数と流量特性

Cv値=弁の流しやすさ。開度と流量の関係(リニア・イコールパーセント等)が流量特性。

課目Ⅳのほかの分野

工業炉・熱設備材料
物を加熱する炉と、その壁をつくる材料。
タービン・発電
熱を回転の力(動力)に変え、発電する機械。
冷凍・空調
冷媒が「蒸発して熱を奪い、外で凝縮して熱を捨てる」を繰り返して、熱を低い所から高い所へ運ぶ。
ボイラ・蒸気
燃料の熱で水を蒸気に変え、工場の各所へ送って使い、戻すまでの一連の設備。
乾燥・蒸留
熱を使って水分を飛ばす(乾燥)、沸点の違いで液体を分ける(蒸留)、濃くする(蒸発濃縮)工程。
熱交換器
熱い流体から冷たい流体へ、混ぜずに熱だけを渡す装置。
ポンプ・送風機
流量を変えるとき、弁で絞るより回転数を下げるほうがはるかに省エネになる。
