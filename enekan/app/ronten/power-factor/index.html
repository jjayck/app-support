力率改善のコンデンサ容量と損失低減

課目Ⅰ電気の基礎計算

ひとことで言うと

コンデンサで無効電力を打ち消すと電流が減る。線路の損失は電流の2乗に比例するので大きく減る。

練習問題

空欄 A・B・C に入るものを答えてください。

線間電圧 6,600 V、消費電力 400 kW、力率 0.8 の三相負荷がある。負荷と並列にコンデンサを設置して力率を 0.98 に改善するのに必要なコンデンサ容量は A kvar である。このとき有効電力が変わらないとすると、線路の抵抗損失は改善前より B % 減少する。コンデンサは負荷の遅れの C を打ち消している。
A数値(3桁・□□□)kvar
B数値(2桁・□□)%
C解答群
  1. ア周波数
  2. イ無効電力
  3. ウ有効電力
  4. エ皮相電力
答えとやさしい解き方を見る
  • A219 kvar
  • B33 %
  • Cイ 無効電力

数値の答えは本番と同じ「桁ごとのマーク」です。桁が余るときは先頭に 0 を入れます。

何を聞かれている?
力率を良くするために並べて付けるコンデンサの大きさ(kvar)と、そのおかげで電線の損失が何 % 減るかを出す問題。

記号と単位

  • P … 消費電力(有効電力、kW)。仕事に使われる電力
  • cosφ(力率)… 流した電力のうち仕事に使われる割合。1 に近いほどむだがない
  • tanφ … 有効電力に対する無効電力の割合
  • Qc … コンデンサの容量(kvar)。打ち消せる無効電力の大きさ
  • φ₁・φ₂ … 改善前・改善後の力率角

解き方

1
無効電力は P × tanφ で表せる。改善前の無効電力から改善後の無効電力を引いた差が、コンデンサで打ち消すぶん。だから P に「tanφ の差」を掛ける。
コンデンサは進みの無効電力を出し、負荷の遅れの無効電力を打ち消す。
2
問題では cosφ しかわからないので、cosφ から tanφ を出す。1/cos²φ = 1 + tan²φ という関係を使うと、1/cos²φ から 1 を引いて √ をとれば tanφ になる。
必要容量 Qc = P(tanφ₁ − tanφ₂)
3
改善前と改善後の cosφ をそれぞれ前の行の式に入れて、tanφ₁ と tanφ₂ を出す。力率 1.0 なら tanφ は 0。
普通の電卓では tanφ = √(1/cos²φ − 1) で求める(1 ÷ cos を2回 → − 1 → √)。
4
出した tanφ の差に P を掛ければ、必要なコンデンサ容量(kvar)になる。
tanφ₁ = √(1/0.8² − 1) = 0.7500、tanφ₂ = √(1/0.98² − 1) = 0.2031
5
消費電力 P と電圧が同じなら、電流は力率に反比例する(力率が良いほど少ない電流ですむ)。電線の損失は電流の2乗に比例する。
Qc = 400 × (0.7500 − 0.2031) = 218.8 → 219 kvar。
6
だから損失の比は「改善前の力率 ÷ 改善後の力率」の2乗。この比は「改善後の損失は改善前の何倍か」なので、1 から引いて 100 を掛けると減った割合(%)になる。
線電流 I = P/(√3·V·cosφ) は力率に反比例し、損失は I² に比例する。

あわせて覚える

  • 損失比 = (cosφ₁/cosφ₂)² = (0.8/0.98)² = 0.6664 → 減少率 33.4 → 33 %。
つまずきやすいところ
損失の比をそのまま答えてしまい「減少率」にするのを忘れる(1 から引く)/電流の比を2乗し忘れる。

同じ分野の論点

ランプの総合効率(lm/W)と照明の省エネ
1Wあたり何ルーメンの光を出すか。LEDは総合効率が高いので、同じ明るさを少ない電力で出せる。
計算デマンド管理と残り時間の平均電力
電気の基本料金は30分平均電力の最大値で決まる。残り時間で使ってよい電力を計算して超えないようにする。
計算変圧器の負荷損と効率
鉄損は常に一定、負荷損(銅損)は負荷率の2乗。両者が等しいとき効率が最大になる。
計算誘導電動機の同期速度と滑り
回転磁界の速さが同期速度 120f/p。実際の回転子はそれより少し遅く、その遅れの割合が滑り。
計算電動機の軸動力・入力・線電流
軸から取り出す動力 ÷ 効率 = 電気の入力。入力から √3VIcosφ を使って電流を出す。
計算光束法による照明台数
必要な明るさ × 面積 = ランプの光束 × 台数 × 照明率 × 保守率。ここから台数を出す。
計算発電効率と燃料使用量
発電量 ÷ 発電効率 = 燃料の熱量。燃料の発熱量で割れば燃料の量になる。
計算点光源の照度と立体角・全光束
照度は光源からの距離の2乗に反比例する。全光束は光度に立体角を掛けて出す。
計算慣性モーメントと回転体の運動エネルギー
回転する物のエネルギーは ½Iω²。回転を止めるときに回生すればこのエネルギーを取り戻せる。
計算ファラデーの法則と電解の電力原単位
電気分解でできる量は流した電気量に比例する。そこから1kgつくるのに要る電力量を計算する。
