熱回路と電気回路の対応

課目Ⅰエネルギー概論・単位

ひとことで言うと

温度差=電圧、熱流=電流、熱抵抗=電気抵抗。直列の壁は抵抗の足し算で解ける。

練習問題

空欄 A・B・C・D に入るものを答えてください。

熱の流れは電気回路と対応させて考えられる。熱流は A に、温度差は B に、熱抵抗は電気抵抗に対応する。物体の温まりにくさを表す熱容量は C に対応する。熱抵抗を直列につなぐと、全体の熱抵抗は各熱抵抗の D になる。
A解答群
  1. ア電力
  2. イ電流
  3. ウ電荷
  4. エ電圧
B解答群
  1. ア抵抗
  2. イ電圧(電位差)
  3. ウ周波数
  4. エ電流
C解答群
  1. ア電流
  2. イ静電容量(コンデンサ)
  3. ウ電気抵抗
  4. エインダクタンス
D解答群
  1. ア積
  2. イ和
  3. ウ逆数の和の逆数
  4. エ平均
答えと解説を見る
  • Aイ 電流
  • Bイ 電圧(電位差)
  • Cイ 静電容量(コンデンサ)
  • Dイ 和
ABオームの法則 I = V/R ↔ 熱流 Q = ΔT/R(熱抵抗 R:平板 L/(λA)、熱伝達 1/(hA))。
D直列(多層壁・壁+両側の熱伝達)は R の和、並列(並んだ別の経路)は 1/R の和の逆数。
C熱容量 C = mc は電荷をためるコンデンサに対応し、熱抵抗 × 熱容量 = 時定数(温度が変化する速さの目安)。

同じ分野の論点

SI基本単位と組立単位
基本は m・kg・s・A・K・mol・cd の7つ。J(ジュール)や W(ワット)はこれらの組合せでできている。
エネルギー変換と回生・ヒートポンプ
ブレーキで捨てていたエネルギーを電気に戻すのが回生。ヒートポンプは電気で熱をくみ上げる。
蓄熱・蓄電の基礎
余っている時間にためて、足りない時間に使う。熱でためるか電気でためるかの違い。
風力の出力・粘性の温度依存・電気加熱
風力の出力は風速の3乗に比例。液体の粘性は温度が上がると下がり、気体は上がる。
電気の組立単位(C・V・Ω)
電荷 C = A·s、電圧 V = W/A、抵抗 Ω = V/A。基本単位までさかのぼって組み立てられる。
エネルギーの種類ごとのエクセルギー率
電気や仕事はほぼ全部が使えるエネルギー。熱は温度が低いほど使える割合(エクセルギー率)が小さい。
計算成績係数の一次エネルギー換算と比較
ヒートポンプのCOPは電気基準。発電の効率を掛けて一次エネルギー基準にすると、燃料ボイラと公平に比べられる。
計算熱のエクセルギーとエクセルギー損失
熱から取り出せる仕事の最大値は 熱量×(1−周囲温度/熱の温度)。温度差で熱が流れるだけでも失われる。
計算ウィーンの変位則と放射エネルギー
熱い物ほど短い波長の光を強く出す(最大の波長 × 絶対温度 = 一定)。
計算風力発電の出力と風速の3乗
風速が2倍になると出力は8倍。風が受ける面積にも比例する。
