含水率と蒸発水量

課目Ⅳ乾燥・蒸留計算

ひとことで言うと

乾量基準=乾いた物に対する水の割合、湿量基準=全体に対する水の割合。基準の違いに注意して蒸発量を出す。

練習問題

空欄 A・B・C に入るものを答えてください。

湿量基準の含水率 60 % の材料を 1,200 kg/h で乾燥機に入れ、含水率 8 %(湿量基準)まで乾燥させる。入口の材料の乾量基準の含水率は A kg/kg、蒸発させる水分量は B kg/h である。水の蒸発潜熱を 2400 kJ/kg とすると、蒸発に必要な熱量は C kW である。
A数値(3桁・□.□□)kg/kg
B数値(4桁・□□□□)kg/h
C数値(3桁・□□□)kW
答えとやさしい解き方を見る
  • A1.50 kg/kg
  • B0678 kg/h
  • C452 kW

数値の答えは本番と同じ「桁ごとのマーク」です。桁が余るときは先頭に 0 を入れます。

何を聞かれている?
乾燥機で材料の水分を飛ばすとき、含水率の言いかえ、蒸発させる水の量、そのための熱量を出す問題。

記号と単位

  • w(湿量基準の含水率)… 水を含んだ材料全体のうち、水が何割か
  • X(乾量基準の含水率)… 乾いた中身 1 kg に対して水が何 kg あるか
  • 乾き材料 … 材料から水を全部取り除いた中身。乾燥しても量は変わらない
  • 蒸発潜熱 … 水 1 kg を蒸発させるのに要る熱

解き方

1
湿量基準は「全体」で割り、乾量基準は「乾いた中身」で割る。全体を 1 とすると水が w、中身が (1 − w) なので、X = w ÷ (1 − w) で言いかえられる。
湿量基準 w = 水分/湿り材料、乾量基準 X = 水分/乾き材料。X = w/(1 − w) = 0.6/0.40 = 1.5000 → 1.50。
2
乾燥で減るのは水だけで、乾いた中身の量は変わらない。入口の量に (1 − 入口の含水率) を掛けて、中身の量を出す。
乾き材料は変わらない:1,200 × (1 − 0.6) = 480.0 kg/h
3
出口では中身が全体の (1 − 出口の含水率) を占めるので、中身 ÷ (1 − 出口の含水率) で出口の材料の量がわかる。入口との差が、飛んだ水の量。
出口の材料 = 480.0/(1 − 0.08) = 521.7 kg/h → 蒸発量 = 1,200 − 521.7 = 678.3 → 678 kg/h。
4
蒸発量(kg/h)× 蒸発潜熱(kJ/kg)で kJ/h。kW は 1秒あたり(kJ/s)なので 3600 で割る。
熱量 = 678.3 × 2400 / 3600 = 452.2 → 452 kW。
つまずきやすいところ
入口の量 × 含水率の差 で蒸発量を出してしまう(中身が変わらないことを使うのが正しい)/3600 で割り忘れる。

「乾燥・蒸留」のイメージ

熱を使って水分を飛ばす(乾燥)、沸点の違いで液体を分ける(蒸留)、濃くする(蒸発濃縮)工程。

乾燥・蒸留の要点と全論点を見る ›

同じ分野の論点

蒸留塔の還流比と気液平衡
塔の上から出た液の一部を戻す割合が還流比。多く戻すほど分離はよくなるが、熱がたくさん要る。
蒸発濃縮の沸点上昇と省エネ蒸発法
溶けている物があると沸点が上がる。蒸気を何度も使い回す(多重効用・再圧縮)と少ない熱で済む。
石炭・バイオマスのガス化反応
石炭などを酸素や水蒸気と反応させて、CO・H₂などの燃えるガスに変える。
乾燥特性曲線と含水率の区分
乾燥は 予熱 → 恒率(表面の水が一定の速さで蒸発) → 減率(中の水がゆっくり出てくる) の順に進む。
気液平衡・単蒸留・充てん塔と棚段塔
沸点の低い成分ほど蒸気側に多く移る。塔の中身は、充てん物を詰める型と棚(トレイ)を重ねる型がある。
乾燥機の受熱方式と乾燥の省エネ
熱い空気を当てる(対流)、熱い面に触れさせる(伝導)、赤外線などで温める(放射)の3つの受け取り方。
計算連続精留の物質収支と還流比
入った量 = 塔頂から出た量 + 塔底から出た量。成分ごとにも同じように成り立つ。
