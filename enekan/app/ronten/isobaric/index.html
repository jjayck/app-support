等圧変化の仕事・内部エネルギー・エントロピー

課目Ⅱ熱力学計算

ひとことで言うと

圧力一定で加熱すると、一部は膨張の仕事に使われ、残りが内部エネルギーの増加になる。

練習問題

空欄 A・B・C・D に入るものを答えてください。

質量 3.0 kg の空気を、圧力 200 kPa 一定のまま温度 800 K から 300 K まで冷却する。空気は理想気体とし、定圧比熱 cₚ = 1.005 kJ/(kg·K)、ガス定数 R = 0.287 kJ/(kg·K) とする。このとき空気から放出される熱量は A kJ、外部から空気にされる仕事は B kJ、内部エネルギーの減少量は C kJ、エントロピーの減少量は D kJ/K である。ただし ln(800/300) = 0.9808 とする。
A数値(4桁・□□□□)kJ
B数値(4桁・□□□□)kJ
C数値(4桁・□□□□)kJ
D数値(4桁・□.□□□)kJ/K
答えとやさしい解き方を見る
  • A1507 kJ
  • B0431 kJ
  • C1077 kJ
  • D2.957 kJ/K

数値の答えは本番と同じ「桁ごとのマーク」です。桁が余るときは先頭に 0 を入れます。

何を聞かれている?
圧力を一定にしたまま気体を冷やすときの、出ていく熱・される仕事・内部エネルギーの減り・エントロピーの減りを出す問題。

記号と単位

  • Q … 熱量、W … 仕事、ΔU … 内部エネルギーの変化(すべて kJ)
  • cₚ … 定圧比熱、cᵥ … 定容比熱、R … ガス定数
  • ΔT … 温度差(K)、ΔS … エントロピーの変化(kJ/K)
  • T1・T2 … 前と後の温度(K)

解き方

1
圧力一定のときの熱は「質量 × 定圧比熱 cₚ × 温度差」。温度差は K でも ℃ でも同じ数になる。
等圧変化:放熱量 Q = m·cₚ·ΔT = 3.0 × 1.005 × 500 = 1507.50 → 1507 kJ
2
圧力一定の仕事は p × 体積の変化。pV = mRT なので、これは m × R × 温度差 と同じになり、体積を求めなくてよい。冷やすと縮むので、気体は外から仕事をされる側になる。
仕事 W = p·ΔV = m·R·ΔT = 3.0 × 0.287 × 500 = 430.50 → 431 kJ(体積が縮むので外部からされる)
3
まず cᵥ = cₚ − R で定容比熱を出す。内部エネルギーの変化は、圧力一定でも定容でも「質量 × cᵥ × 温度差」で決まる。
cᵥ = cₚ − R = 0.718。内部エネルギー ΔU = m·cᵥ·ΔT = 3.0 × 0.718 × 500 = 1077.00 → 1077 kJ
4
確かめ算。出ていく熱は、内部エネルギーの減りと、外からされた仕事のぶんを合わせたもの(Q = ΔU + W)になっているはず。
(検算:Q = ΔU + W → 1077.00 + 430.50 = 1507.50)
5
圧力一定のエントロピー変化は「質量 × cₚ × ln(温度の比)」。減る量を聞かれているので、大きい温度 ÷ 小さい温度 の ln(問題文の値)を使う。
エントロピー ΔS = m·cₚ·ln(T1/T2) = 3.0 × 1.005 × 0.9808 = 2.95711 → 2.957 kJ/K

あわせて覚える

  • (ΔS = ∫dQ/T = m·cₚ∫dT/T を積分した形。等圧変化の熱量はエンタルピー変化 ΔH = m·cₚ·ΔT に等しい)
つまずきやすいところ
仕事に cₚ を使ってしまう(仕事は R)/内部エネルギーに cₚ を使ってしまう(内部エネルギーは cᵥ)。

「熱力学」のイメージ

熱と仕事がどう出入りするかを計算する分野。発電所も冷凍機もエンジンもこの考え方で動く。

熱力学の要点と全論点を見る ›

同じ分野の論点

ランキンサイクルの正味仕事と再熱・プランクの法則
タービンの仕事からポンプの仕事を引いたのが正味仕事。途中でもう一度加熱する(再熱)と出口の湿りが減る。
p-h 線図の線と冷媒の状態
縦が圧力、横がエンタルピー。山形の線の左が液、内側が湿り蒸気、右が過熱蒸気。冷凍サイクルを四角形で描ける。
計算ランキンサイクルの乾き度と熱効率
蒸気発電のモデル。タービンで膨張した後の蒸気の乾き度と、加熱量に対する仕事の割合を計算する。
計算湿り蒸気の比エンタルピーと乾き度
湿り蒸気は水と蒸気の混ざりもの。乾き度 x の割合で、飽和水と飽和蒸気の値を混ぜ合わせる。
計算絞り膨張(等エンタルピー)と乾き度
弁などで絞ると、圧力は下がるがエンタルピーは変わらない。そのため乾き度が変わる。
計算理想気体の状態方程式と体積
pV = mRT。圧力・体積・温度のうち2つが分かれば残りが出る。温度は必ずK。
計算定容加熱の加熱量とエントロピー変化
体積一定だと仕事をしないので、加えた熱はすべて内部エネルギー(温度上昇)になる。
計算ガス定数・比熱の関係と比熱比
定圧比熱 − 定容比熱 = ガス定数。比熱比 κ = 定圧比熱 / 定容比熱(空気は約1.4)。
計算水を飽和蒸気にする加熱量
水を沸点まで温める熱(顕熱)と、沸かして蒸気にする熱(潜熱)の合計。
計算蒸気表の読み取り(湿り蒸気)
圧力か温度から、飽和水(h')と飽和蒸気(h'')の値を表から読む。
計算蒸気表の直線補間
表にない中間の値は、前後の2行を直線でつないで比例配分で求める。
計算ディーゼルサイクルの温度・加熱量・熱効率
ディーゼルエンジンのモデル。圧縮した高温の空気に燃料を入れ、圧力一定で燃やす。
計算コンバインドサイクルの熱効率
ガスタービンで使った後の排熱で蒸気タービンも回す。2段で使うので全体の効率が上がる。
計算可逆断熱膨張の体積・温度・仕事
断熱膨張では内部エネルギーを減らして仕事をする。温度・体積は pV^κ = 一定の関係で決まる。
計算ピストンの力のつり合いと等圧加熱
ピストンにかかる力(圧力×面積と重さ)がつり合っていれば、加熱しても圧力は一定のまま。
計算カルノーサイクルの熱効率
熱機関の効率の上限。高温と低温の絶対温度だけで決まり、1 − T₂/T₁。
計算可逆断熱変化の温度
熱の出入りなしで圧縮すると温度が上がり、膨張すると下がる。pV^κ = 一定。
計算オットーサイクルの熱効率
ガソリンエンジンのモデル。圧縮比が大きいほど効率が上がる。
