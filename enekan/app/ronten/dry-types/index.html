乾燥機の受熱方式と乾燥の省エネ

課目Ⅳ乾燥・蒸留

ひとことで言うと

熱い空気を当てる(対流)、熱い面に触れさせる(伝導)、赤外線などで温める(放射)の3つの受け取り方。

練習問題

空欄 A・B・C・D・E に入るものを答えてください。

乾燥機を熱の受け方で分けると、熱風を材料に当てる A 式(箱形・バンド・回転・流動層・噴霧など)、加熱した面に材料を接触させる B 式(ドラム・真空など)、C による放射・内部加熱式がある。省エネには、乾燥の前に D で機械的に水分を減らすこと、乾燥機から出る熱風の一部を E して熱を回収することが有効である。
A解答群
  1. ア熱風受熱(対流)
  2. イ凍結
  3. ウ放射受熱
  4. エ伝導受熱
B解答群
  1. ア熱風受熱
  2. イ吸着
  3. ウ放射受熱
  4. エ伝導受熱
C解答群
  1. アX線
  2. イ赤外線・マイクロ波
  3. ウ紫外線
  4. エ超音波
D解答群
  1. ア加湿
  2. イ粉砕
  3. ウ冷却
  4. エろ過・圧搾・遠心脱水
E解答群
  1. ア冷却
  2. イ循環
  3. ウ加湿
  4. エ大気放出
答えと解説を見る
  • Aア 熱風受熱(対流)
  • Bエ 伝導受熱
  • Cイ 赤外線・マイクロ波
  • Dエ ろ過・圧搾・遠心脱水
  • Eイ 循環
A熱風受熱式:最も一般的。排気の熱損失が大きくなりやすい。
B伝導受熱式:熱風が少ないので排気損失が小さく熱効率が高い。真空にすれば低温で乾かせる。
Cマイクロ波:水分子を直接加熱する(内部加熱)。
DE機械的脱水は、蒸発で水を除くより必要なエネルギーがはるかに小さい。排気の循環は湿度が上がりすぎない範囲で行う。
定率乾燥期間の乾燥速度 R = h(t − tw)/r(熱風から受けた熱がすべて蒸発に使われる。tw は湿球温度、r は蒸発潜熱)。

「乾燥・蒸留」のイメージ

熱を使って水分を飛ばす(乾燥)、沸点の違いで液体を分ける(蒸留)、濃くする(蒸発濃縮)工程。

乾燥・蒸留の要点と全論点を見る ›

同じ分野の論点

蒸留塔の還流比と気液平衡
塔の上から出た液の一部を戻す割合が還流比。多く戻すほど分離はよくなるが、熱がたくさん要る。
蒸発濃縮の沸点上昇と省エネ蒸発法
溶けている物があると沸点が上がる。蒸気を何度も使い回す(多重効用・再圧縮)と少ない熱で済む。
石炭・バイオマスのガス化反応
石炭などを酸素や水蒸気と反応させて、CO・H₂などの燃えるガスに変える。
乾燥特性曲線と含水率の区分
乾燥は 予熱 → 恒率(表面の水が一定の速さで蒸発) → 減率(中の水がゆっくり出てくる) の順に進む。
気液平衡・単蒸留・充てん塔と棚段塔
沸点の低い成分ほど蒸気側に多く移る。塔の中身は、充てん物を詰める型と棚(トレイ)を重ねる型がある。
計算含水率と蒸発水量
乾量基準=乾いた物に対する水の割合、湿量基準=全体に対する水の割合。基準の違いに注意して蒸発量を出す。
計算連続精留の物質収支と還流比
入った量 = 塔頂から出た量 + 塔底から出た量。成分ごとにも同じように成り立つ。
