ポンプ・送風機の運転障害

課目Ⅱ流体工学

ひとことで言うと

キャビテーション=圧力が下がって泡ができる。サージング=小流量で圧力と流量が周期的に揺れる。

練習問題

空欄 A・B・C に入るものを答えてください。

ポンプや送風機を、揚程(圧力)曲線が右上がりになる小流量の範囲で運転すると、流量と圧力が周期的に大きく変動する A が起こりやすい。管路の弁を急に閉じると、圧力が急上昇して管や弁に衝撃を与える B が起こる。吸込み側の圧力が液の C より下がると、気泡ができて騒音・振動・羽根車の壊食を起こす。

  1. ア水撃作用
  2. イサージング

  4. エ旋回失速

答えと解説を見る
  • Aイ サージング
  • Bア 水撃作用(ウォーターハンマ)
  • Cエ 飽和蒸気圧
Aサージング:右上がりの特性の部分で、管路・タンクの容量と共に自励振動する。運転点を右下がりの範囲に移す、バイパスや放風で流量を確保する。
旋回失速:送風機や圧縮機の羽根で失速した領域が回転方向に伝わる現象。小流量で起こり、サージングの引き金になる。
B水撃作用:弁をゆっくり閉める、サージタンクを設ける。
Cキャビテーション:吸込み揚程・吸込み管の損失・液温を下げ、有効吸込みヘッド(NPSH)に余裕をとる。起こりやすさは吸込み比速度でも判断する。
吸込み側の静圧は、ポンプの位置が高いほど・吸込み流速(運動エネルギー)が大きいほど・吸込み管の損失が大きいほど下がる。

同じ分野の論点

ターボポンプの形式・比速度・特性
羽根車で水に勢いをつけるポンプ。比速度で遠心・斜流・軸流の向き不向きが分かる。
送風機の分類・無次元特性・斜流ポンプ
圧力の高さで、ファンとブロワに分かれる。羽根の形で特性が変わる。
計算管路損失とポンプの軸動力
ポンプは高さの差と管の損失の分だけ水を持ち上げる。軸動力 = ρgQH ÷ 効率。
計算ベンチュリ管・マノメータと粘性係数のレイノルズ数
管を細くした所の圧力低下を液柱で測ると流速・流量が分かる。
計算タンクからの流出と管の摩擦損失
水面の高さのエネルギーが、出口の速さと管の摩擦損失に分かれる。
計算相当直径と層流の管摩擦係数
円でない管は 4×断面積/濡れ縁長さ で直径に置き換える。層流なら管摩擦係数は 64/Re。
計算ブラジウスの式と乱流の摩擦損失
なめらかな管の乱流では、管摩擦係数をブラジウスの式(Reの1/4乗に反比例)で求める。
計算加圧タンクの小孔からの流出
タンク内の圧力と水位の両方が、小さな穴から噴き出す速さになる(流速 = √(2×押す力のヘッド×g))。
計算高さの違う2点のベルヌーイの式
高い所へ上がった分、圧力か速度のエネルギーが減る。位置のエネルギーも含めて合計を一定にする。
計算連続の式とベルヌーイの定理
流量は管のどこでも同じ(連続の式)。流れのエネルギー(圧力+速度+高さ)の合計も一定(ベルヌーイ)。
計算レイノルズ数と流れの判定
流れの勢いと粘りの比。円管では約2300より小さいと層流、大きいと乱流。
