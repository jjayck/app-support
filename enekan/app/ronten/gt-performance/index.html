ガスタービンの性能と大気条件・最適圧力比

課目Ⅳタービン・発電

ひとことで言うと

気温が高いと空気が薄くなり、出力が下がる。効率が最大になる圧力比と、出力が最大になる圧力比は違う。

練習問題

空欄 A・B・C・D に入るものを答えてください。

ガスタービンの出力は、大気温度が低いほど、また大気圧が A ほど大きい。タービン入口温度と圧縮機入口温度の比(最高最低温度比)が大きいほど、比出力(空気 1 kg あたりの出力)は B。比出力と熱効率には、それぞれ最大になる C があり、比出力が最大になる値は熱効率が最大になる値より D。
A解答群
  1. ア関係しない
  2. イ低い
  3. ウ高い
B解答群
  1. ア小さい
  2. イ大きい
  3. ウ変わらない
C解答群
  1. ア最適圧力比
  2. イ最適締切比
  3. ウ最適還流比
  4. エ最適空気比
D解答群
  1. ア小さい
  2. イ等しい
  3. ウ大きい
答えと解説を見る
  • Aウ 高い
  • Bイ 大きい
  • Cア 最適圧力比
  • Dア 小さい
D比出力が最大になる圧力比は、熱効率が最大になる圧力比より小さい。
A大気温度が低い・大気圧が高い → 空気の密度が大きく、同じ体積流量で質量流量が増えて出力が増える(夏は出力が落ちる。吸気冷却で対策)。
C実際のサイクル(圧縮機・タービンの効率 < 1)では、圧力比を上げすぎると圧縮仕事が増えて比出力も効率も下がるので、それぞれ最適圧力比がある。
B最高温度を上げると比出力・熱効率とも上がり、最適圧力比も大きくなる。理想ブレイトンでは効率は圧力比だけで決まる。

同じ分野の論点

ランキンサイクルの改良
蒸気の圧力・温度を上げる、復水器の圧力を下げる、再熱・再生(抽気で給水を加熱)で効率を上げる。
ガスタービンとコンバインドサイクル
空気を圧縮し、燃料を燃やした高温ガスで回す。排熱で蒸気をつくれば蒸気タービンも回せる。
往復動内燃機関の作動とコージェネ
ピストンを動かすエンジン(ガソリン・ディーゼル・ガスエンジン)。発電と同時に排熱を使うのがコージェネ。
蒸気タービンの段落・変圧運転とガスタービン燃焼器
タービンは羽根の段を重ねて少しずつ膨張させる。変圧運転=負荷に合わせてボイラの圧力を変える運転。
危険速度・ガスタービンの出力向上・形式
危険速度=回転軸が共振して大きく振れる回転数。ガスタービンは吸い込む空気を冷やすと出力が上がる。
ガスタービンの軸構成と圧縮機のサージング対策
一軸式は圧縮機とタービンが1本の軸、二軸式は分かれている。圧縮機はサージングを防ぐため、抽気や静翼の角度で調整する。
ガスタービン燃焼器の空気配分と翼の冷却
空気は燃焼用・希釈(温度を下げる)用・冷却用に分けて使う。高温の羽根は内側から空気で冷やす。
蒸気タービンの経年劣化と高温高圧化
長く使うと、羽根の汚れ・すきまの広がり・浸食で効率が落ちる。高温高圧化すれば効率が上がる。
計算蒸気タービンの内部効率と発電端出力
内部効率=実際の仕事 ÷ 理想(等エントロピー)の仕事。そこに機械効率・発電機効率を掛けて出力を出す。
ガスエンジンの熱勘定と排熱回収
エンジンの燃料の熱は、軸出力・排ガス・冷却水におおよそ分かれる。排ガスと冷却水の熱を回収するのがコージェネ。
