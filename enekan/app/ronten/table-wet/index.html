蒸気表の読み取り(湿り蒸気)

課目Ⅱ熱力学計算

ひとことで言うと

圧力か温度から、飽和水(h')と飽和蒸気(h'')の値を表から読む。

練習問題

空欄 A・B・C に入るものを答えてください。

表の飽和蒸気表を用いる。圧力 0.5 MPa における蒸発熱(蒸発潜熱)は A kJ/kg である。同じ圧力で乾き度 0.96 の湿り蒸気の比エンタルピーは B kJ/kg、比エントロピーは C kJ/(kg·K) である。

何を聞かれている?
飽和蒸気表から値を読み取り、蒸発熱と、湿り蒸気の比エンタルピー・比エントロピーを出す問題。

記号と単位

  • h′・s′ … 飽和水(全部が水)の比エンタルピー・比エントロピー
  • h″・s″ … 乾き飽和蒸気(全部が蒸気)の値
  • r … 蒸発熱(蒸発潜熱)、x … 乾き度(蒸気の割合)

解き方

1
表で問題の圧力の行を探し、h′・h″・s′・s″ の4つを書き出す。
表の 0.5 MPa の行を読む:h′ = 640.2、h″ = 2748.1、s′ = 1.8606、s″ = 6.8206。
2
蒸発熱は、水 1 kg を同じ温度で全部蒸気にする熱なので h″ − h′。
蒸発熱 r = h″ − h′ = 2748.1 − 640.2 = 2107.9 → 2108 kJ/kg。
3
湿り蒸気の熱は、全部水のときの h′ に、蒸気になった割合 x のぶんだけ蒸発熱を足す。
h = h′ + x·r = 640.2 + 0.96 × 2107.9 = 2663.8 → 2664 kJ/kg。
4
エントロピーも同じ考え方。s′ に、x × (s″ − s′) を足す。
s = s′ + x(s″ − s′) = 1.8606 + 0.96 × (6.8206 − 1.8606) = 6.6222 → 6.62。

あわせて覚える

  • 表を読むときは、まず単位と「′ が飽和水・″ が乾き飽和蒸気」を確かめる。
つまずきやすいところ
h′ と h″(飽和水と蒸気)の列を取りちがえる/となりの圧力の行を読んでしまう。

「熱力学」のイメージ

熱と仕事がどう出入りするかを計算する分野。発電所も冷凍機もエンジンもこの考え方で動く。

熱力学の要点と全論点を見る ›

同じ分野の論点

ランキンサイクルの正味仕事と再熱・プランクの法則
タービンの仕事からポンプの仕事を引いたのが正味仕事。途中でもう一度加熱する(再熱)と出口の湿りが減る。
p-h 線図の線と冷媒の状態
縦が圧力、横がエンタルピー。山形の線の左が液、内側が湿り蒸気、右が過熱蒸気。冷凍サイクルを四角形で描ける。
計算ランキンサイクルの乾き度と熱効率
蒸気発電のモデル。タービンで膨張した後の蒸気の乾き度と、加熱量に対する仕事の割合を計算する。
計算湿り蒸気の比エンタルピーと乾き度
湿り蒸気は水と蒸気の混ざりもの。乾き度 x の割合で、飽和水と飽和蒸気の値を混ぜ合わせる。
計算絞り膨張(等エンタルピー)と乾き度
弁などで絞ると、圧力は下がるがエンタルピーは変わらない。そのため乾き度が変わる。
計算理想気体の状態方程式と体積
pV = mRT。圧力・体積・温度のうち2つが分かれば残りが出る。温度は必ずK。
計算等圧変化の仕事・内部エネルギー・エントロピー
圧力一定で加熱すると、一部は膨張の仕事に使われ、残りが内部エネルギーの増加になる。
計算定容加熱の加熱量とエントロピー変化
体積一定だと仕事をしないので、加えた熱はすべて内部エネルギー(温度上昇)になる。
計算ガス定数・比熱の関係と比熱比
定圧比熱 − 定容比熱 = ガス定数。比熱比 κ = 定圧比熱 / 定容比熱(空気は約1.4)。
計算水を飽和蒸気にする加熱量
水を沸点まで温める熱(顕熱)と、沸かして蒸気にする熱(潜熱)の合計。
計算蒸気表の直線補間
表にない中間の値は、前後の2行を直線でつないで比例配分で求める。
計算ディーゼルサイクルの温度・加熱量・熱効率
ディーゼルエンジンのモデル。圧縮した高温の空気に燃料を入れ、圧力一定で燃やす。
計算コンバインドサイクルの熱効率
ガスタービンで使った後の排熱で蒸気タービンも回す。2段で使うので全体の効率が上がる。
計算可逆断熱膨張の体積・温度・仕事
断熱膨張では内部エネルギーを減らして仕事をする。温度・体積は pV^κ = 一定の関係で決まる。
計算ピストンの力のつり合いと等圧加熱
ピストンにかかる力(圧力×面積と重さ)がつり合っていれば、加熱しても圧力は一定のまま。
計算カルノーサイクルの熱効率
熱機関の効率の上限。高温と低温の絶対温度だけで決まり、1 − T₂/T₁。
計算可逆断熱変化の温度
熱の出入りなしで圧縮すると温度が上がり、膨張すると下がる。pV^κ = 一定。
計算オットーサイクルの熱効率
ガソリンエンジンのモデル。圧縮比が大きいほど効率が上がる。
