課目Ⅰ機械器具

ひとことで言うと

今いちばん省エネな製品を基準にし、目標年度までにメーカーの出荷品全体でその水準を達成させる制度。

練習問題

空欄 A・B・C・D に入るものを答えてください。

我が国において A 使用され、使用に際し相当量のエネルギーを消費する機械器具などを特定エネルギー消費機器等として、経済産業大臣は製造事業者等の判断の基準を定める。この基準は、そのうちエネルギー消費性能等が B ものの性能や、技術開発の将来の見通しを勘案して定める。生産量等が一定以上の事業者の性能向上が不十分なとき、大臣は C し、従わなければ公表、さらに命令できる。また機器のエネルギー消費効率の D の方法も定めて告示する。
A解答群
  1. ア長期間
  2. イ海外で
  3. ウ業務用に
  4. エ大量に
B解答群
  1. ア平均的な
  2. イ最も普及している
  3. ウ最も優れている
  4. エ最も安価な
C解答群
  1. ア命令
  2. イ指示
  3. ウ勧告
  4. エ助言
D解答群
  1. ア登録
  2. イ検査
  3. ウ表示
  4. エ輸出
答えと解説を見る
  • Aエ 大量に
  • Bウ 最も優れている
  • Cウ 勧告
  • Dウ 表示
A対象は、国内で大量に使われ、使うときに相当量のエネルギーを消費する機械器具(だから効率を上げる効果が大きい)。
法149条:特定エネルギー消費機器(自動車・エアコン・照明など)と特定関係機器(エネルギー消費機器と一緒に使われ、その消費量に影響する機器)。
B判断基準は「現在商品化されている製品のうち最も優れているもの」を基準にする → トップランナー方式。
CD法150条:勧告 → 公表 → 命令。法151条:エネルギー消費効率などの表示事項を告示。
建築材料(断熱材・窓など)は法154条以降で同様の仕組み。
