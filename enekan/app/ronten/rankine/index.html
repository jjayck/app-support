ランキンサイクルの乾き度と熱効率

課目Ⅱ熱力学計算

ひとことで言うと

蒸気発電のモデル。タービンで膨張した後の蒸気の乾き度と、加熱量に対する仕事の割合を計算する。

練習問題

空欄 A・B・C に入るものを答えてください。

ボイラで 5.0 MPa・500 ℃ の過熱蒸気(比エンタルピー 3434.5 kJ/kg、比エントロピー 6.9778 kJ/(kg·K))をつくり、タービンで復水器圧力 0.01 MPa まで等エントロピー膨張させるランキンサイクルがある。0.01 MPa の飽和水と乾き飽和蒸気の比エンタルピーは 191.8・2583.9 kJ/kg、比エントロピーは 0.6492・8.1489 kJ/(kg·K) である。タービン出口の乾き度は A、比エンタルピーは B kJ/kg であり、給水ポンプの仕事を無視すると理論熱効率は C % となる。
A数値(4桁・□.□□□)
B数値(4桁・□□□□)kJ/kg
C数値(3桁・□□.□)%
答えとやさしい解き方を見る
  • A0.844
  • B2210 kJ/kg
  • C37.8 %

数値の答えは本番と同じ「桁ごとのマーク」です。桁が余るときは先頭に 0 を入れます。

何を聞かれている?
蒸気でタービンを回す基本の発電サイクル(ランキンサイクル)で、タービン出口の蒸気の乾き度と熱、そして入れた熱の何 % が仕事になるか(熱効率)を出す問題。

記号と単位

  • h₁・s₁ … ボイラを出てタービンに入る蒸気の比エンタルピー(1 kg の熱)と比エントロピー
  • h₂・s₂ … タービンを出た蒸気の比エンタルピーと比エントロピー
  • h′・s′ … 復水器の圧力での飽和水(全部が水)の値
  • h″・s″ … 同じ圧力での乾き飽和蒸気(全部が蒸気)の値
  • x₂(乾き度)… タービン出口の蒸気の割合
  • η … 熱効率(入れた熱のうち仕事になった割合)

解き方

1
理想のタービンでは比エントロピーが変わらない(s₂ = s₁)。出口の s が「水の s′ と蒸気の s″ の間のどこにあるか」を割合で出すと、それが乾き度になる。(s₁ − s′) を (s″ − s′) で割る。
等エントロピー膨張なので s₂ = s₁。乾き度 x₂ = (s₁ − s')/(s'' − s') = (6.9778 − 0.6492)/(8.1489 − 0.6492) = 0.8438 → 0.844。
2
乾き度がわかれば熱も同じ形で出せる。全部水のときの h′ に、蒸気になった割合 x₂ のぶんだけ蒸発熱 (h″ − h′) を足す。x₂ は丸める前の値を使う。
h₂ = h' + x₂(h'' − h') = 191.8 + 0.8438 × (2583.9 − 191.8) = 2210.4 → 2210 kJ/kg。
3
タービンで取り出せる仕事は、入る蒸気と出る蒸気の熱の差 h₁ − h₂。ボイラで入れる熱は、給水(復水器から戻った飽和水 h′)を h₁ の蒸気にするぶんなので h₁ − h′。
タービン仕事 = h₁ − h₂ = 1224.1、ボイラの加熱量 = h₁ − h' = 3242.7(給水は復水器出口の飽和水)
4
熱効率 = 取り出した仕事 ÷ ボイラで入れた熱。% にするため 100 を掛ける。
η = 1224.1/3242.7 = 0.3775 → 37.8 %。
つまずきやすいところ
ボイラの加熱量を h₁ − h₂ にしてしまう(それはタービン仕事)/乾き度の割り算で分母を s″ だけにしてしまう。

「熱力学」のイメージ

熱と仕事がどう出入りするかを計算する分野。発電所も冷凍機もエンジンもこの考え方で動く。

同じ分野の論点

ランキンサイクルの正味仕事と再熱・プランクの法則
タービンの仕事からポンプの仕事を引いたのが正味仕事。途中でもう一度加熱する(再熱)と出口の湿りが減る。
p-h 線図の線と冷媒の状態
縦が圧力、横がエンタルピー。山形の線の左が液、内側が湿り蒸気、右が過熱蒸気。冷凍サイクルを四角形で描ける。
計算湿り蒸気の比エンタルピーと乾き度
湿り蒸気は水と蒸気の混ざりもの。乾き度 x の割合で、飽和水と飽和蒸気の値を混ぜ合わせる。
計算絞り膨張(等エンタルピー)と乾き度
弁などで絞ると、圧力は下がるがエンタルピーは変わらない。そのため乾き度が変わる。
計算理想気体の状態方程式と体積
pV = mRT。圧力・体積・温度のうち2つが分かれば残りが出る。温度は必ずK。
計算等圧変化の仕事・内部エネルギー・エントロピー
圧力一定で加熱すると、一部は膨張の仕事に使われ、残りが内部エネルギーの増加になる。
計算定容加熱の加熱量とエントロピー変化
体積一定だと仕事をしないので、加えた熱はすべて内部エネルギー(温度上昇)になる。
計算ガス定数・比熱の関係と比熱比
定圧比熱 − 定容比熱 = ガス定数。比熱比 κ = 定圧比熱 / 定容比熱(空気は約1.4)。
計算水を飽和蒸気にする加熱量
水を沸点まで温める熱(顕熱)と、沸かして蒸気にする熱(潜熱)の合計。
計算蒸気表の読み取り(湿り蒸気)
圧力か温度から、飽和水(h')と飽和蒸気(h'')の値を表から読む。
計算蒸気表の直線補間
表にない中間の値は、前後の2行を直線でつないで比例配分で求める。
計算ディーゼルサイクルの温度・加熱量・熱効率
ディーゼルエンジンのモデル。圧縮した高温の空気に燃料を入れ、圧力一定で燃やす。
計算コンバインドサイクルの熱効率
ガスタービンで使った後の排熱で蒸気タービンも回す。2段で使うので全体の効率が上がる。
計算可逆断熱膨張の体積・温度・仕事
断熱膨張では内部エネルギーを減らして仕事をする。温度・体積は pV^κ = 一定の関係で決まる。
計算ピストンの力のつり合いと等圧加熱
ピストンにかかる力(圧力×面積と重さ)がつり合っていれば、加熱しても圧力は一定のまま。
計算カルノーサイクルの熱効率
熱機関の効率の上限。高温と低温の絶対温度だけで決まり、1 − T₂/T₁。
計算可逆断熱変化の温度
熱の出入りなしで圧縮すると温度が上がり、膨張すると下がる。pV^κ = 一定。
計算オットーサイクルの熱効率
ガソリンエンジンのモデル。圧縮比が大きいほど効率が上がる。
