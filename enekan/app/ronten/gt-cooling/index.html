ガスタービン燃焼器の空気配分と翼の冷却

課目Ⅳタービン・発電

ひとことで言うと

空気は燃焼用・希釈(温度を下げる)用・冷却用に分けて使う。高温の羽根は内側から空気で冷やす。

練習問題

空欄 A・B・C・D・E に入るものを答えてください。

ガスタービンの燃焼器では、燃焼用の一次空気で燃料を燃やしたあと、残りの空気(希釈空気)を混ぜて、燃焼ガスを A の入口で許される温度まで下げる。燃焼器のライナーは、内面に沿って空気を流して B を得る。動翼は高温に加えて回転による大きな C を受ける。翼の内部には圧縮機から抜き出した D を流して冷やし、翼面の小穴から吹き出して表面を空気の膜で覆う方法を E 冷却という。
A解答群
  1. ア煙突
  2. イ圧縮機
  3. ウタービンノズル(第1段静翼)
  4. エ排熱回収ボイラ
B解答群
  1. ア燃焼促進
  2. イ冷却効果
  3. ウ脱硝
  4. エ騒音低減
C解答群
  1. ア浮力
  2. イ水圧
  3. ウ遠心力
  4. エ表面張力
D解答群
  1. ア燃料
  2. イ冷却水
  3. ウ空気
  4. エ潤滑油
E解答群
  1. ア蒸発
  2. イ水冷
  3. ウ噴霧
  4. エフィルム
答えと解説を見る
  • Aウ タービンノズル(第1段静翼)
  • Bイ 冷却効果
  • Cウ 遠心力
  • Dウ 空気
  • Eエ フィルム
D燃焼器:一次空気で安定燃焼 → 二次(希釈)空気で温度を下げ、温度分布を均一にしてタービンへ。全空気の多くは冷却・希釈に使われる。
BEライナー:内面に空気膜を流して(フィルム冷却)高温ガスから守る。
C動翼:高温+遠心力でクリープが問題。翼の冷却は内部対流冷却・インピンジメント冷却・フィルム冷却を組み合わせ、表面には遮熱コーティング。
大形の発電用では、空気の代わりに蒸気で冷やす方式もある。

同じ分野の論点

ランキンサイクルの改良
蒸気の圧力・温度を上げる、復水器の圧力を下げる、再熱・再生(抽気で給水を加熱)で効率を上げる。
ガスタービンとコンバインドサイクル
空気を圧縮し、燃料を燃やした高温ガスで回す。排熱で蒸気をつくれば蒸気タービンも回せる。
往復動内燃機関の作動とコージェネ
ピストンを動かすエンジン(ガソリン・ディーゼル・ガスエンジン)。発電と同時に排熱を使うのがコージェネ。
蒸気タービンの段落・変圧運転とガスタービン燃焼器
タービンは羽根の段を重ねて少しずつ膨張させる。変圧運転=負荷に合わせてボイラの圧力を変える運転。
危険速度・ガスタービンの出力向上・形式
危険速度=回転軸が共振して大きく振れる回転数。ガスタービンは吸い込む空気を冷やすと出力が上がる。
ガスタービンの軸構成と圧縮機のサージング対策
一軸式は圧縮機とタービンが1本の軸、二軸式は分かれている。圧縮機はサージングを防ぐため、抽気や静翼の角度で調整する。
蒸気タービンの経年劣化と高温高圧化
長く使うと、羽根の汚れ・すきまの広がり・浸食で効率が落ちる。高温高圧化すれば効率が上がる。
ガスタービンの性能と大気条件・最適圧力比
気温が高いと空気が薄くなり、出力が下がる。効率が最大になる圧力比と、出力が最大になる圧力比は違う。
計算蒸気タービンの内部効率と発電端出力
内部効率=実際の仕事 ÷ 理想(等エントロピー)の仕事。そこに機械効率・発電機効率を掛けて出力を出す。
ガスエンジンの熱勘定と排熱回収
エンジンの燃料の熱は、軸出力・排ガス・冷却水におおよそ分かれる。排ガスと冷却水の熱を回収するのがコージェネ。
