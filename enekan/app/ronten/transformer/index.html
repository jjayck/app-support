変圧器の負荷損と効率

課目Ⅰ電気の基礎計算

ひとことで言うと

鉄損は常に一定、負荷損(銅損)は負荷率の2乗。両者が等しいとき効率が最大になる。

練習問題

空欄 A・B・C に入るものを答えてください。

定格容量 300 kV·A の変圧器の無負荷損は 1.5 kW、定格負荷時の負荷損は 5.0 kW である。この変圧器を負荷率 50 %、力率 0.95 で運転するときの全損失は A kW、効率は B % である。また、効率が最大になる負荷率は C % である。
A数値(4桁・□□.□□)kW
B数値(4桁・□□.□□)%
C数値(3桁・□□.□)%
答えとやさしい解き方を見る
  • A02.75 kW
  • B98.11 %
  • C54.8 %

数値の答えは本番と同じ「桁ごとのマーク」です。桁が余るときは先頭に 0 を入れます。

何を聞かれている?
変圧器を定格より軽い負荷で使うときの損失と効率、そして効率がいちばん高くなる負荷率を出す問題。

記号と単位

  • kV·A … 変圧器の容量(皮相電力)。力率を掛けると kW になる
  • 無負荷損(鉄損)… 電気を流していなくても出る損失。いつも一定
  • 負荷損(銅損)… 巻線に電流が流れて出る損失。定格のときの値が与えられる
  • 負荷率 a … 定格の何割で使っているか

解き方

1
損失は2種類。無負荷損は負荷に関係なく一定。負荷損は電流の2乗に比例するので、負荷率の2乗に比例する。
無負荷損(鉄損)は負荷に関係なく一定、負荷損(銅損)は負荷率の2乗に比例する。
2
全損失 = 無負荷損 + 負荷率² × 定格の負荷損。負荷率は % を小数に直して2乗する。
全損失 = 1.5 + 0.5² × 5.0 = 2.7500 → 2.75 kW
3
出力(kW)= 容量 × 負荷率 × 力率。効率 = 出力 ÷(出力 + 損失)。入力は出力に損失を足したもの。
出力 = 300 × 0.5 × 0.95 = 142.5 kW、効率 = 142.5/(142.5 + 2.7500) = 98.107 → 98.11 %
4
効率がいちばん高くなるのは、無負荷損と負荷損が等しくなるとき。負荷率² × 負荷損 = 無負荷損 とおいて、負荷率について解く(割り算して √)。
効率最大は 無負荷損 = 負荷損 のとき:a² × 5.0 = 1.5 → a = √(1.5/5.0) = 54.77 → 54.8 %
つまずきやすいところ
負荷損に負荷率を2乗せずに掛ける/効率の分母を出力だけにしてしまう(損失を足す)。

同じ分野の論点

ランプの総合効率(lm/W)と照明の省エネ
1Wあたり何ルーメンの光を出すか。LEDは総合効率が高いので、同じ明るさを少ない電力で出せる。
計算力率改善のコンデンサ容量と損失低減
コンデンサで無効電力を打ち消すと電流が減る。線路の損失は電流の2乗に比例するので大きく減る。
計算デマンド管理と残り時間の平均電力
電気の基本料金は30分平均電力の最大値で決まる。残り時間で使ってよい電力を計算して超えないようにする。
計算誘導電動機の同期速度と滑り
回転磁界の速さが同期速度 120f/p。実際の回転子はそれより少し遅く、その遅れの割合が滑り。
計算電動機の軸動力・入力・線電流
軸から取り出す動力 ÷ 効率 = 電気の入力。入力から √3VIcosφ を使って電流を出す。
計算光束法による照明台数
必要な明るさ × 面積 = ランプの光束 × 台数 × 照明率 × 保守率。ここから台数を出す。
計算発電効率と燃料使用量
発電量 ÷ 発電効率 = 燃料の熱量。燃料の発熱量で割れば燃料の量になる。
計算点光源の照度と立体角・全光束
照度は光源からの距離の2乗に反比例する。全光束は光度に立体角を掛けて出す。
計算慣性モーメントと回転体の運動エネルギー
回転する物のエネルギーは ½Iω²。回転を止めるときに回生すればこのエネルギーを取り戻せる。
計算ファラデーの法則と電解の電力原単位
電気分解でできる量は流した電気量に比例する。そこから1kgつくるのに要る電力量を計算する。
