風力の出力・粘性の温度依存・電気加熱

課目Ⅰエネルギー概論・単位

ひとことで言うと

風力の出力は風速の3乗に比例。液体の粘性は温度が上がると下がり、気体は上がる。

練習問題

空欄 A・B・C に入るものを答えてください。

風車が受ける風のエネルギーは、風速の A 乗に比例する。気体の粘性係数は温度が上がると B。電磁誘導で被加熱物に渦電流を流し、そのジュール熱で加熱する方式を C 加熱という。

  1. ア2
  2. イ1
  3. ウ3
  4. エ4
B解答群
  1. ア小さくなる
  2. イ大きくなる
  3. ウ変わらない
C解答群
  1. ア誘導
  2. イ抵抗
  3. ウアーク
  4. エ誘電
答えと解説を見る
  • Aウ 3
  • Bイ 大きくなる
  • Cア 誘導
A風力:単位時間に通過する空気の運動エネルギー P = ½ρAv³(A:受風面積)。風速が 2 倍なら 8 倍。
粘性係数:気体は温度が上がると大きくなり(分子運動が活発になり運動量の交換が増える)、液体は小さくなる。
C電気加熱:誘導加熱(導体の渦電流のジュール熱)、誘電加熱(絶縁物の誘電損、電子レンジ)、抵抗加熱、アーク加熱、赤外線加熱。

同じ分野の論点

SI基本単位と組立単位
基本は m・kg・s・A・K・mol・cd の7つ。J(ジュール)や W(ワット)はこれらの組合せでできている。
エネルギー変換と回生・ヒートポンプ
ブレーキで捨てていたエネルギーを電気に戻すのが回生。ヒートポンプは電気で熱をくみ上げる。
蓄熱・蓄電の基礎
余っている時間にためて、足りない時間に使う。熱でためるか電気でためるかの違い。
熱回路と電気回路の対応
温度差=電圧、熱流=電流、熱抵抗=電気抵抗。直列の壁は抵抗の足し算で解ける。
電気の組立単位(C・V・Ω)
電荷 C = A·s、電圧 V = W/A、抵抗 Ω = V/A。基本単位までさかのぼって組み立てられる。
エネルギーの種類ごとのエクセルギー率
電気や仕事はほぼ全部が使えるエネルギー。熱は温度が低いほど使える割合(エクセルギー率)が小さい。
計算成績係数の一次エネルギー換算と比較
ヒートポンプのCOPは電気基準。発電の効率を掛けて一次エネルギー基準にすると、燃料ボイラと公平に比べられる。
計算熱のエクセルギーとエクセルギー損失
熱から取り出せる仕事の最大値は 熱量×(1−周囲温度/熱の温度)。温度差で熱が流れるだけでも失われる。
計算ウィーンの変位則と放射エネルギー
熱い物ほど短い波長の光を強く出す(最大の波長 × 絶対温度 = 一定)。
計算風力発電の出力と風速の3乗
風速が2倍になると出力は8倍。風が受ける面積にも比例する。
