ガス定数・比熱の関係と比熱比

課目Ⅱ熱力学計算

ひとことで言うと

定圧比熱 − 定容比熱 = ガス定数。比熱比 κ = 定圧比熱 / 定容比熱(空気は約1.4)。

練習問題

空欄 A・B・C・D に入るものを答えてください。

酸素(モル質量 32.0 g/mol)を理想気体とみなす。一般ガス定数を 8.314 J/(mol·K) とすると、酸素のガス定数は A kJ/(kg·K) である。定圧比熱が 0.918 kJ/(kg·K) のとき、定容比熱は B kJ/(kg·K)、比熱比は C となる。一般に、常温付近で比熱比が最も大きいのは D である。

何を聞かれている?
気体のモル質量からその気体のガス定数を出し、定圧比熱から定容比熱と比熱比を求める問題。

記号と単位

  • R₀ … 一般ガス定数(どの気体でも同じ 8.314 J/(mol·K))
  • M … モル質量(g/mol)。1 mol の重さ
  • R … その気体のガス定数(kJ/(kg·K))
  • cₚ・cᵥ … 定圧比熱・定容比熱、κ … 比熱比(cₚ/cᵥ)

解き方

1
1 mol あたりの R₀ を、1 mol の重さ M で割ると、1 kg あたりのガス定数 R になる。J ÷ g と kJ ÷ kg は同じ大きさなので、数字はそのまま kJ/(kg·K) になる。
R = R₀/M = 8.314/32.0 = 0.25981 → 0.260 kJ/(kg·K)(J/(mol·K) ÷ g/mol = kJ/(kg·K))
2
マイヤーの関係 cₚ − cᵥ = R から、cᵥ = cₚ − R。R は丸める前の値で引く。
cᵥ = cₚ − R = 0.918 − 0.25981 = 0.65819 → 0.658 kJ/(kg·K)(R は丸める前の値)
3
比熱比は定圧比熱 ÷ 定容比熱。分母の cᵥ も丸める前の値を使う。
κ = cₚ/cᵥ = 0.918/0.65819 = 1.3947 → 1.39

あわせて覚える

  • 比熱比は 単原子 ≈ 1.67、二原子 ≈ 1.40、三原子以上 ≈ 1.3 以下。分子の自由度が多いほど cᵥ が大きく κ は 1 に近づく。
つまずきやすいところ
M を kg/mol に直して 1000 倍ずれる(g/mol のまま割ればよい)/cᵥ ÷ cₚ と逆に割る。

「熱力学」のイメージ

熱と仕事がどう出入りするかを計算する分野。発電所も冷凍機もエンジンもこの考え方で動く。

熱力学の要点と全論点を見る ›

同じ分野の論点

ランキンサイクルの正味仕事と再熱・プランクの法則
タービンの仕事からポンプの仕事を引いたのが正味仕事。途中でもう一度加熱する(再熱)と出口の湿りが減る。
p-h 線図の線と冷媒の状態
縦が圧力、横がエンタルピー。山形の線の左が液、内側が湿り蒸気、右が過熱蒸気。冷凍サイクルを四角形で描ける。
計算ランキンサイクルの乾き度と熱効率
蒸気発電のモデル。タービンで膨張した後の蒸気の乾き度と、加熱量に対する仕事の割合を計算する。
計算湿り蒸気の比エンタルピーと乾き度
湿り蒸気は水と蒸気の混ざりもの。乾き度 x の割合で、飽和水と飽和蒸気の値を混ぜ合わせる。
計算絞り膨張(等エンタルピー)と乾き度
弁などで絞ると、圧力は下がるがエンタルピーは変わらない。そのため乾き度が変わる。
計算理想気体の状態方程式と体積
pV = mRT。圧力・体積・温度のうち2つが分かれば残りが出る。温度は必ずK。
計算等圧変化の仕事・内部エネルギー・エントロピー
圧力一定で加熱すると、一部は膨張の仕事に使われ、残りが内部エネルギーの増加になる。
計算定容加熱の加熱量とエントロピー変化
体積一定だと仕事をしないので、加えた熱はすべて内部エネルギー(温度上昇)になる。
計算水を飽和蒸気にする加熱量
水を沸点まで温める熱(顕熱)と、沸かして蒸気にする熱(潜熱)の合計。
計算蒸気表の読み取り(湿り蒸気)
圧力か温度から、飽和水(h')と飽和蒸気(h'')の値を表から読む。
計算蒸気表の直線補間
表にない中間の値は、前後の2行を直線でつないで比例配分で求める。
計算ディーゼルサイクルの温度・加熱量・熱効率
ディーゼルエンジンのモデル。圧縮した高温の空気に燃料を入れ、圧力一定で燃やす。
計算コンバインドサイクルの熱効率
ガスタービンで使った後の排熱で蒸気タービンも回す。2段で使うので全体の効率が上がる。
計算可逆断熱膨張の体積・温度・仕事
断熱膨張では内部エネルギーを減らして仕事をする。温度・体積は pV^κ = 一定の関係で決まる。
計算ピストンの力のつり合いと等圧加熱
ピストンにかかる力(圧力×面積と重さ)がつり合っていれば、加熱しても圧力は一定のまま。
計算カルノーサイクルの熱効率
熱機関の効率の上限。高温と低温の絶対温度だけで決まり、1 − T₂/T₁。
計算可逆断熱変化の温度
熱の出入りなしで圧縮すると温度が上がり、膨張すると下がる。pV^κ = 一定。
計算オットーサイクルの熱効率
ガソリンエンジンのモデル。圧縮比が大きいほど効率が上がる。
