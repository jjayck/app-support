相似則と回転速度制御の省エネ

課目Ⅳポンプ・送風機計算

ひとことで言うと

流量は回転数に、揚程は2乗に、動力は3乗に比例。回転数を少し下げるだけで動力は大きく減る。

練習問題

空欄 A・B・C に入るものを答えてください。

定格回転速度で軸動力 22 kW の送風機がある。インバータで回転速度を下げて風量を 75 % にしたとき、相似則が成り立つとすると軸動力は A kW になる。年間 5,000 時間この運転をすると、電力の削減量は B MWh/年 である(効率の変化は無視)。軸動力は回転速度の C に比例する。
A数値(3桁・□□.□)kW
B数値(3桁・□□□)MWh
C解答群
  1. ア平方根
  2. イ2乗
  3. ウ1乗
  4. エ3乗
答えとやさしい解き方を見る
  • A09.3 kW
  • B064 MWh
  • Cエ 3乗

数値の答えは本番と同じ「桁ごとのマーク」です。桁が余るときは先頭に 0 を入れます。

何を聞かれている?
送風機の回転を落として風量を減らしたとき、軸動力がいくつになり、1年で電気がどれだけ減るかを出す問題。

記号と単位

  • N … 回転速度
  • P₂ … 回転を落としたあとの軸動力(kW)
  • ∝ … 「比例する」の記号
  • MWh … 電力量の単位。1 MWh = 1000 kWh

解き方

1
相似則のルールを確認する。風量は回転速度にそのまま比例、圧力は2乗、軸動力は3乗に比例する。風量の割合 = 回転速度の割合 になる。
相似則:風量 ∝ N、圧力(揚程)∝ N²、軸動力 ∝ N³。
2
軸動力は回転速度の3乗に比例するので、もとの軸動力に「風量の割合の3乗」を掛ける。少し回転を落とすだけで動力は大きく下がる。
P₂ = 22 × 0.75³ = 22 × 0.4219 = 9.28 → 09.3 kW。
3
減った動力(もとの動力 − 新しい動力)× 年間の運転時間 で、減った電力量(kWh)になる。1000 で割って MWh に直す。
削減量 = (22 − 9.28) × 5,000 = 63,594 kWh = 63.6 → 64 MWh。

あわせて覚える

  • ダンパで絞る方法では軸動力はあまり下がらないため、回転速度制御の方が省エネ効果が大きい。
つまずきやすいところ
3乗でなく2乗や1乗で計算してしまう/kWh を MWh に直し忘れる(÷ 1000)。
