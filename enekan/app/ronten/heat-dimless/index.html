対流熱伝達の無次元数

課目Ⅱ伝熱工学

ひとことで言うと

ヌセルト数=対流の強さ、レイノルズ数=流れの勢い、プラントル数=流体の性質。この組合せで熱伝達率を出す。

練習問題

空欄 A・B・C に入るものを答えてください。

熱伝達率 h、代表長さ L、流体の熱伝導率 λ でつくる hL/λ を A 数という。動粘度と温度伝導率(熱拡散率)の比は B 数である。強制対流ではヌセルト数はレイノルズ数とプラントル数の関数、自然対流では C 数とプラントル数の関数で表される。
A解答群
  1. アヌセルト
  2. イビオ
  3. ウグラスホフ
  4. エプラントル
B解答群
  1. アプラントル
  2. イヌセルト
  3. ウレイノルズ
  4. エスタントン
C解答群
  1. アフルード
  2. イグラスホフ(またはレイリー)
  3. ウマッハ
  4. エレイノルズ
答えと解説を見る
  • Aア ヌセルト
  • Bア プラントル
  • Cイ グラスホフ(またはレイリー)
ANu = hL/λ(λ は流体の熱伝導率)。同じ形でも固体の熱伝導率を使うとビオ数 Bi になる。
BPr = ν/a。水は約 7(常温)、空気は約 0.7。
CGr は浮力と粘性力の比。Ra = Gr·Pr。円管内の乱流では Nu = 0.023 Re0.8 Pr0.4(ディッタス・ベルターの式)がよく使われる。

「伝熱工学」のイメージ

熱がどう伝わるかを扱う分野。伝わり方は伝導・対流・放射の3つだけ。

伝熱工学の要点と全論点を見る ›

同じ分野の論点

沸騰曲線と凝縮の形態
温度差を大きくすると、核沸騰で伝熱がピークになり、それを超えると蒸気の膜ができて急に伝わりにくくなる。
フーリエの法則と熱伝導率
物の中を伝わる熱は、温度差と熱伝導率に比例し、厚さに反比例する。
黒体・灰色体とキルヒホッフの法則
黒体はすべての光を吸収し最も強く放射する物。よく吸収する物はよく放射する(吸収率=放射率)。
速度境界層と温度境界層・プール沸騰
壁の近くの、流れが遅くなる層・温度が変わる層。プール沸騰は静かな液をためて沸騰させる状態。
計算円管内の強制対流と必要管長
熱伝達率から1mあたりに渡せる熱を出し、必要な熱量を渡すのに何mの管が要るかを計算する。
計算円管の保温の熱抵抗と放熱量
円管は外側ほど面積が広がるので、熱抵抗に対数(ln)が出てくる。
計算形態係数(相反則・総和則)と黒体間の放射
一方の面から出た放射のうち、もう一方の面に届く割合が形態係数。
計算囲まれた小物体の放射と対流の放熱
大きな部屋の中の小さな物は、自分の放射率だけで放射の放熱が決まる。対流の放熱と足して合計を出す。
計算多層平板の熱通過
壁が何層あっても、各層の熱抵抗(厚さ/熱伝導率)と表面の抵抗を足せば全体の熱の通りにくさになる。
計算平行平板間の放射伝熱
向かい合う2枚の板の間の放射は、絶対温度の4乗の差と、両方の放射率で決まる。
