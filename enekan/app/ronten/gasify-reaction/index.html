石炭・バイオマスのガス化反応

課目Ⅳ乾燥・蒸留

ひとことで言うと

石炭などを酸素や水蒸気と反応させて、CO・H₂などの燃えるガスに変える。

練習問題

空欄 A・B・C に入るものを答えてください。

炭素に水蒸気を反応させて一酸化炭素と水素をつくる水性ガス反応は A 反応である。一酸化炭素と水蒸気から二酸化炭素と水素をつくる反応を B 反応という。ガス化炉では、必要な熱を酸素や空気による炭素の C でまかなう。
A解答群
  1. ア熱の出入りのない
  2. イ発熱
  3. ウ吸熱
B解答群
  1. アシフト(水性ガスシフト)
  2. イメタネーション
  3. ウ改質
  4. エブードワ
C解答群
  1. ア部分燃焼
  2. イ乾留
  3. ウ完全燃焼
  4. エ電気加熱
答えと解説を見る
  • Aウ 吸熱
  • Bア シフト(水性ガスシフト)
  • Cア 部分燃焼
A水性ガス反応 C + H₂O → CO + H₂(吸熱)。ブードワ反応 C + CO₂ → 2CO(吸熱)。
Bシフト反応 CO + H₂O → CO₂ + H₂(わずかに発熱)。水素を増やしたいときに使う。
C部分燃焼 C + ½O₂ → CO(発熱)で吸熱反応の熱を補う。石炭の乾留はコークス炉で空気を断って加熱する別の工程。

「乾燥・蒸留」のイメージ

熱を使って水分を飛ばす(乾燥)、沸点の違いで液体を分ける(蒸留)、濃くする(蒸発濃縮)工程。

乾燥・蒸留の要点と全論点を見る ›

同じ分野の論点

蒸留塔の還流比と気液平衡
塔の上から出た液の一部を戻す割合が還流比。多く戻すほど分離はよくなるが、熱がたくさん要る。
蒸発濃縮の沸点上昇と省エネ蒸発法
溶けている物があると沸点が上がる。蒸気を何度も使い回す(多重効用・再圧縮)と少ない熱で済む。
乾燥特性曲線と含水率の区分
乾燥は 予熱 → 恒率(表面の水が一定の速さで蒸発) → 減率(中の水がゆっくり出てくる) の順に進む。
気液平衡・単蒸留・充てん塔と棚段塔
沸点の低い成分ほど蒸気側に多く移る。塔の中身は、充てん物を詰める型と棚(トレイ)を重ねる型がある。
乾燥機の受熱方式と乾燥の省エネ
熱い空気を当てる(対流)、熱い面に触れさせる(伝導)、赤外線などで温める(放射)の3つの受け取り方。
計算含水率と蒸発水量
乾量基準=乾いた物に対する水の割合、湿量基準=全体に対する水の割合。基準の違いに注意して蒸発量を出す。
計算連続精留の物質収支と還流比
入った量 = 塔頂から出た量 + 塔底から出た量。成分ごとにも同じように成り立つ。
