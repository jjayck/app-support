蒸気タービンの段落・変圧運転とガスタービン燃焼器

課目Ⅳタービン・発電

ひとことで言うと

タービンは羽根の段を重ねて少しずつ膨張させる。変圧運転=負荷に合わせてボイラの圧力を変える運転。

練習問題

空欄 A・B・C に入るものを答えてください。

蒸気タービンのうち、蒸気をノズルだけで膨張させ、その速度で動翼を回すのが A タービンで、1段あたりの熱落差を大きくとれる。部分負荷のときに主蒸気の圧力を負荷に応じて下げる B 運転は、弁の絞り損失が減り部分負荷の効率がよい。大形ガスタービンの高温部品は、表面にセラミックスの C を施して金属温度を下げている。
A解答群
  1. ア復水
  2. イ反動
  3. ウ衝動
  4. エ背圧
B解答群
  1. ア定圧
  2. イ変圧
  3. ウ抽気
  4. エ再熱
C解答群
  1. ア遮熱コーティング
  2. イめっき
  3. ウライニング
  4. エ防錆塗装
答えと解説を見る
  • Aウ 衝動
  • Bイ 変圧
  • Cア 遮熱コーティング
C高温部品の表面にセラミックスの遮熱コーティングを施し、金属の温度を下げる。
A衝動タービン:ノズルで全部膨張し、動翼では圧力が下がらない。反動タービン:動翼の中でも膨張し、その反動でも回る(段数が多くなる)。
B変圧運転:ボイラの圧力ごと下げるので、加減弁の絞り損失と給水ポンプ動力が減る。
ガスタービンの燃焼器には、円筒形の燃焼器を周方向に複数並べるマルチキャン形や、環状のアニュラ形がある。マルチキャン形は燃焼器を1本ずつ取り外して点検・交換しやすく、大形の発電用でも使われる。
コンバインドサイクルでは、排熱回収ボイラの蒸気でまわす蒸気タービンの出力がガスタービン出力のおよそ半分になる。

同じ分野の論点

ランキンサイクルの改良
蒸気の圧力・温度を上げる、復水器の圧力を下げる、再熱・再生(抽気で給水を加熱)で効率を上げる。
ガスタービンとコンバインドサイクル
空気を圧縮し、燃料を燃やした高温ガスで回す。排熱で蒸気をつくれば蒸気タービンも回せる。
往復動内燃機関の作動とコージェネ
ピストンを動かすエンジン(ガソリン・ディーゼル・ガスエンジン)。発電と同時に排熱を使うのがコージェネ。
危険速度・ガスタービンの出力向上・形式
危険速度=回転軸が共振して大きく振れる回転数。ガスタービンは吸い込む空気を冷やすと出力が上がる。
ガスタービンの軸構成と圧縮機のサージング対策
一軸式は圧縮機とタービンが1本の軸、二軸式は分かれている。圧縮機はサージングを防ぐため、抽気や静翼の角度で調整する。
ガスタービン燃焼器の空気配分と翼の冷却
空気は燃焼用・希釈(温度を下げる)用・冷却用に分けて使う。高温の羽根は内側から空気で冷やす。
蒸気タービンの経年劣化と高温高圧化
長く使うと、羽根の汚れ・すきまの広がり・浸食で効率が落ちる。高温高圧化すれば効率が上がる。
ガスタービンの性能と大気条件・最適圧力比
気温が高いと空気が薄くなり、出力が下がる。効率が最大になる圧力比と、出力が最大になる圧力比は違う。
計算蒸気タービンの内部効率と発電端出力
内部効率=実際の仕事 ÷ 理想(等エントロピー)の仕事。そこに機械効率・発電機効率を掛けて出力を出す。
ガスエンジンの熱勘定と排熱回収
エンジンの燃料の熱は、軸出力・排ガス・冷却水におおよそ分かれる。排ガスと冷却水の熱を回収するのがコージェネ。
