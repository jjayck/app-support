炉壁の蓄熱損失と排熱回収

課目Ⅳ工業炉・熱設備材料

ひとことで言うと

炉を止めたり動かしたりするたびに、壁を温める熱が無駄になる。排ガスの熱は燃焼空気の予熱で回収する。

練習問題

空欄 A・B・C に入るものを答えてください。

断続操業の炉では、炉壁を加熱するための A 損失が大きい。そのため、かさ密度が小さく熱容量の小さい B で内張りすると省エネになる。排ガスの熱で燃焼用空気を予熱する装置のうち、蓄熱体を交互に切り替えて使うものを C 式という。
A解答群
  1. ア蓄熱
  2. イ放射
  3. ウ冷却水
  4. エ開口部
B解答群
  1. アセラミックファイバ
  2. イ高アルミナ質れんが
  3. ウ粘土質れんが
  4. エ鋳鉄
C解答群
  1. アヒートパイプ
  2. イ換熱(レキュペレータ)
  3. ウ蓄熱(リジェネレータ)
  4. エ直接接触
答えと解説を見る
  • Aア 蓄熱
  • Bア セラミックファイバ
  • Cウ 蓄熱(リジェネレータ)
AC炉壁損失 = 外面からの放散熱 + 炉壁自体に蓄える熱。断続操業では毎回の蓄熱分がそのまま損失になる。
Bセラミックファイバは軽く熱容量が小さいので、昇温が速く蓄熱損失が小さい。
空気予熱器:換熱式(レキュペレータ)は隔壁を通して連続的に、蓄熱式(リジェネレータ)は蓄熱体を交互に切り替えて熱を渡す。リジェネラティブバーナは蓄熱式の代表例。

同じ分野の論点

耐火れんが・耐火断熱れんが・セラミックファイバの比較
重いれんがは高温に強いが熱をためやすい。軽い断熱材ほど熱を通しにくく、熱をためにくい。
連続式加熱炉の搬送方式・ヒートパターン・ベニアリング
材料を送りながら加熱する炉。どの位置で何度にするか(ヒートパターン)を決めて均一に加熱する。
セラミックファイバの組成と劣化・炉の熱精算
セラミックファイバは軽く熱容量が小さいが、高温で長く使うと縮む。熱精算=炉に入った熱と出た熱の内訳を出すこと。
計算工業炉の熱精算と炉効率
燃料の熱のうち、材料に入った割合が炉効率。残りは排ガス・炉壁・開口部などの損失で、ふつう排ガスがいちばん大きい。
計算空気予熱による燃料節約率
排ガスの熱で燃焼用の空気を温めて炉に戻すと、そのぶん燃料が少なくて済む。排ガスが熱い炉ほど効く。
計算被加熱物の熱量と燃料原単位
材料を温める熱 = 質量 × 比熱 × 温度差。それを炉効率で割ると燃料の熱になる。1 t あたりにしたのが原単位。
炉内の放射伝熱と炉圧・開口部の管理
高温の炉では熱は主に放射で伝わる。炉の中は少しだけ正圧にして、冷たい外気を入れない。
