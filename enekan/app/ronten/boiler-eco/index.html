過熱低減器・エコノマイザ・空気予熱器

課目Ⅳボイラ・蒸気

ひとことで言うと

過熱低減器=熱くなりすぎた蒸気を冷ます。エコノマイザ=排ガスで給水を予熱。空気予熱器=排ガスで燃焼空気を予熱。

練習問題

空欄 A・B・C・D・E に入るものを答えてください。

過熱低減器には、過熱蒸気を給水などと熱交換させて冷やす A 式と、蒸気に水を噴射してその B で熱を吸収させる噴射式がある。エコノマイザで給水を予熱すると、燃料の節約になるほか、ドラムに入る給水との温度差が小さくなり C が軽くなる。空気予熱器はふつうエコノマイザの D に置く。回転再生式空気予熱器の伝熱体には E が使われる。
A解答群
  1. ア噴射
  2. イ減圧
  3. ウ絞り
  4. エ表面冷却
B解答群
  1. ア化学反応熱
  2. イ蒸発潜熱
  3. ウ摩擦熱
  4. エ顕熱
C解答群
  1. アブロー量
  2. イNOx
  3. ウドラムの熱応力
  4. エ給水ポンプの動力
D解答群
  1. アドラムの中
  2. イ上流(火炉側)
  3. ウ下流(排ガスの出口側)
  4. エ煙突の外
E解答群
  1. ア耐火れんが
  2. イ金属板(波形の鋼板)
  3. ウガラス管
  4. エセラミックファイバ
答えと解説を見る
  • Aエ 表面冷却
  • Bイ 蒸発潜熱
  • Cウ ドラムの熱応力
  • Dウ 下流(排ガスの出口側)
  • Eイ 金属板(波形の鋼板)
C給水を予熱すると、ドラムに入る給水とボイラ水の温度差が小さくなり、ドラムの熱応力が軽くなる。
AB表面冷却式:管内の過熱蒸気を給水やボイラ水で冷やす(水が蒸気に混ざらない)。噴射式(スプレー式):純度の高い水を噴き込み、蒸発潜熱で温度を下げる。
排ガスの流れ:火炉 → 過熱器 → (再熱器)→ 蒸発管群 → エコノマイザ → 空気予熱器 → 集じん・脱硫 → 煙突。
E回転再生式(ユングストローム式):波形の金属板を詰めたロータが回り、排ガス側で温まり空気側で放熱する。低温部は硫酸の露点腐食に注意。

「ボイラ・蒸気」のイメージ

燃料の熱で水を蒸気に変え、工場の各所へ送って使い、戻すまでの一連の設備。

ボイラ・蒸気の要点と全論点を見る ›

同じ分野の論点

スチームトラップとフラッシュ蒸気
トラップ=蒸気は通さず、水(ドレン)だけを外へ出す弁。高圧のドレンが低圧に出ると一部が再び蒸気になる(フラッシュ)。
ボイラ水の水質管理
水の不純物はスケール(熱を通しにくくする)と腐食の原因。ブローで濃くなった水を捨てる。
ボイラの熱損失と低減策
いちばん大きいのは排ガスが持ち去る熱。空気比を下げる・排熱を回収するのが基本の対策。
貫流ボイラと循環ボイラ
循環=ドラムの水を何度も回して蒸発させる。貫流=管に水を一度通すだけで蒸気にする(水が少なく起動が速い)。
ボイラの NOx 抑制と排煙脱硫・脱硝
NOxは燃やし方で減らし、残りは装置で除く(脱硝)。SOxは排煙脱硫で除く。
シリカのキャリーオーバと脱気
キャリーオーバ=ボイラ水の中の成分が蒸気に混ざって運ばれること。脱気=腐食の原因になる酸素を水から抜く。
過熱器の温度特性・温度調節・材料
過熱器の受け取り方(放射か対流か)で、負荷が変わったときの蒸気温度の変わり方が逆になる。
孔食・苛性脆化・高温腐食
孔食=点状に深く掘れる腐食。苛性脆化=アルカリが濃くなって鋼がもろく割れる。高温腐食=燃焼ガス中の成分による腐食。
蒸気配管のドレン対策
配管の中で蒸気が冷えてできた水を、トラップで早く抜く。たまると衝撃(ウォーターハンマ)の原因になる。
循環ボイラと貫流ボイラの制御
循環ボイラはドラムの水位で給水を、圧力で燃料を制御する。貫流ボイラは給水と燃料の比で制御する。
計算効率改善による燃料・CO₂削減率
効率が上がると同じ蒸気を少ない燃料でつくれる。削減率 = 1 − 改善前の効率/改善後の効率。
計算換算蒸発量とボイラ効率
条件の違うボイラを比べるため、100℃の水を100℃の蒸気にした量に換算する。
計算蒸気表を使ったボイラの蒸発量
蒸気と給水のエンタルピーの差が、1kgあたりに要る熱。燃料の熱をこれで割ると蒸発量になる。
計算過熱蒸気表の読み取り
圧力と温度の2つで行と列を選び、エンタルピーなどを読む。
計算ボイラ効率(入出熱法)
蒸気が得た熱 ÷ 燃料が持ち込んだ熱。入出熱法は、入った熱と出た熱を直接比べる方法。
計算ボイラのブロー量と熱損失
蒸気になるのは水だけで、不純物はボイラに残って濃くなる。濃くなりすぎないよう一部を捨てるのがブロー。
計算ドレンのフラッシュ蒸気量
高圧の熱いドレンの圧力を下げると、持ちきれなくなった熱で一部が蒸気になる。これを低圧蒸気として使う。
計算蒸気配管の管径と流速
流す体積 = 質量 × 比体積。体積を流速で割ると必要な断面積になり、そこから管の太さが出る。
