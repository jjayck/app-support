指定の基準となる使用量

課目Ⅰ指定と原油換算

ひとことで言うと

原油換算で年1,500kL以上使うと国に指定される。工場単位では3,000kL以上が第一種、1,500kL以上が第二種。

練習問題

空欄 A・B・C に入るものを答えてください。

事業者全体の年度のエネルギー使用量(原油換算)が A kL 以上の者は特定事業者に指定される。特定事業者が設置する工場等のうち、使用量が B kL 以上のものは第一種エネルギー管理指定工場等に、C kL 以上で第一種に当たらないものは第二種エネルギー管理指定工場等に指定される。
A解答群
  1. ア5,000
  2. イ3,000
  3. ウ1,000
  4. エ1,500
B解答群
  1. ア1,500
  2. イ3,000
  3. ウ5,000
  4. エ10,000
C解答群
  1. ア1,500
  2. イ500
  3. ウ2,000
  4. エ1,000
答えと解説を見る
  • Aエ 1,500
  • Bイ 3,000
  • Cア 1,500
AC特定事業者:1,500 kL 以上(法7条、令2条)
B第一種エネルギー管理指定工場等:3,000 kL 以上(法10条、令3条)
第二種エネルギー管理指定工場等:1,500 kL 以上(法13条、令6条)
年度は4月1日〜翌年3月31日。

「指定と原油換算」のイメージ

燃料・熱・電気の使用量を「原油何kL分か」にそろえ、多い事業者を国が指定する。

指定と原油換算の要点と全論点を見る ›

同じ分野の論点

連携省エネルギー計画の認定
複数の事業者が協力して省エネしたとき、その成果を事業者間で分け合って報告できる仕組み。
エネルギー使用量に数えるもの・数えないもの
外から買った燃料・熱・電気は数える。自分で発電した電気など、二重に数えることになるものは数えない。
計算原油換算エネルギー使用量と指定区分
使った燃料・熱・電気をGJに直して合計し、0.0258を掛けて原油kLにする。その量で指定の区分が決まる。
