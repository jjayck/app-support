送風機の分類・無次元特性・斜流ポンプ

課目Ⅱ流体工学

ひとことで言うと

圧力の高さで、ファンとブロワに分かれる。羽根の形で特性が変わる。

練習問題

空欄 A・B・C・D・E に入るものを答えてください。

送風機は、羽根車の回転で気体に速度と圧力を与える A 形と、ケーシング内の容積を変えて押し出す B 形に分けられる。送風機の特性を大きさによらず比べるには、圧力係数と C を使う。サージングは、圧力係数(圧力)の曲線が流量に対して D の範囲で運転すると起こりやすい。斜流ポンプの軸動力は、吐出し量が変わっても E。
A解答群
  1. アルーツ
  2. イ容積
  3. ウターボ
  4. エ往復
B解答群
  1. アターボ
  2. イ遠心
  3. ウ軸流
  4. エ容積
C解答群
  1. ア摩擦係数
  2. イレイノルズ数
  3. ウ流量係数
  4. エ比熱比
D解答群
  1. ア右下がり
  2. イ右上がり
  3. ウ水平
E解答群
  1. アあまり変わらない
  2. イ締め切りで最小になる
  3. ウ締め切りで最大になる
答えと解説を見る
  • Aウ ターボ
  • Bエ 容積
  • Cウ 流量係数
  • Dイ 右上がり
  • Eア あまり変わらない
Dサージングは、圧力の曲線が流量に対して右上がりになる範囲で運転すると起こりやすい。
ABターボ形:遠心・斜流・軸流(多翼・ラジアル・ターボ・プロペラなど)。容積形:回転式(ルーツ・スクリュー)と往復式。
C圧力係数 ψ ∝ 圧力/(ρu²)、流量係数 φ ∝ 流量/(羽根車の面積 × 周速 u)。相似な送風機は同じ ψ-φ 曲線になる。
E軸動力の特性:遠心は流量とともに増える(締め切り起動)、軸流は締め切りで最大(弁を開けて起動)、斜流はその中間で流量によらずほぼ一定(過負荷になりにくい)。

「流体工学」のイメージ

水や空気が管の中をどう流れ、どれだけエネルギーを失うかを扱う分野。

流体工学の要点と全論点を見る ›

同じ分野の論点

ポンプ・送風機の運転障害
キャビテーション=圧力が下がって泡ができる。サージング=小流量で圧力と流量が周期的に揺れる。
ターボポンプの形式・比速度・特性
羽根車で水に勢いをつけるポンプ。比速度で遠心・斜流・軸流の向き不向きが分かる。
計算管路損失とポンプの軸動力
ポンプは高さの差と管の損失の分だけ水を持ち上げる。軸動力 = ρgQH ÷ 効率。
計算ベンチュリ管・マノメータと粘性係数のレイノルズ数
管を細くした所の圧力低下を液柱で測ると流速・流量が分かる。
計算タンクからの流出と管の摩擦損失
水面の高さのエネルギーが、出口の速さと管の摩擦損失に分かれる。
計算相当直径と層流の管摩擦係数
円でない管は 4×断面積/濡れ縁長さ で直径に置き換える。層流なら管摩擦係数は 64/Re。
計算ブラジウスの式と乱流の摩擦損失
なめらかな管の乱流では、管摩擦係数をブラジウスの式(Reの1/4乗に反比例)で求める。
計算加圧タンクの小孔からの流出
タンク内の圧力と水位の両方が、小さな穴から噴き出す速さになる(流速 = √(2×押す力のヘッド×g))。
計算高さの違う2点のベルヌーイの式
高い所へ上がった分、圧力か速度のエネルギーが減る。位置のエネルギーも含めて合計を一定にする。
計算連続の式とベルヌーイの定理
流量は管のどこでも同じ(連続の式)。流れのエネルギー(圧力+速度+高さ)の合計も一定(ベルヌーイ)。
計算レイノルズ数と流れの判定
流れの勢いと粘りの比。円管では約2300より小さいと層流、大きいと乱流。
