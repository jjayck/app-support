熱電対の基準接点補償と温度の読み取り

課目Ⅳ計測と制御計算

ひとことで言うと

熱電対の電圧は2つの接点の温度差で決まる。表は 0 ℃ 基準なので、端子の温度ぶんの電圧を足してから読む。

練習問題

空欄 A・B・C・D に入るものを答えてください。

K 熱電対で炉内温度を測る。計器の端子(基準接点)の温度は 20 ℃ で、計器で測った熱起電力は 29.367 mV であった。規準熱起電力(基準接点 0 ℃)は 20 ℃ で 0.798 mV、700 ℃ で 29.129 mV、800 ℃ で 33.275 mV とし、その間は直線とみなす。基準接点 0 ℃ に直した熱起電力は A mV で、測温接点の温度は B ℃ である。基準接点の補正をせずに測った起電力をそのまま換算すると、温度は C K 低く読まれる。補償導線を使うのは「D」である。
A数値(5桁・□□.□□□)mV
B数値(3桁・□□□)℃
C数値(2桁・□□)K
D解答群
  1. ア測温接点の応答を速くするため
  2. イ熱電対と同じ熱起電力特性をもつ安価な線で、基準接点を計器の位置まで移すため
  3. ウ電気抵抗を測って温度を求めるため
  4. エ熱起電力を大きくして感度を上げるため
答えとやさしい解き方を見る
  • A30.165 mV
  • B725 ℃
  • C19 K
  • Dイ 熱電対と同じ熱起電力特性をもつ安価な線で、基準接点を計器の位置まで移すため

数値の答えは本番と同じ「桁ごとのマーク」です。桁が余るときは先頭に 0 を入れます。

何を聞かれている?
計器で測った熱電対の電圧を、0 ℃ 基準の表で読める値に直して、炉の温度を出す問題。

記号と単位

  • 測温接点 … 炉の中の、温度を測りたい側の先端
  • 基準接点 … 計器の端子側。ここの温度との差で電圧が出る
  • E(t, t₀) … 基準接点が t₀ のときに出る電圧

解き方

1
熱電対の電圧は「先端と端子の温度差」ぶんしか出ない。表は端子が 0 ℃ のときの値なので、端子の温度(0 ℃ → t₀)ぶんの電圧を足して 0 ℃ 基準に直す。
補償導線:熱電対と同じ熱起電力特性をもつ安価な線。端子(基準接点)を計器の位置まで延ばし、計器の側で基準接点の温度を補正する。
2
表の2つの温度の間を直線とみなす。「表の下の値からどれだけ上か」÷「2点の電圧の差」× 100 ℃ を、下の温度に足す。
熱起電力は2つの接点の温度差で決まる。0 ℃ 基準の表を使うには、基準接点 20 ℃ ぶんを足す:E(t, 0) = E(t, 20) + E(20, 0) = 29.367 + 0.798 = 30.165 → 30.165 mV
3
足し忘れた電圧で同じように換算すると、低い温度が出る。その差が補正の大きさで、端子の温度とほぼ同じになる。
直線補間:t = 700 + (30.165 − 29.129)/(33.275 − 29.129) × 100 = 724.99 → 725 ℃

あわせて覚える

  • 補正なしで 29.367 mV を換算すると 705.74 ℃、差 = 19.25 → 19 K(基準接点の温度にほぼ等しいが、起電力の傾きが温度で違うので一致はしない)
  • K 熱電対はクロメル・アルメル、常用限度はおよそ 1,000 ℃(線径による)。
つまずきやすいところ
端子の温度(℃)を電圧に足してしまう。足すのは「端子の温度に対応する電圧(mV)」。

「計測と制御」のイメージ

温度・圧力・流量を測り、目標とずれたら自動で調整するしくみ。

計測と制御の要点と全論点を見る ›

同じ分野の論点

PID制御の各動作
P=ずれに比例して動かす、I=ずれの合計を見てずれを消す、D=ずれの変化の速さを見て先回りする。
カスケード・比率・フィードフォワード制御
カスケード=一方の調節計の出力を別の調節計の目標にする。比率=2つの流量の比を一定に保つ。フィードフォワード=外乱を先に測って動かす。
熱電対と差圧式流量計
熱電対=2種類の金属の接点の温度差で電圧が出る。差圧式=絞りの前後の圧力差から流量を出す(流量は差圧の平方根に比例)。
絶対圧・ゲージ圧と真空計
絶対圧=真空を0とした圧力。ゲージ圧=大気圧を0とした圧力。絶対圧 = ゲージ圧 + 大気圧。
調節弁の容量係数と流量特性
Cv値=弁の流しやすさ。開度と流量の関係(リニア・イコールパーセント等)が流量特性。
熱電対の取り付けと表面温度の測定誤差
熱電対の線を伝って熱が逃げると、実際より低く測れる。表面に沿わせて取り付ける。
面積式流量計(フロート形)
テーパの付いた管の中でフロートが浮き上がる高さで流量を読む。
シーケンス制御・伝達関数・PIDの式
シーケンス=決められた順番どおりに動かす制御。伝達関数=入力と出力の関係を式で表したもの。
コリオリ式流量計とブルドン管圧力計
コリオリ式=振動する管の中を流れる力で質量流量を直接測る。ブルドン管=曲げた管が圧力で伸びる量を針に伝える。
補償導線の形式と基準接点
熱電対から計器まで、熱電対と同じ性質の線で延ばす。基準接点の温度をもとに測る。
熱電対の保護管と放射温度計の放射率
保護管で熱電対を守るが、応答は遅くなる。放射温度計は物の放射率を正しく設定しないと誤差が出る。
差圧伝送器の検出方式と伝送信号
圧力差を電気の信号(4〜20 mA など)に変えて送る。
ステップ応答法・限界感度法と強制循環ボイラ・オットー機関
PIDの調整値の決め方。ステップ応答法は入力を一度だけ変えたときの応答から、限界感度法は振動し始める点から決める。
調節弁の構造(単座・複座)とCv値
単座弁は閉めたときの漏れが少ない。複座弁は流体の力がつり合うので小さい力で動かせるが、漏れは多め。
熱電対・測温抵抗体の数値と真空計
白金測温抵抗体は温度で抵抗が変わる性質を使う。種類ごとに使える温度の範囲がある。
定値制御・追値制御・プログラム制御と主調節計・従調節計
目標が一定(定値)、目標が別の値に追従して変わる(追値)、目標を時間の予定どおりに変える(プログラム)。
計算ピトー管の差圧と流速
流れを正面で受けた圧力と横の圧力の差から流速を出す。流速は差圧の平方根に比例する。
計算P動作のオフセットと行き過ぎ量・減衰比
P動作だけでは少しずれが残る(オフセット)。行き過ぎ量=目標を超えた分、減衰比=揺れがどれだけ早くおさまるか。
計算測定誤差の合成と系統誤差・偶然誤差
系統誤差=いつも同じ向きにずれる(補正できる)。偶然誤差=ばらつく。合成は2乗和の平方根。
計算比例帯とオフセットの計算
比例帯が広いほど動きはおだやかだが、オフセットは大きくなる。
計算差圧式流量計の開平と差圧伝送器
オリフィスの差圧は流量の2乗に比例する。だから流量は差圧の平方根(開平)で出す。
計算測温抵抗体の抵抗と導線の誤差
白金の抵抗は温度とともに増える。Pt100 は 0 ℃ で 100 Ω。導線の抵抗も足されてしまうので3導線式で打ち消す。
