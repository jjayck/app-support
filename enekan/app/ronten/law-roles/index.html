統括者・企画推進者の選任

課目Ⅰ管理体制

ひとことで言うと

会社全体の省エネ責任者が統括者(役員クラス)、その実務を支える参謀が企画推進者。

練習問題

空欄 A・B・C に入るものを答えてください。

特定事業者は、事業の実施を統括管理する者(役員クラス)を A として選任しなければならない。さらに、これを補佐する B を、指定の講習の修了者又は C のうちから選任しなければならない。
A解答群
  1. アエネルギー管理統括者
  2. イエネルギー管理企画推進者
  3. ウエネルギー管理者
  4. エエネルギー管理員
B解答群
  1. アエネルギー管理企画推進者
  2. イエネルギー管理員
  3. ウエネルギー管理統括者
  4. エエネルギー管理者
C解答群
  1. ア電気主任技術者
  2. イ技術士
  3. ウエネルギー管理士免状の交付を受けている者
  4. エボイラー技士
答えと解説を見る
  • Aア エネルギー管理統括者
  • Bア エネルギー管理企画推進者
  • Cウ エネルギー管理士免状の交付を受けている者
A法8条:エネルギー管理統括者 = 事業の実施を統括管理する者をもって充てる(資格要件なし)。
BC法9条:エネルギー管理企画推進者 = 講習修了者 or エネルギー管理士から選任し、統括者を補佐。
選任・解任の届出は、選任・解任のあった日の後の最初の7月末日まで(規則12条・15条)。

同じ分野の論点

エネルギー管理者等の義務
工場の現場で設備の運転・管理を見張り、省エネを進めるのが管理者・管理員の仕事。
エネルギー管理者の選任期限・業務・届出
選ぶべきことが決まったら期限内に選び、国に届け出る。業務は設備の維持と使用方法の改善・監視。
統括者の業務と企画推進者の講習
統括者は中長期計画づくりや設備の新設・改造の方針を統括する。企画推進者は決められた講習を受ける。
計算エネルギー管理者の選任数
使用量が多い工場ほど、選ぶ管理者の人数が増える。表で覚える。
