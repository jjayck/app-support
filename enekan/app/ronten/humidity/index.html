相対湿度・絶対湿度・飽和度

課目Ⅳ冷凍・空調計算

ひとことで言うと

絶対湿度=乾いた空気1kgあたりの水蒸気量。相対湿度=その温度で含める最大量に対する割合。

練習問題

空欄 A・B・C・D に入るものを答えてください。

大気圧 101.3 kPa、乾球温度 35 ℃ の湿り空気の相対湿度が 50 % である。35 ℃ の飽和水蒸気圧を 5.629 kPa とすると、水蒸気分圧は A kPa、絶対湿度は乾き空気 1 kg あたり B g、飽和度(比較湿度)は C % である。絶対湿度を変えずにこの空気を加熱すると、相対湿度は D。
A数値(4桁・□.□□□)kPa
B数値(4桁・□□.□□)g/kg(DA)
C数値(3桁・□□.□)%
D解答群
  1. ア上がる
  2. イ下がる
  3. ウ変わらない
  4. エ0 になる
答えとやさしい解き方を見る
  • A2.815 kPa
  • B17.78 g/kg(DA)
  • C48.6 %
  • Dイ 下がる

数値の答えは本番と同じ「桁ごとのマーク」です。桁が余るときは先頭に 0 を入れます。

何を聞かれている?
相対湿度から水蒸気の圧力(分圧)を出し、絶対湿度と飽和度を計算する問題。

記号と単位

  • φ … 相対湿度
  • pw … 水蒸気分圧、ps … その温度の飽和水蒸気圧
  • P … 大気圧(全圧)
  • x … 絶対湿度(乾き空気 1 kg あたりの水蒸気の kg)、xs … 飽和したときの絶対湿度
  • ψ … 飽和度(比較湿度)

解き方

1
相対湿度は「水蒸気の圧力が、飽和の何割か」。だから飽和水蒸気圧に相対湿度(小数)を掛ければ水蒸気分圧になる。
相対湿度 φ = pw/ps → pw = 0.5 × 5.629 = 2.8145 → 2.815 kPa
2
全体の圧力から水蒸気の分を引いた (P − pw) が乾き空気の分圧。0.622 × pw ÷ (P − pw) で乾き空気 1 kg あたりの水蒸気の kg。1000 を掛けて g にする。
絶対湿度 x = 0.622 pw/(P − pw) = 0.622 × 2.8145/(101.3 − 2.8145) = 0.017775 kg/kg(DA) → 17.78 g/kg(DA)
3
同じ式で pw のかわりに ps を入れると、飽和したときの絶対湿度 xs。飽和度は x ÷ xs で、100 を掛けて %。
飽和絶対湿度 xs = 0.622 × 5.629/(101.3 − 5.629) = 0.036597、飽和度 ψ = x/xs = 48.571 → 48.6 %(相対湿度よりわずかに小さい)

あわせて覚える

  • (0.622 = 水の分子量 18.02/空気の分子量 28.97)
  • 加熱すると ps が大きくなり pw は変わらないので、相対湿度は下がる。逆に冷やして pw = ps となる温度が露点温度。
つまずきやすいところ
分母を P のままにして pw を引き忘れる/kg/kg と g/kg の桁(× 1000)。

「冷凍・空調」のイメージ

冷媒が「蒸発して熱を奪い、外で凝縮して熱を捨てる」を繰り返して、熱を低い所から高い所へ運ぶ。

冷凍・空調の要点と全論点を見る ›

同じ分野の論点

冷凍サイクルと空調の用語
冷媒は 圧縮機 → 凝縮器 → 膨張弁 → 蒸発器 の順に回る。空調では顕熱と潜熱を分けて考える。
空調負荷と外気の利用
外が涼しいときは外気をそのまま入れて冷房の負荷を減らす(外気冷房)。
全熱交換器の型と顕熱交換器
換気で捨てる空気と取り入れる外気の間で、温度と湿気の両方をやり取りするのが全熱交換器。
計算外気と還気の混合と冷却負荷
混ぜた空気の温度・湿度は量に比例して平均される。そこから冷やす熱量を出す。
計算冷凍機とヒートポンプの成績係数
同じ機械でも、冷やす側の熱を見るのが冷凍、温める側を見るのがヒートポンプ。ヒートポンプのCOPは冷凍のCOP+1。
