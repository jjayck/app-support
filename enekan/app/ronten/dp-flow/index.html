差圧式流量計の開平と差圧伝送器

課目Ⅳ計測と制御計算

ひとことで言うと

オリフィスの差圧は流量の2乗に比例する。だから流量は差圧の平方根(開平)で出す。

練習問題

空欄 A・B・C・D に入るものを答えてください。

オリフィス流量計で、最大流量 150 t/h のとき差圧は 40 kPa である。差圧が 25.6 kPa のとき流量は A t/h である。差圧伝送器の出力が 0〜40 kPa に対して 4〜20 mA(差圧に比例)のとき、このときの出力は B mA である。流量が最大流量の 30 % のとき、差圧は最大差圧の C % になる。差圧式流量計の性質として正しいのは「D」である。
A数値(4桁・□□□.□)t/h
B数値(4桁・□□.□□)mA
C数値(3桁・□□.□)%
D解答群
  1. ア差圧は流量に比例するので開平演算はいらない
  2. イ流体の密度が変わっても指示は変わらない
  3. ウ流量が大きいほど差圧が小さくなる
  4. エ流量が小さい範囲では差圧が流量の2乗で小さくなり、測定精度が落ちる
答えとやさしい解き方を見る
  • A120.0 t/h
  • B14.24 mA
  • C09.0 %
  • Dエ 流量が小さい範囲では差圧が流量の2乗で小さくなり、測定精度が落ちる

数値の答えは本番と同じ「桁ごとのマーク」です。桁が余るときは先頭に 0 を入れます。

何を聞かれている?
オリフィス流量計の差圧から流量を出し、差圧伝送器の出力(4〜20 mA)と、差圧と流量の関係を確かめる問題。

記号と単位

  • Δp … オリフィスの前後の圧力の差(差圧)
  • Qmax・Δpmax … 最大流量と、そのときの差圧
  • 4〜20 mA … 計器へ送る電流の信号。0 % が 4 mA、100 % が 20 mA

解き方

1
差圧は流量の2乗に比例するので、逆に流量は差圧の平方根に比例する。差圧の割合を出して √ をとり、最大流量を掛ける(電卓の √ キーを使う)。
オリフィスの流量は差圧の平方根に比例:Q = Qmax × √(Δp/Δpmax) = 150 × √(25.6/40) = 150 × 0.8000 = 120.000 → 120.0 t/h
2
伝送器は差圧に比例した電流を出す。0 % で 4 mA、幅は 16 mA なので、4 + 16 × 差圧の割合。
出力 = 4 + 16 × Δp/Δpmax = 4 + 16 × 0.6400 = 14.240 → 14.24 mA(流量に直すには伝送器か計器で開平演算する)
3
差圧は流量の2乗なので、流量の割合を2乗する。流量が少ないと差圧はとても小さくなる。
差圧は流量の2乗に比例:(30/100)² = 0.0900 → 9.0 %

あわせて覚える

  • 流量のレンジアビリティ(測れる範囲の比)はおよそ 3:1〜4:1 と狭い。質量流量は √(Δp·ρ) に比例するので、密度が変わる気体や蒸気では温度・圧力補正が要る。
つまずきやすいところ
流量を差圧に比例させてしまう(√ を忘れる)/4〜20 mA の 4 を足し忘れる。

「計測と制御」のイメージ

温度・圧力・流量を測り、目標とずれたら自動で調整するしくみ。

計測と制御の要点と全論点を見る ›

同じ分野の論点

PID制御の各動作
P=ずれに比例して動かす、I=ずれの合計を見てずれを消す、D=ずれの変化の速さを見て先回りする。
カスケード・比率・フィードフォワード制御
カスケード=一方の調節計の出力を別の調節計の目標にする。比率=2つの流量の比を一定に保つ。フィードフォワード=外乱を先に測って動かす。
熱電対と差圧式流量計
熱電対=2種類の金属の接点の温度差で電圧が出る。差圧式=絞りの前後の圧力差から流量を出す(流量は差圧の平方根に比例)。
絶対圧・ゲージ圧と真空計
絶対圧=真空を0とした圧力。ゲージ圧=大気圧を0とした圧力。絶対圧 = ゲージ圧 + 大気圧。
調節弁の容量係数と流量特性
Cv値=弁の流しやすさ。開度と流量の関係(リニア・イコールパーセント等)が流量特性。
熱電対の取り付けと表面温度の測定誤差
熱電対の線を伝って熱が逃げると、実際より低く測れる。表面に沿わせて取り付ける。
面積式流量計(フロート形)
テーパの付いた管の中でフロートが浮き上がる高さで流量を読む。
シーケンス制御・伝達関数・PIDの式
シーケンス=決められた順番どおりに動かす制御。伝達関数=入力と出力の関係を式で表したもの。
コリオリ式流量計とブルドン管圧力計
コリオリ式=振動する管の中を流れる力で質量流量を直接測る。ブルドン管=曲げた管が圧力で伸びる量を針に伝える。
補償導線の形式と基準接点
熱電対から計器まで、熱電対と同じ性質の線で延ばす。基準接点の温度をもとに測る。
熱電対の保護管と放射温度計の放射率
保護管で熱電対を守るが、応答は遅くなる。放射温度計は物の放射率を正しく設定しないと誤差が出る。
差圧伝送器の検出方式と伝送信号
圧力差を電気の信号(4〜20 mA など)に変えて送る。
ステップ応答法・限界感度法と強制循環ボイラ・オットー機関
PIDの調整値の決め方。ステップ応答法は入力を一度だけ変えたときの応答から、限界感度法は振動し始める点から決める。
調節弁の構造(単座・複座)とCv値
単座弁は閉めたときの漏れが少ない。複座弁は流体の力がつり合うので小さい力で動かせるが、漏れは多め。
熱電対・測温抵抗体の数値と真空計
白金測温抵抗体は温度で抵抗が変わる性質を使う。種類ごとに使える温度の範囲がある。
定値制御・追値制御・プログラム制御と主調節計・従調節計
目標が一定(定値)、目標が別の値に追従して変わる(追値)、目標を時間の予定どおりに変える(プログラム)。
計算ピトー管の差圧と流速
流れを正面で受けた圧力と横の圧力の差から流速を出す。流速は差圧の平方根に比例する。
計算P動作のオフセットと行き過ぎ量・減衰比
P動作だけでは少しずれが残る(オフセット)。行き過ぎ量=目標を超えた分、減衰比=揺れがどれだけ早くおさまるか。
計算測定誤差の合成と系統誤差・偶然誤差
系統誤差=いつも同じ向きにずれる(補正できる)。偶然誤差=ばらつく。合成は2乗和の平方根。
計算比例帯とオフセットの計算
比例帯が広いほど動きはおだやかだが、オフセットは大きくなる。
計算熱電対の基準接点補償と温度の読み取り
熱電対の電圧は2つの接点の温度差で決まる。表は 0 ℃ 基準なので、端子の温度ぶんの電圧を足してから読む。
計算測温抵抗体の抵抗と導線の誤差
白金の抵抗は温度とともに増える。Pt100 は 0 ℃ で 100 Ω。導線の抵抗も足されてしまうので3導線式で打ち消す。
