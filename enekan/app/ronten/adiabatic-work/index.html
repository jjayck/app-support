可逆断熱膨張の体積・温度・仕事

課目Ⅱ熱力学計算

ひとことで言うと

断熱膨張では内部エネルギーを減らして仕事をする。温度・体積は pVκ = 一定の関係で決まる。

練習問題

空欄 A・B・C・D に入るものを答えてください。

空気 2 kg が 400 kPa、600 K の状態から、200 kPa まで可逆断熱膨張する。空気を理想気体とし、ガス定数 0.287 kJ/(kg·K)、比熱比 κ = 1.4 とする。膨張後の体積は A m³、温度は B K、気体がした仕事は C kJ である。可逆断熱変化では D が成り立つ。ただし 21/1.4 = 1.6407 とする。
A数値(4桁・□□.□□)m³
B数値(3桁・□□□)K
C数値(4桁・□□□□)kJ
D解答群
  1. アPVκ = 一定
  2. イV/T = 一定
  3. ウPV = 一定
  4. エP/T = 一定
答えとやさしい解き方を見る
  • A01.41 m³
  • B492 K
  • C0155 kJ
  • Dア PVκ = 一定

数値の答えは本番と同じ「桁ごとのマーク」です。桁が余るときは先頭に 0 を入れます。

何を聞かれている?
気体が熱の出入りなしに(可逆断熱で)膨らんだとき、膨張後の体積・温度と、気体が外にした仕事を求める問題。

記号と単位

  • m … 気体の質量(kg)、R … ガス定数、P … 圧力(kPa)、V … 体積(m³)、T … 温度(K)
  • κ(比熱比)… 空気なら 1.4、cᵥ … 体積一定での比熱
  • W … 気体がした仕事(kJ)

解き方

1
理想気体の式 PV = mRT を V について解いて、初めの体積を出す。kPa × m³ = kJ なので、R を kJ のまま使えば単位がそろう。
初めの体積 V₁ = mRT₁/P₁ = 2 × 0.287 × 600/400 = 0.86100 m³
2
可逆断熱では PVκ が一定。圧力が下がった割合の 1/κ 乗だけ体積が増える。その累乗の値は問題文に書いてあるものを使う。
PVκ = 一定 → V₂ = V₁ (P₁/P₂)1/κ = 0.86100 × 1.6407 = 1.41264 → 1.41 m³
3
膨張後の圧力と体積が分かったので、もう一度 PV = mRT を T について解く。
T₂ = P₂V₂/(mR) = 200 × 1.41264/(2 × 0.287) = 492.21 → 492 K
4
断熱変化の仕事は (初めの PV − 後の PV) ÷ (κ − 1)。熱が出入りしないので、気体は自分の内部エネルギーを減らして仕事をする。
断熱変化の仕事 W = (P₁V₁ − P₂V₂)/(κ − 1) = (344.400 − 282.529)/0.4 = 154.68 → 155 kJ(= m·cᵥ(T₁ − T₂)、内部エネルギーの減少分)

あわせて覚える

  • 本番で累乗の値が表で与えられるとき、たとえば 1.21/1.4 は 1.2 = 6/5 として 61/1.4 ÷ 51/1.4 のように表の値の比で求める。
つまずきやすいところ
体積の倍率を (P₁/P₂) そのもので掛けてしまう(1/κ 乗が必要)/仕事の式で κ − 1 でなく κ で割る。

「熱力学」のイメージ

熱と仕事がどう出入りするかを計算する分野。発電所も冷凍機もエンジンもこの考え方で動く。

熱力学の要点と全論点を見る ›

同じ分野の論点

ランキンサイクルの正味仕事と再熱・プランクの法則
タービンの仕事からポンプの仕事を引いたのが正味仕事。途中でもう一度加熱する(再熱)と出口の湿りが減る。
p-h 線図の線と冷媒の状態
縦が圧力、横がエンタルピー。山形の線の左が液、内側が湿り蒸気、右が過熱蒸気。冷凍サイクルを四角形で描ける。
計算ランキンサイクルの乾き度と熱効率
蒸気発電のモデル。タービンで膨張した後の蒸気の乾き度と、加熱量に対する仕事の割合を計算する。
計算湿り蒸気の比エンタルピーと乾き度
湿り蒸気は水と蒸気の混ざりもの。乾き度 x の割合で、飽和水と飽和蒸気の値を混ぜ合わせる。
計算絞り膨張(等エンタルピー)と乾き度
弁などで絞ると、圧力は下がるがエンタルピーは変わらない。そのため乾き度が変わる。
計算理想気体の状態方程式と体積
pV = mRT。圧力・体積・温度のうち2つが分かれば残りが出る。温度は必ずK。
計算等圧変化の仕事・内部エネルギー・エントロピー
圧力一定で加熱すると、一部は膨張の仕事に使われ、残りが内部エネルギーの増加になる。
計算定容加熱の加熱量とエントロピー変化
体積一定だと仕事をしないので、加えた熱はすべて内部エネルギー(温度上昇)になる。
計算ガス定数・比熱の関係と比熱比
定圧比熱 − 定容比熱 = ガス定数。比熱比 κ = 定圧比熱 / 定容比熱(空気は約1.4)。
計算水を飽和蒸気にする加熱量
水を沸点まで温める熱(顕熱)と、沸かして蒸気にする熱(潜熱)の合計。
計算蒸気表の読み取り(湿り蒸気)
圧力か温度から、飽和水(h')と飽和蒸気(h'')の値を表から読む。
計算蒸気表の直線補間
表にない中間の値は、前後の2行を直線でつないで比例配分で求める。
計算ディーゼルサイクルの温度・加熱量・熱効率
ディーゼルエンジンのモデル。圧縮した高温の空気に燃料を入れ、圧力一定で燃やす。
計算コンバインドサイクルの熱効率
ガスタービンで使った後の排熱で蒸気タービンも回す。2段で使うので全体の効率が上がる。
計算ピストンの力のつり合いと等圧加熱
ピストンにかかる力(圧力×面積と重さ)がつり合っていれば、加熱しても圧力は一定のまま。
計算カルノーサイクルの熱効率
熱機関の効率の上限。高温と低温の絶対温度だけで決まり、1 − T₂/T₁。
計算可逆断熱変化の温度
熱の出入りなしで圧縮すると温度が上がり、膨張すると下がる。pV^κ = 一定。
計算オットーサイクルの熱効率
ガソリンエンジンのモデル。圧縮比が大きいほど効率が上がる。
