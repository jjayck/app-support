蓄熱・蓄電の基礎

課目Ⅰエネルギー概論・単位

ひとことで言うと

余っている時間にためて、足りない時間に使う。熱でためるか電気でためるかの違い。

練習問題

空欄 A・B・C に入るものを答えてください。

氷の融解潜熱は約 334 kJ/kg で、水の温度を 1 K 上げる顕熱(約 4.19 kJ/kg)のおよそ A 倍あるので、氷蓄熱は同じ体積で多くの熱をためられる。電力貯蔵用の二次電池のうち、約 300 ℃ で運転し、大容量の電力貯蔵に使われるのは B 電池である。電解液をタンクにためてポンプで循環させる C 電池は、タンクを大きくすれば容量を増やせる。
A解答群
  1. ア800
  2. イ80
  3. ウ2
  4. エ8
B解答群
  1. アNaS(ナトリウム・硫黄)
  2. イリチウムイオン
  3. ウ鉛
  4. エニッケル水素
C解答群
  1. ア空気
  2. イレドックスフロー
  3. ウ鉛
  4. エNaS
答えと解説を見る
  • Aイ 80
  • Bア NaS(ナトリウム・硫黄)
  • Cイ レドックスフロー
A334 ÷ 4.19 ≒ 80。氷蓄熱は夜間の電力で氷をつくり、昼間の冷房に使う(ピークシフト)。
BNaS 電池:負極にナトリウム、正極に硫黄。高温で動作し、エネルギー密度が大きい。
Cレドックスフロー電池:バナジウムなどのイオンの酸化還元を使う。長寿命で大型の定置用。
リチウムイオン電池:エネルギー密度が大きく、電気自動車や家庭用に広く使われる。エネルギー密度は Wh/kg で比べる(1 Wh = 3.6 kJ)。

同じ分野の論点

SI基本単位と組立単位
基本は m・kg・s・A・K・mol・cd の7つ。J(ジュール)や W(ワット)はこれらの組合せでできている。
エネルギー変換と回生・ヒートポンプ
ブレーキで捨てていたエネルギーを電気に戻すのが回生。ヒートポンプは電気で熱をくみ上げる。
風力の出力・粘性の温度依存・電気加熱
風力の出力は風速の3乗に比例。液体の粘性は温度が上がると下がり、気体は上がる。
熱回路と電気回路の対応
温度差=電圧、熱流=電流、熱抵抗=電気抵抗。直列の壁は抵抗の足し算で解ける。
電気の組立単位(C・V・Ω)
電荷 C = A·s、電圧 V = W/A、抵抗 Ω = V/A。基本単位までさかのぼって組み立てられる。
エネルギーの種類ごとのエクセルギー率
電気や仕事はほぼ全部が使えるエネルギー。熱は温度が低いほど使える割合(エクセルギー率)が小さい。
計算成績係数の一次エネルギー換算と比較
ヒートポンプのCOPは電気基準。発電の効率を掛けて一次エネルギー基準にすると、燃料ボイラと公平に比べられる。
計算熱のエクセルギーとエクセルギー損失
熱から取り出せる仕事の最大値は 熱量×(1−周囲温度/熱の温度)。温度差で熱が流れるだけでも失われる。
計算ウィーンの変位則と放射エネルギー
熱い物ほど短い波長の光を強く出す(最大の波長 × 絶対温度 = 一定)。
計算風力発電の出力と風速の3乗
風速が2倍になると出力は8倍。風が受ける面積にも比例する。
