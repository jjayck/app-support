課目Ⅰ報告と計画

ひとことで言うと

毎年出す通知表。使用量、原単位の推移、設備の状況、取組の内容などを書く。

練習問題

空欄 A・B・C・D に入るものを答えてください。

特定事業者は毎年度、エネルギーの使用量その他の使用の状況(エネルギーの使用の A 及びエネルギーの使用に伴って発生するB に係る事項を含む)、並びにエネルギーを消費する設備などの C の状況を主務大臣に報告する。このうち B に係る事項の省令を定めるとき、経済産業大臣はあらかじめ D に協議する。
A解答群
  1. ア時間帯
  2. イ効率
  3. ウ費用
  4. エ地域
B解答群
  1. ア二酸化炭素の排出量
  2. イ排水量
  3. ウ廃棄物の量
  4. エ窒素酸化物の量
C解答群
  1. ア設置及び改廃
  2. イ減価償却
  3. ウ購入価格
  4. エ耐用年数
D解答群
  1. ア環境大臣
  2. イ国土交通大臣
  3. ウ内閣総理大臣
  4. エ厚生労働大臣
答えと解説を見る
  • Aイ 効率
  • Bア 二酸化炭素の排出量
  • Cア 設置及び改廃
  • Dア 環境大臣
ABC法16条1項:定期報告 = 使用量・使用の状況(効率とCO₂排出量を含む)+ 設備の設置及び改廃の状況。
D法16条2項:CO₂ に係る部分の省令は環境大臣に協議。
期限は毎年度7月末日(規則)。

「報告と計画」のイメージ

指定された事業者が毎年国に出す「通知表」と「今後の計画」。

報告と計画の要点と全論点を見る ›

同じ分野の論点

届出・計画・報告の期限
使用量の届出と、毎年の定期報告・中長期計画にはそれぞれ提出期限がある。いつ・何を出すかをセットで覚える。
指導助言・合理化計画の指示と命令
国の対応は段階的に強くなる:指導・助言 → 合理化計画の指示 → 公表 → 命令。
非化石転換の中長期計画と勧告
非化石エネルギーへの転換も中長期計画を出す。取組が不十分だと国が勧告する。
報告徴収と立入検査
国は必要に応じて報告を求めたり、工場に立ち入って検査したりできる。
