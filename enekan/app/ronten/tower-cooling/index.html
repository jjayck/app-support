開放式冷却塔と冷却水の管理

課目Ⅳ熱交換器

ひとことで言うと

水の一部が蒸発して残りを冷やす。蒸発で濃くなった水は一部を捨てて(ブロー)入れ替える。

練習問題

空欄 A・B・C に入るものを答えてください。

開放式冷却塔は、循環水の一部が A するときの潜熱で水を冷やす。冷却できる水温の下限の目安は、外気の B である。循環水は蒸発によって濃縮し、スケールや腐食の原因になるので、一部を排出して補給水と入れ替える C を行う。

  1. ア凍結
  2. イ蒸発
  3. ウ凝縮
  4. エ沸騰
B解答群
  1. ア露点温度
  2. イ乾球温度
  3. ウ平均気温
  4. エ湿球温度
C解答群
  1. アドレン抜き
  2. イ逆洗
  3. ウブロー
  4. エパージ
答えと解説を見る
  • Aイ 蒸発
  • Bエ 湿球温度
  • Cウ ブロー
A開放式冷却塔:循環水の一部が蒸発し、その蒸発潜熱で残りの水が冷える。
B冷却塔の出口水温 − 湿球温度 = アプローチ、入口水温 − 出口水温 = レンジ。
C濃縮倍数 = 循環水の濃度/補給水の濃度。ブローを減らすと水は節約できるが濃縮が進むので、薬注と組み合わせて管理する。
密閉式冷却塔は管内の冷却水が外気に触れないので水質が悪化しにくいが、同じ能力なら大きく、送風動力も増えやすい。

「熱交換器」のイメージ

熱い流体から冷たい流体へ、混ぜずに熱だけを渡す装置。

同じ分野の論点

汚れ係数と多管式熱交換器の形式
汚れがたまると熱抵抗が増える。多管式は胴の中に多数の管を通した形で、構造によって掃除のしやすさが違う。
フィン付き伝熱面とフィン効率
熱が伝わりにくい側にひれ(フィン)を付けて面積を増やす。フィンの先ほど温度が下がるので効率は100%未満。
ドレン回収管の二相流・化学洗浄・熱容量流量
回収管の中は水と蒸気が混ざって流れる。熱容量流量=質量流量 × 比熱で、温度の変わりやすさを決める。
計算熱交換器の温度効率と出口温度
温度効率=実際に変わった温度 ÷ 変えられる最大の温度差。ここから出口温度を出す。
計算対数平均温度差と伝熱面積
入口と出口で温度差が違うので、平均の温度差を対数で出す。熱量 = 熱通過率 × 面積 × 対数平均温度差。
