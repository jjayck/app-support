排ガスCO₂濃度から空気比

課目Ⅲ燃焼計算計算

ひとことで言うと

空気を多く入れるほど排ガスが薄まり、CO₂の割合は下がる。その下がり方から空気比が分かる。

練習問題

空欄 A・B・C に入るものを答えてください。

質量組成が 炭素 85.0 %、水素 12.5 %、硫黄 1.5 %、酸素 1.0 % の重油を燃焼させ、乾き燃焼ガス中の CO₂ を測定したところ 12.5 % であった。完全燃焼とすると、理論空気量で燃焼させたときの乾き燃焼ガス中の CO₂ 濃度(CO₂max)は A % で、空気比は B である。CO₂ 濃度が CO₂max より低いほど C。原子量は C = 12、H = 1、O = 16、N = 14、S = 32、気体 1 kmol の体積は 22.4 m³N、空気中の酸素は体積で 21 % とする。
A数値(3桁・□□.□)%
B数値(3桁・□.□□)
C解答群
  1. ア燃焼温度が上がる
  2. イ空気比が大きくなる
  3. ウ空気比が小さくなる
  4. エ燃料の水素が増える
答えとやさしい解き方を見る
  • A15.5 %
  • B1.23
  • Cイ 空気比が大きくなる

数値の答えは本番と同じ「桁ごとのマーク」です。桁が余るときは先頭に 0 を入れます。

何を聞かれている?
排ガス中の CO₂ の濃度を測った値から、どれだけ空気を多めに送っているか(空気比)を逆算する問題。あわせて、空気がちょうどのときの CO₂ 濃度(CO₂max)も出す。

記号と単位

  • O₀・A₀ … 理論酸素量・理論空気量(燃料 1 kg あたり m³N)
  • G₀d … 理論空気で燃やしたときの乾き燃焼ガス量(水蒸気を除いたガス)
  • CO₂max … 空気がちょうどのときの乾きガス中の CO₂ 濃度。これより高くはならない
  • m … 空気比

解き方

1
いつもの公式で、燃料 1 kg に要る酸素と空気の量を出す。空気の量は酸素を 0.21 で割る。
O₀ = 22.4 × (C/12 + H/4 + S/32 − O/32) = 2.2902、A₀ = O₀/0.21 = 10.9056 m³N/kg
2
燃えてできる CO₂ と SO₂ の量を出す。炭素 C/12 kmol、硫黄 S/32 kmol がそのまま同じ数の CO₂・SO₂ になり、22.4 を掛けて体積にする。
CO₂ = 22.4 × 0.85/12 = 1.5867、SO₂ = 22.4 × 0.015/32 = 0.0105
3
乾きガスは水蒸気を除いたガス。理論空気のときは CO₂ と SO₂ に、空気の窒素(A₀ の 79 %)を足したものになる。
理論乾きガス G₀d = CO₂ + SO₂ + 0.79A₀ = 10.2126 m³N/kg(水分 H₂O は乾きガスに入れない)
4
CO₂ の量を乾きガス全体で割ると濃度になる。空気がちょうどのときガスが一番少ないので、この濃度が最大値 CO₂max。
CO₂max = 1.5867/10.2126 = 15.536 → 15.5 %
5
空気を m 倍にすると、余分な空気 (m − 1) × A₀ がそのまま乾きガスに加わる。一方、CO₂ の量は燃料で決まるので変わらない。
空気比 m の乾きガスは G₀d + (m − 1)A₀。CO₂ の量は変わらないので
6
「CO₂ の量 ÷ 乾きガス = 測った濃度」という式を立て、m について解く。CO₂ の量を濃度で割ると乾きガスの量になり、そこから G₀d を引いた残りが余分な空気なので、A₀ で割って 1 を足す。
1.5867 / (G₀d + (m − 1)A₀) = 0.125 → m = 1 + (1.5867/0.125 − 10.2126)/10.9056 = 1.2275 → 1.23
7
CO₂max を測った CO₂ で割る簡易式でも近い値が出る。ただし答えは前の行の正確な式で出す。
(簡易式 m ≒ CO₂max/CO₂ = 1.243 は近い値になるが、正確には上の式で解く)
つまずきやすいところ
乾きガスに H₂O を入れてしまう/簡易式の値を答えにしてしまう。

「燃焼計算」のイメージ

燃料の成分から、必要な空気と出てくる排ガスの量を計算する分野。

燃焼計算の要点と全論点を見る ›

同じ分野の論点

計算液体燃料(重油)の理論空気量と燃焼ガス量
重油は質量で C・H・S の割合が与えられる。kgをkmolに直し、22.4 m³N/kmol を掛けて体積にする。
計算固体燃料の燃焼ガス量と低発熱量
石炭も重油と同じ手順。低発熱量は、燃焼でできた水と燃料の水分が蒸発する熱を差し引いたもの。
計算空気予熱器の回収熱と予熱空気温度
排ガスが失った熱 = 空気が得た熱。ここから予熱した空気の温度を出す。
計算燃料転換とH/C比によるCO₂削減
水素の割合が多い燃料ほど、同じ熱を出すのに出すCO₂が少ない。石炭 → 重油 → 天然ガスの順に少なくなる。
計算分子式の燃料(酸素を含む)の燃焼計算
燃料自身が酸素を含むと、その分だけ外から入れる酸素が少なくて済む。
計算水素混焼の熱量比・質量比とCO₂削減
水素はCO₂を出さないので、混ぜた熱量の割合だけCO₂が減る。ただし体積あたりの熱量は小さい。
計算バイオマス混焼の質量比とCO₂削減
バイオマスの燃焼で出るCO₂は数えない扱いなので、置き換えた熱量の分だけCO₂が減る。
計算不完全燃焼の排ガスから空気比(窒素基準)
排ガスにCOが残るときは、窒素の量を基準にして、入れた空気と必要な空気を比べる。
計算気体燃料の燃焼ガス量
気体は体積の比がそのまま反応の比。CH₄ 1 m³N には O₂ 2 m³N が要り、CO₂ 1 と H₂O 2 ができる。
