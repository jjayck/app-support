液体燃料(重油)の理論空気量と燃焼ガス量

課目Ⅲ燃焼計算計算

ひとことで言うと

重油は質量で C・H・S の割合が与えられる。kgをkmolに直し、22.4 m³N/kmol を掛けて体積にする。

練習問題

空欄 A・B・C に入るものを答えてください。

質量組成が 炭素 87.0 %、水素 11.0 %、硫黄 1.0 %、酸素 1.0 % の重油を、空気比 1.2 で完全燃焼させる。燃料 1 kg あたりの理論酸素量は A m³N、理論空気量は B m³N、湿り燃焼ガス量は C m³N である。原子量は C = 12、H = 1、O = 16、N = 14、S = 32、気体 1 kmol の体積は 22.4 m³N、空気中の酸素は体積で 21 % とする。
A数値(3桁・□.□□)m³N/kg
B数値(3桁・□□.□)m³N/kg
C数値(3桁・□□.□)m³N/kg
答えとやさしい解き方を見る
  • A2.24 m³N/kg
  • B10.7 m³N/kg
  • C13.4 m³N/kg

数値の答えは本番と同じ「桁ごとのマーク」です。桁が余るときは先頭に 0 を入れます。

何を聞かれている?
重油 1 kg を燃やすのに要る酸素と空気の量、そして燃えたあとに出てくるガスの量(湿り燃焼ガス量)を、燃料の成分の割合から出す問題。

記号と単位

  • C・H・S・O … 燃料 1 kg 中の炭素・水素・硫黄・酸素の質量の割合(87 % なら 0.87)
  • O₀ … 理論酸素量。ちょうど燃え切るのに要る酸素の量
  • A₀ … 理論空気量。O₀ を空気で送るときの空気の量
  • m … 空気比。理論空気量の何倍の空気を送るか
  • m³N … 0 ℃・1 気圧にそろえた気体の体積。気体 1 kmol = 22.4 m³N

解き方

1
まず考え方。質量の割合を原子量で割ると、燃料 1 kg に何 kmol 入っているかがわかる。反応式から、炭素と硫黄は 1 kmol につき O₂ 1 kmol、水素(H₂)は 1 kmol につき O₂ ½ kmol を使う。
燃料 1 kg 中のモル数(kmol)= 質量割合 ÷ 原子量。燃える成分ごとに必要な O₂:C + O₂ → CO₂、H₂ + ½O₂ → H₂O、S + O₂ → SO₂。
2
炭素は C/12 kmol で同じ数の O₂ が要る。水素は原子が H/1 kmol あり、H₂ にすると半分、O₂ はさらにその半分なので H/4。硫黄は S/32。燃料の中の酸素は O₂ として O/32 kmol ぶんを引く。合計の kmol に 22.4 を掛けて体積にする。
O₀ = 22.4 × (C/12 + H/4 + S/32 − O/32)
3
上の式に、問題の成分の割合(% を小数にしたもの)を入れて計算する。
= 22.4 × (0.87/12 + 0.11/4 + 0.01/32 − 0.01/32) = 2.2400 → 2.24 m³N/kg
4
燃料の中にもともと酸素が入っていれば、そのぶんは外から送らなくてよい。だから O/32 を引く。
(燃料中の酸素 O はすでに燃焼に使える酸素なので差し引く)
5
空気のうち酸素は 21 % しかない。必要な酸素を 0.21 で割ると、それを含む空気の量になる。
A₀ = O₀/0.21 = 10.667 → 10.7 m³N/kg
6
燃えたあとのガスを中身ごとに足す。CO₂ と SO₂ は使った O₂ と同じ量、H₂O は水素から H/2 kmol、N₂ は送った空気(m × A₀)の 79 %、余った O₂ は余分に送った空気 (m − 1) × A₀ の 21 %。
湿りガス = CO₂ 1.6240 + SO₂ 0.0070 + H₂O(22.4 × H/2)1.2320 + N₂(0.79mA₀)10.112 + 過剰O₂(0.21(m−1)A₀)0.448
7
前の行の5つを足し合わせて、問題の桁に丸める。
= 13.423 → 13.4 m³N/kg
8
検算用の近道。送った空気 mA₀ に、水素で増えるぶん(O₂ 1 に対して H₂O 2 になるので H/4 ぶん増える)と燃料の酸素 O/32 ぶんを足すと、同じ答えになる。
検算の近道:G = mA₀ + 22.4 × (H/4 + O/32)(水素は O₂ 1 に対して H₂O 2 になるので体積が増える)。
つまずきやすいところ
水素を H/2 や H/12 にしてしまう(O₂ は H/4、できる H₂O は H/2)/燃料中の酸素 O/32 を引き忘れる。

「燃焼計算」のイメージ

燃料の成分から、必要な空気と出てくる排ガスの量を計算する分野。

燃焼計算の要点と全論点を見る ›

同じ分野の論点

計算固体燃料の燃焼ガス量と低発熱量
石炭も重油と同じ手順。低発熱量は、燃焼でできた水と燃料の水分が蒸発する熱を差し引いたもの。
計算排ガスCO₂濃度から空気比
空気を多く入れるほど排ガスが薄まり、CO₂の割合は下がる。その下がり方から空気比が分かる。
計算空気予熱器の回収熱と予熱空気温度
排ガスが失った熱 = 空気が得た熱。ここから予熱した空気の温度を出す。
計算燃料転換とH/C比によるCO₂削減
水素の割合が多い燃料ほど、同じ熱を出すのに出すCO₂が少ない。石炭 → 重油 → 天然ガスの順に少なくなる。
計算分子式の燃料(酸素を含む)の燃焼計算
燃料自身が酸素を含むと、その分だけ外から入れる酸素が少なくて済む。
計算水素混焼の熱量比・質量比とCO₂削減
水素はCO₂を出さないので、混ぜた熱量の割合だけCO₂が減る。ただし体積あたりの熱量は小さい。
計算バイオマス混焼の質量比とCO₂削減
バイオマスの燃焼で出るCO₂は数えない扱いなので、置き換えた熱量の分だけCO₂が減る。
計算不完全燃焼の排ガスから空気比(窒素基準)
排ガスにCOが残るときは、窒素の量を基準にして、入れた空気と必要な空気を比べる。
計算気体燃料の燃焼ガス量
気体は体積の比がそのまま反応の比。CH₄ 1 m³N には O₂ 2 m³N が要り、CO₂ 1 と H₂O 2 ができる。
