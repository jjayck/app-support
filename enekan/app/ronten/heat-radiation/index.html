黒体・灰色体とキルヒホッフの法則

課目Ⅱ伝熱工学

ひとことで言うと

黒体はすべての光を吸収し最も強く放射する物。よく吸収する物はよく放射する(吸収率=放射率)。

練習問題

空欄 A・B・C に入るものを答えてください。

入射する放射をすべて吸収する理想的な物体を A という。放射率が波長によらず一定で 1 より小さい物体を灰色体といい、温度 T の灰色体の面が単位面積あたりに出す放射エネルギーは B である。同じ温度・同じ波長では吸収率と放射率が等しいことを C の法則という。不透明な面に放射 q が入射すると、吸収率 α のとき反射されるのは (1 − α)q である。
A解答群
  1. ア白体
  2. イ透明体
  3. ウ黒体
  4. エ灰色体
B解答群
  1. アσ(εT)⁴
  2. イσT⁴/ε
  3. ウεσT²
  4. エεσT⁴
C解答群
  1. アプランク
  2. イキルヒホッフ
  3. ウフーリエ
  4. エウィーン
答えと解説を見る
  • Aウ 黒体
  • Bエ εσT⁴
  • Cイ キルヒホッフ
A黒体:吸収率 1・放射率 1。放射エネルギー E = σT⁴(σ = 5.67×10⁻⁸ W/(m²·K⁴))。
BC灰色体:E = εσT⁴。キルヒホッフの法則で α = ε。不透明な面では 吸収率 + 反射率 = 1、透過率 = 0。
面の熱収支:吸収する放射 + 対流で受ける熱 = 自分が出す放射 + 伝導で逃げる熱、のように釣り合いを立てて表面温度を求める。

「伝熱工学」のイメージ

熱がどう伝わるかを扱う分野。伝わり方は伝導・対流・放射の3つだけ。

伝熱工学の要点と全論点を見る ›

同じ分野の論点

沸騰曲線と凝縮の形態
温度差を大きくすると、核沸騰で伝熱がピークになり、それを超えると蒸気の膜ができて急に伝わりにくくなる。
対流熱伝達の無次元数
ヌセルト数=対流の強さ、レイノルズ数=流れの勢い、プラントル数=流体の性質。この組合せで熱伝達率を出す。
フーリエの法則と熱伝導率
物の中を伝わる熱は、温度差と熱伝導率に比例し、厚さに反比例する。
速度境界層と温度境界層・プール沸騰
壁の近くの、流れが遅くなる層・温度が変わる層。プール沸騰は静かな液をためて沸騰させる状態。
計算円管内の強制対流と必要管長
熱伝達率から1mあたりに渡せる熱を出し、必要な熱量を渡すのに何mの管が要るかを計算する。
計算円管の保温の熱抵抗と放熱量
円管は外側ほど面積が広がるので、熱抵抗に対数(ln)が出てくる。
計算形態係数(相反則・総和則)と黒体間の放射
一方の面から出た放射のうち、もう一方の面に届く割合が形態係数。
計算囲まれた小物体の放射と対流の放熱
大きな部屋の中の小さな物は、自分の放射率だけで放射の放熱が決まる。対流の放熱と足して合計を出す。
計算多層平板の熱通過
壁が何層あっても、各層の熱抵抗(厚さ/熱伝導率)と表面の抵抗を足せば全体の熱の通りにくさになる。
計算平行平板間の放射伝熱
向かい合う2枚の板の間の放射は、絶対温度の4乗の差と、両方の放射率で決まる。
