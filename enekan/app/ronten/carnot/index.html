カルノーサイクルの熱効率

課目Ⅱ熱力学計算

ひとことで言うと

熱機関の効率の上限。高温と低温の絶対温度だけで決まり、1 − T₂/T₁。

練習問題

空欄 A・B・C に入るものを答えてください。

温度 700 K の高温熱源と温度 310 K の低温熱源の間で作動するカルノーサイクルがある。このサイクルの理論熱効率は A % である。高温熱源から 1 サイクルあたり 650 kJ の熱を受け取るとき、得られる仕事は B kJ である。また、低温熱源へ捨てる熱量は C で表される。
A数値(3桁・□□.□)%
B数値(3桁・□□□)kJ
C解答群
  1. アQₕ·Tₗ/(Tₕ−Tₗ)
  2. イQₕ·(Tₕ−Tₗ)/Tₗ
  3. ウQₕ·Tₗ/Tₕ
  4. エQₕ·Tₕ/Tₗ
答えとやさしい解き方を見る
  • A55.7 %
  • B362 kJ
  • Cウ Qₕ·Tₗ/Tₕ

数値の答えは本番と同じ「桁ごとのマーク」です。桁が余るときは先頭に 0 を入れます。

何を聞かれている?
理想の熱機関(カルノーサイクル)が、もらった熱の何 % を仕事にできるかを出す問題。

記号と単位

  • Tₕ・Tₗ … 高温側・低温側の温度(K)
  • Qₕ … 高温側からもらう熱、W … 取り出せる仕事、Qₗ … 低温側へ捨てる熱

解き方

1
カルノーの効率は温度だけで決まる。Tₗ/Tₕ が「捨てる割合」なので、1 から引いた残りが仕事にできる割合。温度は必ず K(℃ なら 273 を足す)。
カルノー効率 η = 1 − Tₗ/Tₕ = 1 − 310/700 = 0.5571 → 55.7 %。
2
もらった熱のうち、効率の割合が仕事になる。効率は丸める前の値で掛ける。
仕事 W = η·Qₕ = 0.5571 × 650 = 362.1 → 362 kJ。
3
仕事にならなかった残りが捨てる熱。もらった熱 − 仕事。
捨てる熱 Qₗ = Qₕ − W = Qₕ·Tₗ/Tₕ(可逆サイクルでは Q/T が等しい)。
つまずきやすいところ
℃ のまま割り算する/丸めた % で掛けて答えが1ずれる。

「熱力学」のイメージ

熱と仕事がどう出入りするかを計算する分野。発電所も冷凍機もエンジンもこの考え方で動く。

熱力学の要点と全論点を見る ›

同じ分野の論点

ランキンサイクルの正味仕事と再熱・プランクの法則
タービンの仕事からポンプの仕事を引いたのが正味仕事。途中でもう一度加熱する(再熱)と出口の湿りが減る。
p-h 線図の線と冷媒の状態
縦が圧力、横がエンタルピー。山形の線の左が液、内側が湿り蒸気、右が過熱蒸気。冷凍サイクルを四角形で描ける。
計算ランキンサイクルの乾き度と熱効率
蒸気発電のモデル。タービンで膨張した後の蒸気の乾き度と、加熱量に対する仕事の割合を計算する。
計算湿り蒸気の比エンタルピーと乾き度
湿り蒸気は水と蒸気の混ざりもの。乾き度 x の割合で、飽和水と飽和蒸気の値を混ぜ合わせる。
計算絞り膨張(等エンタルピー)と乾き度
弁などで絞ると、圧力は下がるがエンタルピーは変わらない。そのため乾き度が変わる。
計算理想気体の状態方程式と体積
pV = mRT。圧力・体積・温度のうち2つが分かれば残りが出る。温度は必ずK。
計算等圧変化の仕事・内部エネルギー・エントロピー
圧力一定で加熱すると、一部は膨張の仕事に使われ、残りが内部エネルギーの増加になる。
計算定容加熱の加熱量とエントロピー変化
体積一定だと仕事をしないので、加えた熱はすべて内部エネルギー(温度上昇)になる。
計算ガス定数・比熱の関係と比熱比
定圧比熱 − 定容比熱 = ガス定数。比熱比 κ = 定圧比熱 / 定容比熱(空気は約1.4)。
計算水を飽和蒸気にする加熱量
水を沸点まで温める熱(顕熱)と、沸かして蒸気にする熱(潜熱)の合計。
計算蒸気表の読み取り(湿り蒸気)
圧力か温度から、飽和水(h')と飽和蒸気(h'')の値を表から読む。
計算蒸気表の直線補間
表にない中間の値は、前後の2行を直線でつないで比例配分で求める。
計算ディーゼルサイクルの温度・加熱量・熱効率
ディーゼルエンジンのモデル。圧縮した高温の空気に燃料を入れ、圧力一定で燃やす。
計算コンバインドサイクルの熱効率
ガスタービンで使った後の排熱で蒸気タービンも回す。2段で使うので全体の効率が上がる。
計算可逆断熱膨張の体積・温度・仕事
断熱膨張では内部エネルギーを減らして仕事をする。温度・体積は pV^κ = 一定の関係で決まる。
計算ピストンの力のつり合いと等圧加熱
ピストンにかかる力(圧力×面積と重さ)がつり合っていれば、加熱しても圧力は一定のまま。
計算可逆断熱変化の温度
熱の出入りなしで圧縮すると温度が上がり、膨張すると下がる。pV^κ = 一定。
計算オットーサイクルの熱効率
ガソリンエンジンのモデル。圧縮比が大きいほど効率が上がる。
