成績係数の一次エネルギー換算と比較

課目Ⅰエネルギー概論・単位計算

ひとことで言うと

ヒートポンプのCOPは電気基準。発電の効率を掛けて一次エネルギー基準にすると、燃料ボイラと公平に比べられる。

練習問題

空欄 A・B・C・D に入るものを答えてください。

冷凍能力 500 kW の冷房を、成績係数 4.5 の電動冷凍機と、成績係数 1.2(燃料の発熱量基準)のガス吸収冷凍機で比べる。購入電気の一次エネルギー換算を 1 kWh あたり 8.64 MJ とすると、電気の一次エネルギーから見た効率(受電端の発電効率に相当)は A %で、電動冷凍機の一次エネルギー基準の成績係数は B である。これは吸収冷凍機の C 倍にあたる。電動冷凍機が1時間に使う電気の一次エネルギーは D GJ である。
A数値(3桁・□□.□)%
B数値(3桁・□.□□)
C数値(3桁・□.□□)倍
D数値(3桁・□□.□)GJ
答えとやさしい解き方を見る
  • A41.7 %
  • B1.87
  • C1.56 倍
  • D01.0 GJ

数値の答えは本番と同じ「桁ごとのマーク」です。桁が余るときは先頭に 0 を入れます。

何を聞かれている?
電気で動く冷凍機と燃料で動く吸収冷凍機を、同じ「一次エネルギー(燃料のもとの熱)」の基準にそろえて、どちらが効率的か比べる問題。

記号と単位

  • COP(成績係数)… 使ったエネルギーの何倍の冷房ができるか
  • 一次エネルギー … 発電所で燃やす燃料など、もとのエネルギー
  • 8.64 MJ/kWh … 電気 1 kWh をつくるのに使ったとみなす一次エネルギー
  • 3.6 MJ … 電気 1 kWh を熱量に直した値

解き方

1
電気 1 kWh は熱にすると 3.6 MJ。それをつくるのに一次エネルギー 8.64 MJ を使ったとみなすので、発電の効率は 3.6 ÷ 8.64。
1 kWh = 3.6 MJ の電気をつくるのに一次エネルギー 8.64 MJ を使うとみなす → 効率 = 3.6/8.64 = 0.41667 → 41.7 %
2
電動冷凍機の COP は「電気の何倍冷やせるか」。電気は一次エネルギーの約4割しか届いていないので、COP に発電の効率を掛けると「一次エネルギーの何倍冷やせるか」になる。
一次エネルギー基準 COP = 冷凍能力/一次エネルギー = COP × 3.6/8.64 = 4.5 × 0.41667 = 1.8750 → 1.87
3
一次エネルギー基準の COP どうしで割り算して、電動冷凍機が吸収冷凍機の何倍かを出す。
吸収冷凍機との比 = 1.8750/1.2 = 1.5625 → 1.56 倍
4
消費電力は 冷凍能力 ÷ COP。1時間動かすと電力量(kWh)は同じ数になる。それに 8.64 MJ を掛けて一次エネルギーにし、1000 で割って GJ に直す。
消費電力 = 500/4.5 = 111.111 kW → 1時間で 111.111 kWh × 8.64 MJ = 0.9600 → 1.0 GJ

あわせて覚える

  • 電気で動く機器と燃料で動く機器は、同じ一次エネルギーの土俵にそろえてから比べる。
つまずきやすいところ
電動冷凍機の COP をそのまま吸収冷凍機と比べる(一次エネルギーにそろえていない)/MJ を GJ に直し忘れる。

同じ分野の論点

SI基本単位と組立単位
基本は m・kg・s・A・K・mol・cd の7つ。J(ジュール)や W(ワット)はこれらの組合せでできている。
エネルギー変換と回生・ヒートポンプ
ブレーキで捨てていたエネルギーを電気に戻すのが回生。ヒートポンプは電気で熱をくみ上げる。
蓄熱・蓄電の基礎
余っている時間にためて、足りない時間に使う。熱でためるか電気でためるかの違い。
風力の出力・粘性の温度依存・電気加熱
風力の出力は風速の3乗に比例。液体の粘性は温度が上がると下がり、気体は上がる。
熱回路と電気回路の対応
温度差=電圧、熱流=電流、熱抵抗=電気抵抗。直列の壁は抵抗の足し算で解ける。
電気の組立単位(C・V・Ω)
電荷 C = A·s、電圧 V = W/A、抵抗 Ω = V/A。基本単位までさかのぼって組み立てられる。
エネルギーの種類ごとのエクセルギー率
電気や仕事はほぼ全部が使えるエネルギー。熱は温度が低いほど使える割合(エクセルギー率)が小さい。
計算熱のエクセルギーとエクセルギー損失
熱から取り出せる仕事の最大値は 熱量×(1−周囲温度/熱の温度)。温度差で熱が流れるだけでも失われる。
計算ウィーンの変位則と放射エネルギー
熱い物ほど短い波長の光を強く出す(最大の波長 × 絶対温度 = 一定)。
計算風力発電の出力と風速の3乗
風速が2倍になると出力は8倍。風が受ける面積にも比例する。
