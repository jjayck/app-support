速度境界層と温度境界層・プール沸騰

課目Ⅱ伝熱工学

ひとことで言うと

壁の近くの、流れが遅くなる層・温度が変わる層。プール沸騰は静かな液をためて沸騰させる状態。

練習問題

空欄 A・B・C・D に入るものを答えてください。

平板に沿う流れでは、壁の近くに速度が変化する速度境界層と、温度が変化する温度境界層ができる。プラントル数 Pr = ν/a は、両者の A を決める。Pr が 1 より十分小さい液体金属では、温度境界層は速度境界層より B。静止した液体の中に置いた加熱面で起こる沸騰を C 沸騰といい、管内を流れながら起こる沸騰を D 沸騰という。
A解答群
  1. ア圧力の比
  2. イ温度の比
  3. ウ流量の比
  4. エ厚さの比
B解答群
  1. ア厚い
  2. イ薄い
  3. ウ等しい
C解答群
  1. アプール
  2. イ流動
  3. ウ膜
  4. エ核
D解答群
  1. アサブクール
  2. イ自然対流
  3. ウ流動
  4. エプール
答えと解説を見る
  • Aエ 厚さの比
  • Bア 厚い
  • Cア プール
  • Dウ 流動
BPr ≪ 1 の液体金属は熱がよく拡散するので、温度境界層は速度境界層より厚い(Pr ≫ 1 の油では逆に薄い)。
APr = 動粘度 ν / 温度伝導率 a(運動量の拡散と熱の拡散の比)。Pr ≒ 1 の気体では両境界層はほぼ同じ厚さ、Pr ≫ 1 の油では温度境界層が薄い。
境界層が薄いほど壁の近くの温度勾配が急で、熱伝達率は大きい。
CDプール沸騰:沸騰曲線(核沸騰 → 限界熱流束 → 遷移 → 膜沸騰)は主にこの条件で説明される。流動沸騰:ボイラの蒸発管など、流れの中で気泡流 → スラグ流 → 環状流と様子が変わる。

「伝熱工学」のイメージ

熱がどう伝わるかを扱う分野。伝わり方は伝導・対流・放射の3つだけ。

伝熱工学の要点と全論点を見る ›

同じ分野の論点

沸騰曲線と凝縮の形態
温度差を大きくすると、核沸騰で伝熱がピークになり、それを超えると蒸気の膜ができて急に伝わりにくくなる。
対流熱伝達の無次元数
ヌセルト数=対流の強さ、レイノルズ数=流れの勢い、プラントル数=流体の性質。この組合せで熱伝達率を出す。
フーリエの法則と熱伝導率
物の中を伝わる熱は、温度差と熱伝導率に比例し、厚さに反比例する。
黒体・灰色体とキルヒホッフの法則
黒体はすべての光を吸収し最も強く放射する物。よく吸収する物はよく放射する(吸収率=放射率)。
計算円管内の強制対流と必要管長
熱伝達率から1mあたりに渡せる熱を出し、必要な熱量を渡すのに何mの管が要るかを計算する。
計算円管の保温の熱抵抗と放熱量
円管は外側ほど面積が広がるので、熱抵抗に対数(ln)が出てくる。
計算形態係数(相反則・総和則)と黒体間の放射
一方の面から出た放射のうち、もう一方の面に届く割合が形態係数。
計算囲まれた小物体の放射と対流の放熱
大きな部屋の中の小さな物は、自分の放射率だけで放射の放熱が決まる。対流の放熱と足して合計を出す。
計算多層平板の熱通過
壁が何層あっても、各層の熱抵抗(厚さ/熱伝導率)と表面の抵抗を足せば全体の熱の通りにくさになる。
計算平行平板間の放射伝熱
向かい合う2枚の板の間の放射は、絶対温度の4乗の差と、両方の放射率で決まる。
