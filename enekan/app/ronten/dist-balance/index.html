連続精留の物質収支と還流比

課目Ⅳ乾燥・蒸留計算

ひとことで言うと

入った量 = 塔頂から出た量 + 塔底から出た量。成分ごとにも同じように成り立つ。

練習問題

空欄 A・B・C・D に入るものを答えてください。

低沸点成分のモル分率 0.6 の原料を 1000 kmol/h で連続精留塔に供給し、塔頂から低沸点成分 0.98 の留出液を、塔底から 0.1 の缶出液を取り出す。留出液量は A kmol/h、缶出液量は B kmol/h である。還流比を 3.0 とすると、塔頂から出る蒸気量は C kmol/h である。還流比を大きくすると、必要な理論段数は少なくなるが、リボイラの加熱量は D。
A数値(4桁・□□□.□)kmol/h
B数値(4桁・□□□.□)kmol/h
C数値(4桁・□□□□)kmol/h
D解答群
  1. ア少なくなる
  2. イ変わらない
  3. ウ多くなる
答えとやさしい解き方を見る
  • A568.2 kmol/h
  • B431.8 kmol/h
  • C2273 kmol/h
  • Dウ 多くなる

数値の答えは本番と同じ「桁ごとのマーク」です。桁が余るときは先頭に 0 を入れます。

何を聞かれている?
蒸留塔に入る原料と、塔頂・塔底から出る量の収支から、それぞれの量と塔頂の蒸気量を出す問題。

記号と単位

  • F … 原料の量、D … 塔頂の留出液、W … 塔底の缶出液(kmol/h)
  • zF・xD・xW … それぞれの低沸点成分のモル分率
  • R … 還流比、L … 塔へもどす液(還流)の量、V … 塔頂から出る蒸気の量

解き方

1
入った量 = 出た量 を2本立てる。1本は全体の量、もう1本は低沸点成分だけの量(量 × 割合)。
全量の収支 F = D + W、低沸点成分の収支 F·zF = D·xD + W·xW
2
2本の式から W を消して D について解くと、この形になる。数字を入れて D を出す。
→ D = F(zF − xW)/(xD − xW) = 1000 × (0.6 − 0.1)/(0.98 − 0.1) = 568.182 → 568.2 kmol/h
3
全体の収支 F = D + W から、W = F − D。
W = 1000 − 568.182 = 431.818 → 431.8 kmol/h
4
還流比 R = L/D なので、L = R × D。塔頂の蒸気は、もどす液 L と取り出す D に分かれるので、V = L + D。
還流比 R = L/D → L = 3.0 × 568.182 = 1704.545、塔頂の蒸気 V = L + D = 2272.727 → 2273 kmol/h

あわせて覚える

  • V が増えるほど、それを蒸発させるリボイラの熱(と凝縮器の冷却)が増える。最小還流比の 1.2〜2 倍程度で運転するのが経済的。
つまずきやすいところ
分母を (xD − xW) でなく (zF − xW) にしてしまう/V を L だけにして D を足し忘れる。

「乾燥・蒸留」のイメージ

熱を使って水分を飛ばす(乾燥)、沸点の違いで液体を分ける(蒸留)、濃くする(蒸発濃縮)工程。

乾燥・蒸留の要点と全論点を見る ›

同じ分野の論点

蒸留塔の還流比と気液平衡
塔の上から出た液の一部を戻す割合が還流比。多く戻すほど分離はよくなるが、熱がたくさん要る。
蒸発濃縮の沸点上昇と省エネ蒸発法
溶けている物があると沸点が上がる。蒸気を何度も使い回す(多重効用・再圧縮)と少ない熱で済む。
石炭・バイオマスのガス化反応
石炭などを酸素や水蒸気と反応させて、CO・H₂などの燃えるガスに変える。
乾燥特性曲線と含水率の区分
乾燥は 予熱 → 恒率(表面の水が一定の速さで蒸発) → 減率(中の水がゆっくり出てくる) の順に進む。
気液平衡・単蒸留・充てん塔と棚段塔
沸点の低い成分ほど蒸気側に多く移る。塔の中身は、充てん物を詰める型と棚(トレイ)を重ねる型がある。
乾燥機の受熱方式と乾燥の省エネ
熱い空気を当てる(対流)、熱い面に触れさせる(伝導)、赤外線などで温める(放射)の3つの受け取り方。
計算含水率と蒸発水量
乾量基準=乾いた物に対する水の割合、湿量基準=全体に対する水の割合。基準の違いに注意して蒸発量を出す。
