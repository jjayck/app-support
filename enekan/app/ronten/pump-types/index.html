ターボポンプの形式・比速度・特性

課目Ⅱ流体工学

ひとことで言うと

羽根車で水に勢いをつけるポンプ。比速度で遠心・斜流・軸流の向き不向きが分かる。

練習問題

空欄 A・B・C に入るものを答えてください。

ターボポンプのうち、高い揚程で比較的少ない流量に向くのは A ポンプで、大きな流量で低い揚程に向くのは軸流ポンプである。形が相似なポンプは、大きさによらず B が等しい。軸流ポンプは、吐出し弁を閉じて流量を 0 にしたときの軸動力が C。
A解答群
  1. ア往復
  2. イ斜流
  3. ウ遠心(渦巻)
  4. エ軸流
B解答群
  1. ア軸動力
  2. イ比速度
  3. ウ効率
  4. エ揚程
C解答群
  1. ア最小になる
  2. イ0 になる
  3. ウ最大になる
答えと解説を見る
  • Aウ 遠心(渦巻)
  • Bイ 比速度
  • Cウ 最大になる
AB比速度 Ns = N√Q / H3/4:遠心(小)→ 斜流 → 軸流(大)。比速度でポンプの形式が決まる。
遠心ポンプは流量が増えると軸動力も増えるので、締め切り(流量 0)で起動する。
C軸流ポンプは締め切りで軸動力が最大になるので、弁を開けて起動する。小流量では羽根が失速して特性が不安定になる。

「流体工学」のイメージ

水や空気が管の中をどう流れ、どれだけエネルギーを失うかを扱う分野。

流体工学の要点と全論点を見る ›

同じ分野の論点

ポンプ・送風機の運転障害
キャビテーション=圧力が下がって泡ができる。サージング=小流量で圧力と流量が周期的に揺れる。
送風機の分類・無次元特性・斜流ポンプ
圧力の高さで、ファンとブロワに分かれる。羽根の形で特性が変わる。
計算管路損失とポンプの軸動力
ポンプは高さの差と管の損失の分だけ水を持ち上げる。軸動力 = ρgQH ÷ 効率。
計算ベンチュリ管・マノメータと粘性係数のレイノルズ数
管を細くした所の圧力低下を液柱で測ると流速・流量が分かる。
計算タンクからの流出と管の摩擦損失
水面の高さのエネルギーが、出口の速さと管の摩擦損失に分かれる。
計算相当直径と層流の管摩擦係数
円でない管は 4×断面積/濡れ縁長さ で直径に置き換える。層流なら管摩擦係数は 64/Re。
計算ブラジウスの式と乱流の摩擦損失
なめらかな管の乱流では、管摩擦係数をブラジウスの式(Reの1/4乗に反比例)で求める。
計算加圧タンクの小孔からの流出
タンク内の圧力と水位の両方が、小さな穴から噴き出す速さになる(流速 = √(2×押す力のヘッド×g))。
計算高さの違う2点のベルヌーイの式
高い所へ上がった分、圧力か速度のエネルギーが減る。位置のエネルギーも含めて合計を一定にする。
計算連続の式とベルヌーイの定理
流量は管のどこでも同じ(連続の式)。流れのエネルギー(圧力+速度+高さ)の合計も一定(ベルヌーイ)。
計算レイノルズ数と流れの判定
流れの勢いと粘りの比。円管では約2300より小さいと層流、大きいと乱流。
