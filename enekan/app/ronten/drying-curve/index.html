乾燥特性曲線と含水率の区分

課目Ⅳ乾燥・蒸留

ひとことで言うと

乾燥は 予熱 → 恒率(表面の水が一定の速さで蒸発) → 減率(中の水がゆっくり出てくる) の順に進む。

練習問題

空欄 A・B・C に入るものを答えてください。

材料を一定条件の熱風で乾燥すると、材料予熱期間のあと、表面が自由水でぬれていて乾燥速度が一定の A 期間になる。このとき材料の表面温度は熱風の B にほぼ等しい。乾燥速度が下がり始めるときの含水率を C 含水率という。
A解答群
  1. ア恒温
  2. イ減率乾燥
  3. ウ予熱
  4. エ定率乾燥
B解答群
  1. ア露点温度
  2. イ乾球温度
  3. ウ沸点
  4. エ湿球温度
C解答群
  1. ア臨界
  2. イ平衡
  3. ウ限界
  4. エ自由
答えと解説を見る
  • Aエ 定率乾燥
  • Bエ 湿球温度
  • Cウ 限界
A材料予熱期間 → 定率(恒率)乾燥期間:表面が水でぬれていて、乾燥速度は一定。
B定率乾燥期間の材料の表面温度は、熱風の湿球温度にほぼ等しい。
C乾燥速度が下がり始めるときの含水率を限界含水率という(そこから減率乾燥期間)。
減率乾燥期間:材料内部から表面への水分移動が追いつかず、乾燥速度が下がり、材料温度が上がる。
平衡含水率:その熱風条件ではこれ以上乾かない含水率。自由含水率 = 含水率 − 平衡含水率(乾燥で除ける分)。
蒸発操作では、溶液の沸点と同じ圧力の水の沸点がほぼ直線関係になることを使うデューリング線図で沸点上昇を読む。

「乾燥・蒸留」のイメージ

熱を使って水分を飛ばす(乾燥)、沸点の違いで液体を分ける(蒸留)、濃くする(蒸発濃縮)工程。

乾燥・蒸留の要点と全論点を見る ›

同じ分野の論点

蒸留塔の還流比と気液平衡
塔の上から出た液の一部を戻す割合が還流比。多く戻すほど分離はよくなるが、熱がたくさん要る。
蒸発濃縮の沸点上昇と省エネ蒸発法
溶けている物があると沸点が上がる。蒸気を何度も使い回す(多重効用・再圧縮)と少ない熱で済む。
石炭・バイオマスのガス化反応
石炭などを酸素や水蒸気と反応させて、CO・H₂などの燃えるガスに変える。
気液平衡・単蒸留・充てん塔と棚段塔
沸点の低い成分ほど蒸気側に多く移る。塔の中身は、充てん物を詰める型と棚(トレイ)を重ねる型がある。
乾燥機の受熱方式と乾燥の省エネ
熱い空気を当てる(対流)、熱い面に触れさせる(伝導)、赤外線などで温める(放射)の3つの受け取り方。
計算含水率と蒸発水量
乾量基準=乾いた物に対する水の割合、湿量基準=全体に対する水の割合。基準の違いに注意して蒸発量を出す。
計算連続精留の物質収支と還流比
入った量 = 塔頂から出た量 + 塔底から出た量。成分ごとにも同じように成り立つ。
