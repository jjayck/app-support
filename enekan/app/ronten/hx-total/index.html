全熱交換器の型と顕熱交換器

課目Ⅳ冷凍・空調

ひとことで言うと

換気で捨てる空気と取り入れる外気の間で、温度と湿気の両方をやり取りするのが全熱交換器。

練習問題

空欄 A・B・C・D に入るものを答えてください。

換気のとき、排気と取り入れる外気の間で、温度(顕熱)と湿度(潜熱)を同時に交換するのが A である。吸湿性のある素材のロータを回して交換する B 形と、仕切り板を通して交換する C 形がある。温度だけを交換するものは D 交換器という。
A解答群
  1. ア蒸発器
  2. イ全熱交換器
  3. ウ冷却塔
  4. エ顕熱交換器
B解答群
  1. ア回転
  2. イ静止
  3. ウプレート
  4. エ二重管
C解答群
  1. ア回転
  2. イ直接接触
  3. ウ蓄熱
  4. エ静止
D解答群
  1. ア顕熱
  2. イ直接
  3. ウ全熱
  4. エ潜熱
答えと解説を見る
  • Aイ 全熱交換器
  • Bア 回転
  • Cエ 静止
  • Dア 顕熱
D温度(顕熱)だけを交換するものは顕熱交換器。湿気(潜熱)も交換するものが全熱交換器。
ABC全熱交換器は外気負荷を大きく減らせる。回転形は効率が高いが、排気が給気側に少し移る(漏れ)ことがある。静止形は仕切り板(特殊加工紙など)を水分が透過する。
外気冷房ができる中間期は、全熱交換器を止めて(バイパスして)外気をそのまま入れる。

「冷凍・空調」のイメージ

冷媒が「蒸発して熱を奪い、外で凝縮して熱を捨てる」を繰り返して、熱を低い所から高い所へ運ぶ。

冷凍・空調の要点と全論点を見る ›

同じ分野の論点

冷凍サイクルと空調の用語
冷媒は 圧縮機 → 凝縮器 → 膨張弁 → 蒸発器 の順に回る。空調では顕熱と潜熱を分けて考える。
空調負荷と外気の利用
外が涼しいときは外気をそのまま入れて冷房の負荷を減らす(外気冷房)。
計算外気と還気の混合と冷却負荷
混ぜた空気の温度・湿度は量に比例して平均される。そこから冷やす熱量を出す。
計算相対湿度・絶対湿度・飽和度
絶対湿度=乾いた空気1kgあたりの水蒸気量。相対湿度=その温度で含める最大量に対する割合。
計算冷凍機とヒートポンプの成績係数
同じ機械でも、冷やす側の熱を見るのが冷凍、温める側を見るのがヒートポンプ。ヒートポンプのCOPは冷凍のCOP+1。
