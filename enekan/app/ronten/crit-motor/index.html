電動力応用設備の管理

課目Ⅰ判断基準

ひとことで言うと

モータで動かすポンプ・ファンなどは、負荷に合わせて台数や回転数を調整し、ムダな運転をしない。

練習問題

空欄 A・B・C に入るものを答えてください。

電動力応用設備は、電動機の A による損失を低減するよう、始動電力量との関係を考えて不要時に停止する。複数の電動機は部分負荷の効率を考え、B の調整と負荷の適正配分を行う。ポンプ・ファンなどの流体機械は、使用端圧力と吐出量を見直し、回転数の変更などで負荷を減らす。負荷変動幅が定常的な場合は、配管の変更や C などの対策を行う。
A解答群
  1. ア絶縁劣化
  2. イ過熱
  3. ウ振動
  4. エ空転
B解答群
  1. ア稼働台数
  2. イ定格出力
  3. ウ周波数
  4. エ電源電圧
C解答群
  1. アバイパス運転
  2. イインペラーカット
  3. ウ電動機の大型化
  4. エバルブ絞り
答えと解説を見る
  • Aエ 空転
  • Bア 稼働台数
  • Cイ インペラーカット
AB判断基準 Ⅰ―２ (6) ①:空転の防止、台数制御と負荷配分、流体機械の回転数制御。
C流量を常に絞って使うなら、バルブで絞るよりインペラーカットで羽根車を小さくする方が軸動力が減る(相似則:動力 ∝ 回転数³・径⁵)。

「判断基準」のイメージ

国が示す「省エネの模範解答」。事業者はこれを基準に取り組む。

判断基準の要点と全論点を見る ›

同じ分野の論点

工場等の判断基準の6項目
燃焼・伝熱・廃熱回収・熱の動力変換・損失防止・電気の変換の6つ。熱の流れの順に並んでいる。
努力目標と非化石転換
原単位1%低減に加えて、使うエネルギーを非化石に切り替えていく努力も求められる。
全ての事業者が取り組むべき事項
規模に関係なくやるべきこと:取組方針を決め、体制を整え、資金・人材を確保し、状況を把握する。
管理標準と4つの措置
管理標準=社内マニュアル。設備ごとに「運転管理・計測記録・保守点検・新設時の措置」を決める。
受電端力率の基準と目標
受電端の力率を高く保つ(コンデンサで改善)。力率が低いと同じ仕事でも電流が増え、損失が増える。
目標と計画的な取組
エネルギー消費原単位を中長期的にみて年平均1%以上下げることを目標に、計画的に取り組む。
熱利用設備・廃熱回収の新設時の措置
新しく設備を入れるときは、熱を使う設備を分散して配置するなど、最初から熱のムダが出ない設計にする。
受変電・配電と電気加熱の損失防止
変圧器は使う場所の近くに置き配電線路を短く、電気加熱は接触部分の抵抗損失を減らす。
照明・空調の目標及び措置(タスク・アンビエント等)
照明は手元(タスク)と周囲(アンビエント)を分けて必要な所だけ明るく。空調も必要な範囲・温度に絞る。
廃熱の回収利用の基準とFEMS
捨てる熱の顕熱・潜熱を回収できる範囲で回収する。FEMSで工場全体のエネルギーを見える化・制御する。
事務所の空気調和・換気の管理
事務所の空調は、区画ごとに温度・湿度・換気量の基準を決め、ムダな冷やしすぎ・暖めすぎを防ぐ。
