可逆断熱変化の温度

課目Ⅱ熱力学計算

ひとことで言うと

熱の出入りなしで圧縮すると温度が上がり、膨張すると下がる。pVκ = 一定。

練習問題

空欄 A・B に入るものを答えてください。

比熱比 κ = 1.4 の理想気体を、温度 300 K から圧力比 5 で可逆断熱圧縮する。圧縮後の温度は A K である。可逆断熱変化では B が一定に保たれる。ただし 50.4/1.4 = 1.5838 とする。
A数値(3桁・□□□)K
B解答群
  1. アエンタルピー
  2. イ温度
  3. ウ内部エネルギー
  4. エエントロピー
答えとやさしい解き方を見る
  • A475 K
  • Bエ エントロピー

数値の答えは本番と同じ「桁ごとのマーク」です。桁が余るときは先頭に 0 を入れます。

何を聞かれている?
気体を熱の出入りなしに(可逆断熱で)圧縮したとき、何 K になるかを求める問題。

記号と単位

  • T1・T2 … 圧縮前・後の温度(K)、p2/p1 … 圧力比(何倍に圧縮したか)
  • κ(比熱比)… 空気などは 1.4

解き方

1
可逆断熱変化では、温度の比は圧力比の (κ−1)/κ 乗になる。この関係を使う。
可逆断熱変化:T2/T1 = (p2/p1)(κ−1)/κ。
2
圧縮前の温度に、問題文に書いてある累乗の値を掛けるだけ。答えは整数なので四捨五入。
T2 = 300 × 50.4/1.4 = 300 × 1.5838(問題文の値)= 475.14 → 475 K。

あわせて覚える

  • 可逆断熱 = 等エントロピー変化。
つまずきやすいところ
指数を (κ−1)/κ でなく κ−1 や 1/κ にしてしまう/℃ で与えられたときに 273 を足し忘れる。

「熱力学」のイメージ

熱と仕事がどう出入りするかを計算する分野。発電所も冷凍機もエンジンもこの考え方で動く。

熱力学の要点と全論点を見る ›

同じ分野の論点

ランキンサイクルの正味仕事と再熱・プランクの法則
タービンの仕事からポンプの仕事を引いたのが正味仕事。途中でもう一度加熱する(再熱)と出口の湿りが減る。
p-h 線図の線と冷媒の状態
縦が圧力、横がエンタルピー。山形の線の左が液、内側が湿り蒸気、右が過熱蒸気。冷凍サイクルを四角形で描ける。
計算ランキンサイクルの乾き度と熱効率
蒸気発電のモデル。タービンで膨張した後の蒸気の乾き度と、加熱量に対する仕事の割合を計算する。
計算湿り蒸気の比エンタルピーと乾き度
湿り蒸気は水と蒸気の混ざりもの。乾き度 x の割合で、飽和水と飽和蒸気の値を混ぜ合わせる。
計算絞り膨張(等エンタルピー)と乾き度
弁などで絞ると、圧力は下がるがエンタルピーは変わらない。そのため乾き度が変わる。
計算理想気体の状態方程式と体積
pV = mRT。圧力・体積・温度のうち2つが分かれば残りが出る。温度は必ずK。
計算等圧変化の仕事・内部エネルギー・エントロピー
圧力一定で加熱すると、一部は膨張の仕事に使われ、残りが内部エネルギーの増加になる。
計算定容加熱の加熱量とエントロピー変化
体積一定だと仕事をしないので、加えた熱はすべて内部エネルギー(温度上昇)になる。
計算ガス定数・比熱の関係と比熱比
定圧比熱 − 定容比熱 = ガス定数。比熱比 κ = 定圧比熱 / 定容比熱(空気は約1.4)。
計算水を飽和蒸気にする加熱量
水を沸点まで温める熱(顕熱)と、沸かして蒸気にする熱(潜熱)の合計。
計算蒸気表の読み取り(湿り蒸気)
圧力か温度から、飽和水(h')と飽和蒸気(h'')の値を表から読む。
計算蒸気表の直線補間
表にない中間の値は、前後の2行を直線でつないで比例配分で求める。
計算ディーゼルサイクルの温度・加熱量・熱効率
ディーゼルエンジンのモデル。圧縮した高温の空気に燃料を入れ、圧力一定で燃やす。
計算コンバインドサイクルの熱効率
ガスタービンで使った後の排熱で蒸気タービンも回す。2段で使うので全体の効率が上がる。
計算可逆断熱膨張の体積・温度・仕事
断熱膨張では内部エネルギーを減らして仕事をする。温度・体積は pV^κ = 一定の関係で決まる。
計算ピストンの力のつり合いと等圧加熱
ピストンにかかる力(圧力×面積と重さ)がつり合っていれば、加熱しても圧力は一定のまま。
計算カルノーサイクルの熱効率
熱機関の効率の上限。高温と低温の絶対温度だけで決まり、1 − T₂/T₁。
計算オットーサイクルの熱効率
ガソリンエンジンのモデル。圧縮比が大きいほど効率が上がる。
