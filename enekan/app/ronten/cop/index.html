冷凍機とヒートポンプの成績係数

課目Ⅳ冷凍・空調計算

ひとことで言うと

同じ機械でも、冷やす側の熱を見るのが冷凍、温める側を見るのがヒートポンプ。ヒートポンプのCOPは冷凍のCOP+1。

練習問題

空欄 A・B・C に入るものを答えてください。

ある冷凍機が低温側から 40 kW の熱を汲み上げ、圧縮機の動力は 12 kW である。冷凍機としての成績係数は A である。同じ機械をヒートポンプとして高温側の加熱に使うと、成績係数は B となり、冷凍機の成績係数より C だけ大きい。
A数値(3桁・□.□□)
B数値(3桁・□.□□)
C解答群
  1. ア1
  2. イ0
  3. ウW
  4. エ2
答えとやさしい解き方を見る
  • A3.33
  • B4.33
  • Cア 1

数値の答えは本番と同じ「桁ごとのマーク」です。桁が余るときは先頭に 0 を入れます。

何を聞かれている?
冷凍機・ヒートポンプが、払った動力の何倍の熱を運べるか(成績係数 COP)を出す問題。

記号と単位

  • Qₗ … 低温側から汲み上げた熱(冷やした熱)
  • W … 圧縮機の動力(払った電気)
  • Qₕ … 高温側に出す熱。Qₗ と W の合計

解き方

1
冷凍機の目的は「冷やすこと」なので、成果は汲み上げた熱 Qₗ。COP = 成果 ÷ 払った動力。
冷凍機 COP(冷凍機) = Qₗ/W = 40/12 = 3.333 → 3.33。
2
ヒートポンプの目的は「温めること」。高温側には、汲み上げた熱に動力のぶんも加わって出てくる(Qₕ = Qₗ + W)。だから冷凍機の COP よりいつもちょうど 1 大きい。
高温側へ出す熱 Qₕ = Qₗ + W なので COP(HP) = Qₕ/W = COP(冷凍機) + 1 = 4.333 → 4.33。
つまずきやすいところ
ヒートポンプでも Qₗ/W を使ってしまう。「何が成果か」で割られる数(分子)を決める。

「冷凍・空調」のイメージ

冷媒が「蒸発して熱を奪い、外で凝縮して熱を捨てる」を繰り返して、熱を低い所から高い所へ運ぶ。

冷凍・空調の要点と全論点を見る ›

同じ分野の論点

冷凍サイクルと空調の用語
冷媒は 圧縮機 → 凝縮器 → 膨張弁 → 蒸発器 の順に回る。空調では顕熱と潜熱を分けて考える。
空調負荷と外気の利用
外が涼しいときは外気をそのまま入れて冷房の負荷を減らす(外気冷房)。
全熱交換器の型と顕熱交換器
換気で捨てる空気と取り入れる外気の間で、温度と湿気の両方をやり取りするのが全熱交換器。
計算外気と還気の混合と冷却負荷
混ぜた空気の温度・湿度は量に比例して平均される。そこから冷やす熱量を出す。
計算相対湿度・絶対湿度・飽和度
絶対湿度=乾いた空気1kgあたりの水蒸気量。相対湿度=その温度で含める最大量に対する割合。
