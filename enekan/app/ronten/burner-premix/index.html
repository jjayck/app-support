予混合燃焼と拡散燃焼

課目Ⅲ燃焼管理

ひとことで言うと

先に混ぜて燃やすか(予混合:短く高温の炎・逆火に注意)、燃やしながら混ぜるか(拡散:長く安定した炎)。

練習問題

空欄 A・B・C に入るものを答えてください。

気体燃料と空気を燃焼前に混ぜておく A 燃焼は、火炎が短く高負荷燃焼に向くが、B の危険がある。これに対し、燃料と空気を別々に供給して混ざりながら燃える C 燃焼は、火炎が長くなるが安定している。
A解答群
  1. ア分解
  2. イ表面
  3. ウ予混合
  4. エ拡散
B解答群
  1. ア逆火
  2. イすすの多量発生
  3. ウ低温腐食
  4. エ灰の付着
C解答群
  1. ア表面
  2. イ予混合
  3. ウ拡散
  4. エ蒸発
答えと解説を見る
  • Aウ 予混合
  • Bア 逆火
  • Cウ 拡散
AB予混合燃焼:混合気の燃焼速度が流速を上回るとバーナ内へ火炎が戻る(逆火)。流速が速すぎると吹消え。
C拡散燃焼:燃料と空気が混ざる速さで燃焼が決まるので火炎は長いが、逆火の心配がなく安定。工業用バーナの多くはこちら。
火炎の色:予混合火炎はすすができにくく青い不輝炎。拡散火炎は火炎中のすすが光る輝炎で、放射伝熱が大きい。

NOxの生成と低減
