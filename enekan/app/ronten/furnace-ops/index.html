炉内の放射伝熱と炉圧・開口部の管理

課目Ⅳ工業炉・熱設備材料

ひとことで言うと

高温の炉では熱は主に放射で伝わる。炉の中は少しだけ正圧にして、冷たい外気を入れない。

練習問題

空欄 A・B・C・D に入るものを答えてください。

燃焼炉の炉内の圧力は A に保ち、開口部からの外気の侵入と炎の吹き出しを防ぐ。炉内のような高温域では、被加熱物への伝熱は主に B による。燃焼ガスのうち熱放射をよく出すのは主に C で、N₂ や O₂ はほとんど放射しない。開口部からの放射損失を減らすには D。
A解答群
  1. ア大きな負圧
  2. イ大気圧の2倍
  3. ウ真空
  4. エわずかな正圧
B解答群
  1. ア蒸発
  2. イ放射
  3. ウ対流だけ
  4. エ伝導だけ
C解答群
  1. アAr と He
  2. イH₂ と CO だけ
  3. ウN₂ と O₂
  4. エCO₂ と H₂O
D解答群
  1. ア扉を開けたまま運転する
  2. イ空気比を上げる
  3. ウ炉圧を負圧にする
  4. エ開口部を小さくし、扉を開けている時間を短くする
答えと解説を見る
  • Aエ わずかな正圧
  • Bイ 放射
  • Cエ CO₂ と H₂O
  • Dエ 開口部を小さくし、扉を開けている時間を短くする
BC放射の熱量は絶対温度の4乗に比例するので、高温の炉ほど放射が支配的になる。燃焼ガスの放射は CO₂ と H₂O の特定の波長(帯)から出る。
A炉圧が負圧だと冷たい外気が入り込み、排ガス量と排ガス損失が増える。正圧が大きすぎると炎や高温ガスが吹き出して炉体を傷める。
D開口部からの放射損失は、開口面積・炉内温度の4乗・開けている時間に比例する。

「工業炉・熱設備材料」のイメージ

物を加熱する炉と、その壁をつくる材料。

工業炉・熱設備材料の要点と全論点を見る ›

同じ分野の論点

炉壁の蓄熱損失と排熱回収
炉を止めたり動かしたりするたびに、壁を温める熱が無駄になる。排ガスの熱は燃焼空気の予熱で回収する。
耐火れんが・耐火断熱れんが・セラミックファイバの比較
重いれんがは高温に強いが熱をためやすい。軽い断熱材ほど熱を通しにくく、熱をためにくい。
連続式加熱炉の搬送方式・ヒートパターン・ベニアリング
材料を送りながら加熱する炉。どの位置で何度にするか(ヒートパターン)を決めて均一に加熱する。
セラミックファイバの組成と劣化・炉の熱精算
セラミックファイバは軽く熱容量が小さいが、高温で長く使うと縮む。熱精算=炉に入った熱と出た熱の内訳を出すこと。
計算工業炉の熱精算と炉効率
燃料の熱のうち、材料に入った割合が炉効率。残りは排ガス・炉壁・開口部などの損失で、ふつう排ガスがいちばん大きい。
計算空気予熱による燃料節約率
排ガスの熱で燃焼用の空気を温めて炉に戻すと、そのぶん燃料が少なくて済む。排ガスが熱い炉ほど効く。
計算被加熱物の熱量と燃料原単位
材料を温める熱 = 質量 × 比熱 × 温度差。それを炉効率で割ると燃料の熱になる。1 t あたりにしたのが原単位。
