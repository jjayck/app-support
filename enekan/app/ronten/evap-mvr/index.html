蒸発濃縮の沸点上昇と省エネ蒸発法

課目Ⅳ乾燥・蒸留

ひとことで言うと

溶けている物があると沸点が上がる。蒸気を何度も使い回す(多重効用・再圧縮)と少ない熱で済む。

練習問題

空欄 A・B・C に入るものを答えてください。

溶液の沸点は、同じ圧力の純溶媒より A。蒸発缶を複数つなぎ、前の缶で発生した蒸気を次の缶の加熱に使う方式を B 蒸発という。発生した蒸気を圧縮機で昇圧し、同じ缶の加熱に再利用する方式を C という。
A解答群
  1. ア変わらない
  2. イ高くなる
  3. ウ低くなる
B解答群
  1. ア多重効用
  2. イ減圧
  3. ウフラッシュ
  4. エ単効用
C解答群
  1. ア自己蒸気機械圧縮(MVR)
  2. イスチームトラップ
  3. ウ直接接触凝縮
  4. エエゼクタ
答えと解説を見る
  • Aイ 高くなる
  • Bア 多重効用
  • Cア 自己蒸気機械圧縮(MVR)
A沸点上昇:溶質が溶けていると蒸気圧が下がり、沸点が上がる。その分、加熱蒸気との温度差が小さくなる。
B多重効用:後の缶ほど圧力を下げて沸点を下げ、前の缶の蒸気で加熱する。n 重効用で加熱蒸気量はおよそ 1/n。
CMVR:蒸気の潜熱をそのまま再利用でき、電力(圧縮機)だけで蒸発できる。

「乾燥・蒸留」のイメージ

熱を使って水分を飛ばす(乾燥)、沸点の違いで液体を分ける(蒸留)、濃くする(蒸発濃縮)工程。

乾燥・蒸留の要点と全論点を見る ›

同じ分野の論点

蒸留塔の還流比と気液平衡
塔の上から出た液の一部を戻す割合が還流比。多く戻すほど分離はよくなるが、熱がたくさん要る。
石炭・バイオマスのガス化反応
石炭などを酸素や水蒸気と反応させて、CO・H₂などの燃えるガスに変える。
乾燥特性曲線と含水率の区分
乾燥は 予熱 → 恒率(表面の水が一定の速さで蒸発) → 減率(中の水がゆっくり出てくる) の順に進む。
気液平衡・単蒸留・充てん塔と棚段塔
沸点の低い成分ほど蒸気側に多く移る。塔の中身は、充てん物を詰める型と棚(トレイ)を重ねる型がある。
乾燥機の受熱方式と乾燥の省エネ
熱い空気を当てる(対流)、熱い面に触れさせる(伝導)、赤外線などで温める(放射)の3つの受け取り方。
計算含水率と蒸発水量
乾量基準=乾いた物に対する水の割合、湿量基準=全体に対する水の割合。基準の違いに注意して蒸発量を出す。
計算連続精留の物質収支と還流比
入った量 = 塔頂から出た量 + 塔底から出た量。成分ごとにも同じように成り立つ。
