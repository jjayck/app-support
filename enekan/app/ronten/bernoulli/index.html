連続の式とベルヌーイの定理

課目Ⅱ流体工学計算

ひとことで言うと

流量は管のどこでも同じ(連続の式)。流れのエネルギー(圧力+速度+高さ)の合計も一定(ベルヌーイ)。

練習問題

空欄 A・B・C に入るものを答えてください。

水平に置かれた管の内径が 200 mm から 75 mm に縮小している。太い部分の平均流速が 0.8 m/s のとき、細い部分の流速は A m/s である。損失を無視すると、太い部分と細い部分の静圧差は B kPa である(水の密度 1000 kg/m³)。流速を求める連続の式は C にもとづく。
A数値(3桁・□□.□)m/s
B数値(4桁・□□□.□)kPa
C解答群
  1. アエネルギー保存則
  2. イ運動量保存則
  3. ウ質量保存則
  4. エ角運動量保存則
答えとやさしい解き方を見る
  • A05.7 m/s
  • B015.9 kPa
  • Cウ 質量保存則

数値の答えは本番と同じ「桁ごとのマーク」です。桁が余るときは先頭に 0 を入れます。

何を聞かれている?
水平な管が途中で細くなるとき、細い部分の流速と、太い部分と細い部分の圧力の差を求める問題。

記号と単位

  • u1・u2 … 太い部分・細い部分の流速、A1・A2 … 断面積、D1・D2 … 内径
  • p1・p2 … 圧力(Pa)、ρ … 水の密度

解き方

1
1秒に流れる水の量はどこでも同じ(連続の式)。断面積は直径の2乗に比例するので、細い部分の流速は「太い部分の流速 × (太い内径 ÷ 細い内径)²」。
連続の式は、管のどの断面でも流れる質量が同じという質量保存則にもとづく。
2
管が水平なので高さの項は消え、ベルヌーイの式は「圧力の差 = ρ/2 × (速さの2乗の差)」になる。水なら ρ/2 = 500。Pa を 1000 で割って kPa。
連続の式 u1·A1 = u2·A2 → u2 = u1 (D1/D2)² = 0.8 × (0.2/0.075)² = 5.689 → 5.7 m/s。

あわせて覚える

  • ベルヌーイの式(水平)p1 − p2 = ρ/2 (u2² − u1²) = 500 × (5.689² − 0.8²) = 15862 Pa → 15.9 kPa。
つまずきやすいところ
内径の比を2乗し忘れる/速さの差を2乗してしまう(正しくは2乗してから差)。

「流体工学」のイメージ

水や空気が管の中をどう流れ、どれだけエネルギーを失うかを扱う分野。

流体工学の要点と全論点を見る ›

同じ分野の論点

ポンプ・送風機の運転障害
キャビテーション=圧力が下がって泡ができる。サージング=小流量で圧力と流量が周期的に揺れる。
ターボポンプの形式・比速度・特性
羽根車で水に勢いをつけるポンプ。比速度で遠心・斜流・軸流の向き不向きが分かる。
送風機の分類・無次元特性・斜流ポンプ
圧力の高さで、ファンとブロワに分かれる。羽根の形で特性が変わる。
計算管路損失とポンプの軸動力
ポンプは高さの差と管の損失の分だけ水を持ち上げる。軸動力 = ρgQH ÷ 効率。
計算ベンチュリ管・マノメータと粘性係数のレイノルズ数
管を細くした所の圧力低下を液柱で測ると流速・流量が分かる。
計算タンクからの流出と管の摩擦損失
水面の高さのエネルギーが、出口の速さと管の摩擦損失に分かれる。
計算相当直径と層流の管摩擦係数
円でない管は 4×断面積/濡れ縁長さ で直径に置き換える。層流なら管摩擦係数は 64/Re。
計算ブラジウスの式と乱流の摩擦損失
なめらかな管の乱流では、管摩擦係数をブラジウスの式(Reの1/4乗に反比例)で求める。
計算加圧タンクの小孔からの流出
タンク内の圧力と水位の両方が、小さな穴から噴き出す速さになる(流速 = √(2×押す力のヘッド×g))。
計算高さの違う2点のベルヌーイの式
高い所へ上がった分、圧力か速度のエネルギーが減る。位置のエネルギーも含めて合計を一定にする。
計算レイノルズ数と流れの判定
流れの勢いと粘りの比。円管では約2300より小さいと層流、大きいと乱流。
