エネルギー・電気の需要の最適化の定義

課目Ⅰ目的と定義

ひとことで言うと

電気が余る時間に多く使い、足りない時間に控えること。「量を減らす」ではなく「使う時間をずらす」がポイント。

練習問題

空欄 A・B・C に入るものを答えてください。

この法律で「エネルギー」とは、化石燃料及び A 並びに熱及び B をいう。また「電気の需要の最適化」とは、季節又は C による電気の需給の状況の変動に応じて、電気の需要量の増加又は減少をさせることをいう。
A解答群
  1. ア水素
  2. イ非化石燃料
  3. ウ再生可能エネルギー
  4. エ原子力
B解答群
  1. ア動力
  2. イ電気
  3. ウ都市ガス
  4. エ蒸気
C解答群
  1. ア電気料金
  2. イ時間帯
  3. ウ天候
  4. エ地域
答えと解説を見る
  • Aイ 非化石燃料
  • Bイ 電気
  • Cイ 時間帯
AB法2条1項:エネルギー = 化石燃料・非化石燃料・熱・電気。2023年改正で非化石燃料(水素など)が加わり、非化石を含む全エネルギーの使用の合理化が求められるようになった。
C法2条6項:電気の需要の最適化 = 季節・時間帯による需給の変動に応じて需要を増減させること(いわゆるDR)。

同じ分野の論点

法の目的
省エネ法のゴールは3つ:エネルギーの使用の合理化、非化石エネルギーへの転換、電気の需要の最適化。それで国民経済の健全な発展に役立てる。
基本方針の策定と協議
国(経済産業大臣)が省エネの大きな方針を決めて公表する。決めるときは関係する大臣と相談する。
電気需要最適化の指針
電気の需要を最適化するために事業者がとるべき行動(使う時間をずらす・蓄電する等)を国が示したもの。
