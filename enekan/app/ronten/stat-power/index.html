日本の電源構成の推移

課目Ⅰエネルギー情勢・政策

ひとことで言うと

電気を何でつくっているかの割合。化石燃料・原子力・再エネの比率が年によってどう変わったかを押さえる。

練習問題

空欄 A・B・C に入るものを答えてください。

日本の発電電力量の電源構成をみると、2023年度にシェアが最も大きい電源は A で、石炭、石油等を合わせた火力の合計はおよそ B である。東日本大震災の前の 2010年度に約 25 % を占めていた原子力は、2023年度には C まで下がった。水力を含む再生可能エネルギーの割合は 2023年度に約 23 % である。
A解答群
  1. ア石炭
  2. イ原子力
  3. ウLNG(天然ガス)
  4. エ石油等
B解答群
  1. ア5 割
  2. イ3 割
  3. ウ9 割
  4. エ7 割
C解答群
  1. ア約 20 %
  2. イ約 1 %
  3. ウ約 15 %
  4. エ約 9 %
答えと解説を見る
  • Aウ LNG(天然ガス)
  • Bエ 7 割
  • Cエ 約 9 %
出典:資源エネルギー庁「エネルギー動向(2025年版)」第14-1-6 発電電力量の推移(総合エネルギー統計)。
ABC2023年度:LNG 32.9 %、石炭 28.3 %、新エネ等 15.3 %、原子力 8.5 %、水力(揚水含む)7.6 %、石油等 7.4 %。火力の合計 68.6 %、再エネ(水力 + 新エネ等)22.9 %。
2010年度:LNG 29.0 %、石炭 27.8 %、原子力 25.1 %、石油等 8.6 %、水力 7.3 %、新エネ等 2.2 %(火力の合計 65.4 %)。
震災後は原子力の停止を LNG・石油で補い、2020年度には火力の合計が 76 % まで上がった。その後、再稼働と再エネの増加で火力の割合は下がっている。
火力の燃料別では LNG > 石炭 > 石油等 の順。統計は毎年更新されるので、受験年度のエネルギー白書で最新の値を確認すること。

同じ分野の論点

パリ協定とIPCC
パリ協定は気温上昇を2℃より十分低く、1.5℃に抑える努力をする国際的な約束。IPCCは科学的な評価をまとめる機関。
水素の輸送・貯蔵方法
水素は軽くかさばるので、圧縮する・冷やして液にする・別の物質(MCHやアンモニア)に変えて運ぶ。
最終エネルギー消費の部門別構成
実際にエネルギーを使う側(産業・業務・家庭・運輸)ごとの割合。どの部門が大きいかを押さえる。
原油・LNGの輸入先と中東依存度
原油は中東への依存度が高い。LNGは輸入先が分散している。この違いがポイント。
メタネーションとCCUS
メタネーション=水素とCO₂から都市ガスの主成分メタンをつくる。CCUS=CO₂を回収して使う・地中にためる。
