冷凍サイクルと空調の用語

課目Ⅳ冷凍・空調

ひとことで言うと

冷媒は 圧縮機 → 凝縮器 → 膨張弁 → 蒸発器 の順に回る。空調では顕熱と潜熱を分けて考える。

練習問題

空欄 A・B・C に入るものを答えてください。

蒸気圧縮式冷凍サイクルでは、冷媒は圧縮機 → A → 膨張弁 → 蒸発器の順に流れる。吸収冷凍機では吸収液に臭化リチウム水溶液を使い、冷媒は B である。空調で、全熱負荷に占める顕熱負荷の割合を C という。
A解答群
  1. ア再生器
  2. イ凝縮器
  3. ウ蒸発器
  4. エ吸収器
B解答群
  1. ア空気
  2. イアンモニア
  3. ウ水
  4. エ二酸化炭素
C解答群
  1. ア相対湿度
  2. イ顕熱比(SHF)
  3. ウ比エンタルピー
  4. エ成績係数
答えと解説を見る
  • Aイ 凝縮器
  • Bウ 水
  • Cイ 顕熱比(SHF)
A蒸気圧縮式:圧縮機で高温高圧にし、凝縮器で放熱して液化、膨張弁で減圧、蒸発器で吸熱して冷却。
B吸収冷凍機の冷媒(水)の流れ:蒸発器 → 吸収器(吸収液に吸われる)→ 再生器(発生器、加熱して追い出す)→ 凝縮器 → 蒸発器。
吸収式(臭化リチウム):冷媒の水が低圧で蒸発して冷やす。駆動は熱(蒸気・温水・燃焼)。
C顕熱比 SHF = 顕熱 / (顕熱 + 潜熱)。
p-h 線図での成績係数:圧縮機入口 h₁、出口 h₂、凝縮器出口 h₃(膨張後 h₄ = h₃)とすると、冷凍の COP = (h₁ − h₄)/(h₂ − h₁)、ヒートポンプの COP = (h₂ − h₃)/(h₂ − h₁) = 冷凍の COP + 1。

「冷凍・空調」のイメージ

冷媒が「蒸発して熱を奪い、外で凝縮して熱を捨てる」を繰り返して、熱を低い所から高い所へ運ぶ。

同じ分野の論点

空調負荷と外気の利用
外が涼しいときは外気をそのまま入れて冷房の負荷を減らす(外気冷房)。
全熱交換器の型と顕熱交換器
換気で捨てる空気と取り入れる外気の間で、温度と湿気の両方をやり取りするのが全熱交換器。
計算外気と還気の混合と冷却負荷
混ぜた空気の温度・湿度は量に比例して平均される。そこから冷やす熱量を出す。
計算相対湿度・絶対湿度・飽和度
絶対湿度=乾いた空気1kgあたりの水蒸気量。相対湿度=その温度で含める最大量に対する割合。
計算冷凍機とヒートポンプの成績係数
同じ機械でも、冷やす側の熱を見るのが冷凍、温める側を見るのがヒートポンプ。ヒートポンプのCOPは冷凍のCOP+1。
