汚れ係数と多管式熱交換器の形式

課目Ⅳ熱交換器

ひとことで言うと

汚れがたまると熱抵抗が増える。多管式は胴の中に多数の管を通した形で、構造によって掃除のしやすさが違う。

練習問題

空欄 A・B・C に入るものを答えてください。

伝熱面に汚れが付くと熱抵抗が加わり、熱通過率は A。多管式熱交換器のうち、管束を胴から引き抜いて管の外側も清掃できるのは B 形である。固定管板形では胴側の機械的な清掃が難しいので、胴側には C 流体を流すのがよい。
A解答群
  1. ア低下する
  2. イ上昇する
  3. ウ変わらない
B解答群
  1. アプレート
  2. イ遊動頭(フローティングヘッド)
  3. ウ固定管板
  4. エ二重管
C解答群
  1. ア高温の
  2. イ汚れやすい
  3. ウ汚れにくい
  4. エ粘度の高い
答えと解説を見る
  • Aア 低下する
  • Bイ 遊動頭(フローティングヘッド)
  • Cウ 汚れにくい
A1/K = 1/h₁ + 1/h₂ + 壁の熱抵抗 + 汚れ係数(汚れの熱抵抗)。設計では汚れ係数を見込んで面積に余裕をとる。
BC遊動頭形・U字管形は熱膨張を逃がせて管束を引き抜ける。固定管板形は安価だが胴側を清掃できない。
汚れやすい流体は清掃しやすい管内側に流す。定期的な洗浄で熱通過率を回復させることが省エネになる。

「熱交換器」のイメージ

熱い流体から冷たい流体へ、混ぜずに熱だけを渡す装置。

熱交換器の要点と全論点を見る ›

同じ分野の論点

開放式冷却塔と冷却水の管理
水の一部が蒸発して残りを冷やす。蒸発で濃くなった水は一部を捨てて(ブロー)入れ替える。
フィン付き伝熱面とフィン効率
熱が伝わりにくい側にひれ(フィン)を付けて面積を増やす。フィンの先ほど温度が下がるので効率は100%未満。
ドレン回収管の二相流・化学洗浄・熱容量流量
回収管の中は水と蒸気が混ざって流れる。熱容量流量=質量流量 × 比熱で、温度の変わりやすさを決める。
計算熱交換器の温度効率と出口温度
温度効率=実際に変わった温度 ÷ 変えられる最大の温度差。ここから出口温度を出す。
計算対数平均温度差と伝熱面積
入口と出口で温度差が違うので、平均の温度差を対数で出す。熱量 = 熱通過率 × 面積 × 対数平均温度差。
