np 管理図

手法管理図計算

ひとことで言うと

検査数が一定のときの不良数の管理図。np̄ ± 3√(np̄(1 − p̄))。

練習問題

空欄 A・B・C に入るものを答えてください。

毎回 n = 50 個ずつ検査し、20 回分の不適合品数の合計が Σnp = 25 個であった。np 管理図の中心線は A、UCL は B、LCL は C である。
A数値(4桁・□□.□□)
B数値(4桁・□□.□□)
C解答群
  1. アn·p̄ − 3
  2. イp̄ − 3√p̄
  3. ウ0
  4. エ示さない(計算値が負になるので考えない)
答えとやさしい解き方を見る
  • A01.25
  • B04.56
  • Cエ 示さない(計算値が負になるので考えない)

数値の答えは本番と同じ「桁ごとのマーク」です。桁が余るときは先頭に 0 を入れます。

何を聞かれている?
毎回同じ数を検査するときに、不良の個数の管理図(np 管理図)の線を出す問題。

記号と単位

  • np̄ … 1 回あたりの平均の不良数

解き方

1
不良数の合計 ÷ 回数で中心線。それを n で割ると p̄。
中心線 n·p̄ = Σnp/k = 25/20 = 1.25 → 1.25。p̄ = 1.25/50 = 0.025。
2
上の線は np̄ + 3√(np̄(1 − p̄))。
UCL = n·p̄ + 3√(n·p̄(1 − p̄)) = 1.25 + 3√(1.25 × 0.975) = 1.25 + 3.3119 = 4.5619 → 4.56。
3
下の線は np̄ − 3√(…)。負なら示さない。
LCL = 1.25 − 3.3119 = −2.0619 < 0 なので示さない。

あわせて覚える

  • np 管理図は n が一定のときに使う(n が変わるなら p 管理図)。
つまずきやすいところ
√ の中の (1 − p̄) を忘れる。

「管理図」のイメージ

工程が「いつもどおり」かを、中心線と上下の管理限界の線で見張るグラフ。

管理図の要点と全論点を見る ›

同じ分野の論点

計算X̄-R 管理図の管理限界
X̿ ± A₂R̄、R の上の線は D₄R̄。係数は群の大きさ n で読む。
計算X̄-s 管理図の管理限界
範囲のかわりに標準偏差を使う。X̿ ± A₃s̄、s の線は B₃s̄・B₄s̄。
計算X-Rs 管理図の管理限界
データが 1 つずつしか取れないとき。X̄ ± 2.66R̄s、移動範囲は k − 1 個。
計算p 管理図
不良率の管理図。検査数 n が違えば、線も日ごとに変わる。
計算c 管理図
同じ大きさのものの、きずの数の管理図。c̄ ± 3√c̄。
計算u 管理図
大きさが違うものの、1 単位あたりのきずの数の管理図。ū ± 3√(ū/n)。
計算管理図の異常判定ルール
線の外だけでなく、同じ側に 9 点、増加・減少が 6 点などの並び方も異常のサイン。
管理図の考え方(原因と群分け)
群の中のばらつきは偶然原因だけになるように群を分け、群と群の違いから異常原因を見つける。
