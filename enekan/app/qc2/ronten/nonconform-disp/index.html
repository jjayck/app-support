不適合品の処置(再格付け・スクラップ)

実践品質マネジメントシステム

ひとことで言うと

等級を変える=再格付け、そのまま使うことを認める=特別採用、使えなくする=スクラップ。

練習問題

空欄 A・B・C に入るものを答えてください。

不適合となった製品の処置について、次の説明に当てはまるものを選べ(JIS Q 9000 の用語)。 (1) 当初意図していた使用をできなくするために、不適合となった製品に対してとる処置(再資源化や破壊など)。→ A (2) 当初とは異なる要求事項に適合するように、不適合となった製品の等級を変更する。→ B (3) 同じ用途をもつ対象に対して、異なる要求事項について与えられる区分又はランク。→ C
A解答群
  1. アスクラップ
  2. イ特別採用
  3. ウ再格付け
  4. エ等級
B解答群
  1. ア等級
  2. イスクラップ
  3. ウ再格付け
  4. エ特別採用
C解答群
  1. ア等級
  2. イ特別採用
  3. ウスクラップ
  4. エ再格付け
答えと解説を見る
  • Aア スクラップ
  • Bウ 再格付け
  • Cア 等級
ABC(1) 正解は「スクラップ」。取り違えやすい「再格付け」は等級を変えて別の要求事項に適合させる処置。
B(2) 正解は「再格付け」。取り違えやすい「特別採用」は規定要求事項に適合していない製品を、そのまま使用又はリリースすることを認めること。
C(3) 正解は「等級」。取り違えやすい「再格付け」は不適合となった製品の等級を変更する処置で、区分そのものではない。
等級を変える=再格付け、そのまま使うことを認める=特別採用、使えなくする=スクラップ。 根拠:JIS Q 9000:2015 3.12.10/JIS Q 9000:2015 3.12.4/JIS Q 9000:2015 3.6.3。

品質マネジメントの原則
顧客重視・リーダーシップ・人々の積極的参加・プロセスアプローチ・改善・客観的事実に基づく意思決定・関係性管理。
修正・是正処置・不適合品の処置
不適合を除く=修正、原因を除いて再発を防ぐ=是正処置、起こりうる原因を除く=予防処置。
QMS の基本用語
方針は意図と方向付け、目標は達成すべき結果。妥当性確認は意図した用途に合うかの確認。
検証・トレーサビリティ・有効性
規定どおりか=検証、履歴を追える=トレーサビリティ、結果の達成度=有効性、資源との関係=効率。
