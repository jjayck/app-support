ポアソン分布の確率

手法確率分布計算

ひとことで言うと

まれに起きることの回数。0 回の確率は e−λ、平均も分散も λ。

練習問題

空欄 A・B・C・D に入るものを答えてください。

1 日あたりの設備の停止回数 X は、平均 λ = 1.5 のポアソン分布に従う。P(X = 0) = A、P(X = 1) = B、P(X ≤ 2) = C である。ポアソン分布は D である。ただし e−1.5 = 0.2231 とする。
A数値(5桁・□.□□□□)
B数値(5桁・□.□□□□)
C数値(5桁・□.□□□□)
D解答群
  1. ア平均も分散も λ
  2. イ平均は λ、分散は λ²
  3. ウ平均は λ、分散は λ(1 − λ)
  4. エ平均は λ、分散は √λ
答えとやさしい解き方を見る
  • A0.2231
  • B0.3347
  • C0.8087
  • Dア 平均も分散も λ

数値の答えは本番と同じ「桁ごとのマーク」です。桁が余るときは先頭に 0 を入れます。

何を聞かれている?
きずの数や故障回数のように、まれに起きることの回数の確率をポアソン分布で出す問題。

記号と単位

  • λ(ラムダ)… 平均の回数
  • e−λ … 問題文で与えられる値(0 回の確率そのもの)

解き方

1
式:P(x) = e−λ × λˣ ÷ x!。x! は 1 × 2 × … × x。
ポアソン分布:P(X = x) = e−λ λˣ / x!。
2
e−λ は自分で計算せず、問題文の値をそのまま使う。
e−λ は関数電卓を使わず、問題文で与えた e−1.5 = 0.2231 の値を使う。
3
0 回の確率は e−λ そのもの。
P(X = 0) = e−1.5 = 0.2231 → 0.2231。
4
1 回は λ を 1 回掛ける。
P(X = 1) = 1.5 × 0.2231 = 0.33465 → 0.3347。
5
2 回は λ² を 2 で割って掛ける。0〜2 回を足すと「2 回以下」。
P(X = 2) = 1.5²/2 × 0.2231 = 0.25099。P(X ≤ 2) = 0.2231 + 0.33465 + 0.25099 = 0.80874 → 0.8087。
6
平均と分散がどちらも λ なのがポアソン分布の特徴。
ポアソン分布は平均と分散がどちらも λ。
つまずきやすいところ
x! で割り忘れる(2 回のとき ÷ 2)/「2 以下」に 2 を入れ忘れる。

計算正規分布の確率
(x − μ)/σ で標準化すれば、正規分布表 1 枚でどんな正規分布の確率も読める。
計算確率から値を求める(正規分布)
上から 5 % の点は K = 1.645。値に戻すときは μ + Kσ。
計算二項分布の確率
n 個中 x 個が不良の確率。0 個は (1 − p)ⁿ、平均 np、分散 np(1 − p)。
計算期待値と分散の加法性
和でも差でも、独立なら分散は足し算。標準偏差は足さない。
計算平均値の分布と中心極限定理
n 個の平均のばらつきは σ/√n。平均はもとの分布によらずほぼ正規分布になる。
