工程能力指数 Cp・Cpk

手法工程能力計算

ひとことで言うと

Cp = 規格の幅/6s。平均のずれを考えると Cpk = 近いほうの規格までの距離/3s。1.33 以上で十分。

練習問題

空欄 A・B・C に入るものを答えてください。

ある部品の寸法の規格は 19.4 〜 20.6 mm である。工程から取ったデータの平均値は x̄ = 19.8 mm、標準偏差は s = 0.15 mm であった。工程能力指数 Cp は A、かたよりを考慮した工程能力指数 Cpk は B であり、Cpk で評価すると C。
A数値(3桁・□.□□)
B数値(3桁・□.□□)
C解答群
  1. ア工程能力は十分ある
  2. イ工程能力はまずまずだが十分とはいえない
  3. ウ工程能力は非常に不足している
  4. エ工程能力は不足している
  5. オ工程能力は十分すぎる
答えとやさしい解き方を見る
  • A1.33
  • B0.89
  • Cエ 工程能力は不足している

数値の答えは本番と同じ「桁ごとのマーク」です。桁が余るときは先頭に 0 を入れます。

何を聞かれている?
規格の幅に対して工程のばらつきがどれだけ小さいか(工程能力指数)を出し、平均のずれも考えた Cpk で評価する問題。

記号と単位

  • Sᵤ・Sₗ … 上限規格・下限規格
  • s … 標準偏差
  • Cp … 規格の幅 ÷ 6s
  • Cpk … 平均から近いほうの規格までの距離 ÷ 3s

解き方

1
規格の幅(上限 − 下限)を 6s で割る。6s は「ほぼ全部の製品が入る幅」。
Cp = (Sᵤ − Sₗ)/(6s) = (20.6 − 19.4)/(6 × 0.15) = 1.2/0.9 = 1.3333 → 1.33。
2
平均から上限までの距離を 3s で割る。
上限側:(Sᵤ − x̄)/(3s) = (20.6 − 19.8)/(3 × 0.15) = 1.7778。
3
平均から下限までの距離を 3s で割る。
下限側:(x̄ − Sₗ)/(3s) = (19.8 − 19.4)/(3 × 0.15) = 0.8889。
4
2 つのうち小さいほうが Cpk。規格に近い側が危ないので、そちらで評価する。
Cpk は小さいほう(下限側)= 0.8889 → 0.89。平均が規格の中心からずれているぶん Cp より小さい。
5
1.33 以上なら十分、1.00 未満なら不足、が基準の目安。
目安:1.67 以上 十分すぎる/1.33 以上 十分/1.00 以上 まずまず/0.67 以上 不足/0.67 未満 非常に不足。0.89 は「工程能力は不足している」。
つまずきやすいところ
Cpk で 6s で割ってしまう(片側なので 3s)/大きいほうを Cpk にしてしまう。
