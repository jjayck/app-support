品質マネジメントの原則

実践品質マネジメントシステム

ひとことで言うと

顧客重視・リーダーシップ・人々の積極的参加・プロセスアプローチ・改善・客観的事実に基づく意思決定・関係性管理。

練習問題

空欄 A・B・C に入るものを答えてください。

JIS Q 9000 の品質マネジメントの原則について、次の説明に当てはまる原則を選べ。 (1) データと情報の分析及び評価にもとづいて決めるほうが、望む結果を得る可能性が高い。→ A (2) 持続的成功のために、供給者などの密接に関連する利害関係者とのつながりをマネジメントする。→ B (3) 製品やサービスを受け取る側の要求事項を満たし、さらにその期待を超える努力をすることを主眼とする。→ C
A解答群
  1. アプロセスアプローチ
  2. イ人々の積極的参加
  3. ウ顧客重視
  4. エ関係性管理
  5. オ客観的事実に基づく意思決定
B解答群
  1. ア顧客重視
  2. イ改善
  3. ウ関係性管理
  4. エ人々の積極的参加
  5. オ客観的事実に基づく意思決定
C解答群
  1. ア改善
  2. イ顧客重視
  3. ウプロセスアプローチ
  4. エ関係性管理
  5. オ客観的事実に基づく意思決定
答えと解説を見る
  • Aオ 客観的事実に基づく意思決定
  • Bウ 関係性管理
  • Cイ 顧客重視
AC(1) 正解は「客観的事実に基づく意思決定」。取り違えやすい「顧客重視」は顧客の要求事項を満たし期待を超えることを主眼にする原則。
B(2) 正解は「関係性管理」。取り違えやすい「顧客重視」は顧客の要求事項を満たすことを主眼にする原則。
C(3) 正解は「顧客重視」。取り違えやすい「関係性管理」は供給者など密接に関連する利害関係者との関係を管理すること。
7 原則:顧客重視・リーダーシップ・人々の積極的参加・プロセスアプローチ・改善・客観的事実に基づく意思決定・関係性管理。 根拠:JIS Q 9000:2015 2.3.6/JIS Q 9000:2015 2.3.7/JIS Q 9000:2015 2.3.1。

「品質マネジメントシステム」のイメージ

品質を中心に組織を運営する仕組み(ISO 9001 / JIS Q 9001)と、その用語。

同じ分野の論点

修正・是正処置・不適合品の処置
不適合を除く=修正、原因を除いて再発を防ぐ=是正処置、起こりうる原因を除く=予防処置。
QMS の基本用語
方針は意図と方向付け、目標は達成すべき結果。妥当性確認は意図した用途に合うかの確認。
検証・トレーサビリティ・有効性
規定どおりか=検証、履歴を追える=トレーサビリティ、結果の達成度=有効性、資源との関係=効率。
不適合品の処置(再格付け・スクラップ)
等級を変える=再格付け、そのまま使うことを認める=特別採用、使えなくする=スクラップ。
