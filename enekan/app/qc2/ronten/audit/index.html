品質監査と力量

実践診断・監査・人材育成

ひとことで言うと

誰が行うかで第一者(内部)・第二者・第三者監査。力量は知識と技能を使って結果を出す能力。

練習問題

空欄 A・B・C に入るものを答えてください。

監査と人材について、次の説明に当てはまる用語を選べ(JIS Q 9000 の用語)。 (1) 組織が自ら、又は組織の代理人が自分の組織について行うもの。→ A (2) 定めた基準が満たされている程度を判定するために、客観的な証拠を集めて客観的に評価する、体系的で独立し文書化したプロセス。→ B (3) 適合の認証などを行う、独立した外部の組織が行うもの。→ C
A解答群
  1. ア監査
  2. イ第三者監査
  3. ウ内部監査
  4. エ認識
  5. オ第二者監査
B解答群
  1. ア監査
  2. イ内部監査
  3. ウマネジメントレビュー
  4. エ第二者監査
  5. オ第三者監査
C解答群
  1. ア第三者監査
  2. イマネジメントレビュー
  3. ウ監査
  4. エ内部監査
  5. オ力量
答えと解説を見る
  • Aウ 内部監査
  • Bア 監査
  • Cア 第三者監査
AB(1) 正解は「内部監査」。取り違えやすい「第二者監査」は顧客など、組織に利害をもつ者が行う監査。
B(2) 正解は「監査」。取り違えやすい「マネジメントレビュー」はトップマネジメントが QMS の適切性・妥当性・有効性を確かめるために行う見直し。
C(3) 正解は「第三者監査」。取り違えやすい「内部監査」は組織が自ら行う監査。
誰が行うかで第一者(内部)・第二者・第三者に分かれる。 根拠:JIS Q 9000:2015 3.13.1。
