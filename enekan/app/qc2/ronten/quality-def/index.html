品質・要求事項・品質特性・代用特性

実践品質の概念

ひとことで言うと

品質は特性の集まりが要求事項を満たす程度。直接測れない特性は代用特性で測る。

練習問題

空欄 A・B・C に入るものを答えてください。

品質に関する次の説明に当てはまる用語を選べ。 (1) 対象に本来備わっている特性の集まりが、要求事項を満たす程度。→ A (2) 製品に対する顧客の要求事項のうち、品質に関するものを言葉で表したもの。→ B (3) 明示されている、通常は暗黙のうちに了解されている、又は義務として求められているニーズや期待。→ C
A解答群
  1. ア品質
  2. イ品質特性
  3. ウ要求事項
  4. エ要求品質
  5. オ代用特性
B解答群
  1. ア品質特性
  2. イ要求品質
  3. ウ要求事項
  4. エ代用特性
  5. オ品質
C解答群
  1. ア品質特性
  2. イ品質
  3. ウ代用特性
  4. エ要求品質
  5. オ要求事項
答えと解説を見る
  • Aア 品質
  • Bイ 要求品質
  • Cオ 要求事項
AC(1) 正解は「品質」。取り違えやすい「品質特性」は要求事項に関連する、対象に本来備わっている一つひとつの特性で、満たす程度そのものではない。
B(2) 正解は「要求品質」。取り違えやすい「品質特性」は要求を測れる形に置き換えた特性で、顧客の言葉そのものではない。
C(3) 正解は「要求事項」。取り違えやすい「品質」は特性の集まりがニーズや期待を満たす程度のこと。
「満たす程度」が品質、「ニーズや期待」が要求事項、「測る特性」が品質特性。 根拠:JIS Q 9000:2015 3.6.2/JIS Q 9025:2003 3.1.13/JIS Q 9000:2015 3.6.4。
