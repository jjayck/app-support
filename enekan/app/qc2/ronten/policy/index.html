方針・重点課題・目標・方策

実践方針管理

ひとことで言うと

方針の中に重点課題・目標(到達点)・方策(手段)があり、達成度は管理項目で見る。

練習問題

空欄 A・B・C に入るものを答えてください。

方針管理(JIS Q 9023)の用語について、次の説明に当てはまるものを選べ。 (1) 部門の方針や実施計画を作るときに、上位・下位の管理者や関係する他部門と十分に話し合って調整する。→ A (2) 目標がどこまで達成できているかを見るために、評価の尺度として選んだ項目。→ B (3) 組織として優先順位の高いものに絞って取り組み、達成すべき事項。→ C
A解答群
  1. アすり合わせ
  2. イ重点課題
  3. ウ方針
  4. エ方策
  5. オ管理項目
B解答群
  1. ア重点課題
  2. イ方針
  3. ウ方策
  4. エ目標
  5. オ管理項目
C解答群
  1. ア重点課題
  2. イ方針
  3. ウすり合わせ
  4. エ管理項目
  5. オ目標
答えと解説を見る
  • Aア すり合わせ
  • Bオ 管理項目
  • Cア 重点課題
A(1) 正解は「すり合わせ」。取り違えやすい「方策」は目標を達成する手段そのもの。
B(2) 正解は「管理項目」。取り違えやすい「方策」は目標を達成するための手段で、達成の度合いを測る尺度ではない。
C(3) 正解は「重点課題」。取り違えやすい「方針」はトップの全体的な意図及び方向付けそのもので、その中で絞り込んだ事項ではない。
方針(方向付け)→ 重点課題 → 目標(到達点)→ 方策(手段)、達成度は管理項目で見る。 根拠:JIS Q 9023:2018 5.2.3/JIS Q 9023:2018 3.7/JIS Q 9023:2018 3.3。
