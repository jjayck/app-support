品質表・企画品質・設計品質

実践品質保証:新製品開発

ひとことで言うと

要求品質の目標が企画品質、品質特性の目標が設計品質。品質表は 2 つの展開表の二元表。

練習問題

空欄 A・B・C に入るものを答えてください。

品質機能展開(JIS Q 9025)の用語について、次の説明に当てはまるものを選べ。 (1) 要求品質展開表と品質特性展開表とを組み合わせた二元表。→ A (2) 顧客の、製品に対する要求事項(原始情報とも呼ぶ)。→ B (3) 品質特性に対する品質目標。→ C
A解答群
  1. ア要求品質
  2. イ設計品質
  3. ウ企画品質
  4. エ品質表
  5. オ品質特性展開表
B解答群
  1. ア顧客の声
  2. イ企画品質
  3. ウ品質表
  4. エ設計品質
  5. オ要求品質
C解答群
  1. ア企画品質
  2. イ設計品質
  3. ウ品質特性展開表
  4. エ要求品質
  5. オ顧客の声
答えと解説を見る
  • Aエ 品質表
  • Bア 顧客の声
  • Cイ 設計品質
A(1) 正解は「品質表」。取り違えやすい「品質特性展開表」は品質特性を階層構造で表した展開表(一元の表)。
B(2) 正解は「顧客の声」。取り違えやすい「要求品質」は製品に対する要求事項のうち、品質に関するもの。
C(3) 正解は「設計品質」。取り違えやすい「企画品質」は要求品質に対する品質目標。
顧客の声 → 要求品質 → 品質特性。要求品質の目標が企画品質、品質特性の目標が設計品質。 根拠:JIS Q 9025:2003 3.2.3/JIS Q 9025:2003 3.1.12/JIS Q 9025:2003 3.2.5。
