手法データのまとめ方

ひとことで言うと

測ったデータが計量値、数えたデータが計数値、文章のデータが言語データ。全体が母集団、取り出した一部がサンプル。

練習問題

空欄 A・B・C に入るものを答えてください。

データの種類について、次のデータや説明に当てはまるものを選べ。 (1) 考察の対象となる特性をもつ、すべてのものの集団。→ A (2) 調べたい集団全体についての情報を得るために、そこから取り出した一部。→ B (3) 顧客の意見や苦情の文章のように、数値で表さないデータ。→ C
A解答群
  1. ア計量値
  2. イ計数値
  3. ウ言語データ
  4. エサンプル
  5. オ母集団
B解答群
  1. ア母集団
  2. イ計数値
  3. ウサンプル
  4. エ言語データ
  5. オ計量値
C解答群
  1. ア言語データ
  2. イ計数値
  3. ウサンプル
  4. エ計量値
  5. オ母集団
答えと解説を見る
  • Aオ 母集団
  • Bウ サンプル
  • Cア 言語データ
AB(1) 正解は「母集団」。取り違えやすい「サンプル」は母集団から、それを調べるために取り出した一部。
B(2) 正解は「サンプル」。取り違えやすい「母集団」は考察の対象となる特性をもつすべてのものの集団。
C(3) 正解は「言語データ」。取り違えやすい「計数値」は数えてデータにした数値。
測る=計量値、数える=計数値、文章=言語データ。全体=母集団、取り出した一部=サンプル。 根拠:QC検定4級の手引き 4章*33/QC検定4級の手引き 4章*32/QC検定4級の手引き 4章*30。

同じ分野の論点

計算基本統計量の計算
平均で真ん中、平方和→分散→標準偏差でばらつき。分散の分母は n − 1。
計算データの変換(数値変換)
u = (x − 基準)× 倍率。平均は「ずらし+目盛り」を戻し、平方和は目盛りの 2 乗だけ戻す。
計算パレート図の累積比率
件数の多い順に並べ、「その他」は最後。上位の数項目で全体の大部分を占めることを見る。
サンプリングの種類と性質
層ごとに抜く=層別、選んだまとまりを全部=集落、選んだまとまりからさらに抜く=2 段、一定間隔=系統。
QC七つ道具の使い分け
件数の順ならパレート図、要因の整理なら特性要因図、ばらつきの形ならヒストグラム、2 つの関係なら散布図、分けて比べるなら層別。
