改善と維持向上・要因と原因

実践管理の方法

ひとことで言うと

向上の活動が改善(繰り返すと継続的改善)、外れないように保つのが維持向上。特定されたものが原因。

練習問題

空欄 A・B・C に入るものを答えてください。

次の説明に当てはまる用語を選べ。 (1) パフォーマンスを向上するために繰り返し行われる活動。→ A (2) パフォーマンスを向上するための活動(繰り返し行うことも、一回限りのこともある)。→ B (3) 目標を現状又はその延長線上に置き、目標から外れないようにし、外れたらすぐ元に戻せるようにする活動。→ C
A解答群
  1. ア要因
  2. イ維持向上
  3. ウ継続的改善
  4. エ原因
  5. オ改善
B解答群
  1. ア維持向上
  2. イ要因
  3. ウ継続的改善
  4. エ改善
  5. オ原因
C解答群
  1. ア原因
  2. イ要因
  3. ウ継続的改善
  4. エ改善
  5. オ維持向上
答えと解説を見る
  • Aウ 継続的改善
  • Bエ 改善
  • Cオ 維持向上
ABC(1) 正解は「継続的改善」。取り違えやすい「維持向上」は目標を現状又はその延長線上に置き、外れないようにする活動で、向上を繰り返すことではない。
B(2) 正解は「改善」。取り違えやすい「継続的改善」は向上のための活動を繰り返し行うことで、一回限りの活動は含まない。
C(3) 正解は「維持向上」。取り違えやすい「継続的改善」はパフォーマンスを向上するために繰り返し行われる活動。
向上の活動が改善(繰り返すと継続的改善)、外れないように保つのが維持向上。特定されたものが原因。 根拠:JIS Q 9000:2015 3.3.2/JIS Q 9000:2015 3.3.1/JIS Q 9026:2016 3.1。
