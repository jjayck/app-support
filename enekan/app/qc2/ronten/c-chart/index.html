c 管理図

手法管理図計算

ひとことで言うと

同じ大きさのものの、きずの数の管理図。c̄ ± 3√c̄。

練習問題

空欄 A・B・C・D に入るものを答えてください。

同じ大きさの塗装パネルを毎回 1 枚ずつ調べ、ブツの数を数えた。20 枚分の合計は Σc = 89 個であった。c 管理図の中心線は A、UCL は B、LCL は C である。c 管理図は、不適合数が D に従うことにもとづいている。
A数値(3桁・□.□□)
B数値(4桁・□□.□□)
C解答群
  1. アc̄/3
  2. イ0
  3. ウc̄ − 3
  4. エ示さない(計算値が負になるので考えない)
D解答群
  1. ア正規分布
  2. イポアソン分布
  3. ウχ² 分布
  4. エ二項分布
答えとやさしい解き方を見る
  • A4.45
  • B10.78
  • Cエ 示さない(計算値が負になるので考えない)
  • Dイ ポアソン分布

数値の答えは本番と同じ「桁ごとのマーク」です。桁が余るときは先頭に 0 を入れます。

何を聞かれている?
同じ大きさのものを調べて、きずの数の管理図(c 管理図)の線を出す問題。

記号と単位

  • c̄ … 1 個あたりの平均のきずの数

解き方

1
合計 ÷ 個数。
c̄ = Σc/k = 89/20 = 4.45 → 4.45。
2
きずの数はポアソン分布なので、標準偏差は √c̄。
不適合数はポアソン分布で、分散 = 平均 = c̄。だから標準偏差は √c̄。
3
上の線は c̄ + 3√c̄。
UCL = c̄ + 3√c̄ = 4.45 + 3 × 2.1095 = 10.7785 → 10.78。
4
下の線は c̄ − 3√c̄。負なら示さない。
LCL = c̄ − 3√c̄ = −1.8785 < 0 なので示さない。
つまずきやすいところ
√ を付け忘れて c̄ + 3c̄ にしてしまう。
この論点の問題は全 8 問(無料 1 問)

工程が「いつもどおり」かを、中心線と上下の管理限界の線で見張るグラフ。

同じ分野の論点

計算X̄-R 管理図の管理限界
X̿ ± A₂R̄、R の上の線は D₄R̄。係数は群の大きさ n で読む。
計算X̄-s 管理図の管理限界
範囲のかわりに標準偏差を使う。X̿ ± A₃s̄、s の線は B₃s̄・B₄s̄。
計算X-Rs 管理図の管理限界
データが 1 つずつしか取れないとき。X̄ ± 2.66R̄s、移動範囲は k − 1 個。
計算p 管理図
不良率の管理図。検査数 n が違えば、線も日ごとに変わる。
計算np 管理図
検査数が一定のときの不良数の管理図。np̄ ± 3√(np̄(1 − p̄))。
計算u 管理図
大きさが違うものの、1 単位あたりのきずの数の管理図。ū ± 3√(ū/n)。
計算管理図の異常判定ルール
線の外だけでなく、同じ側に 9 点、増加・減少が 6 点などの並び方も異常のサイン。
管理図の考え方(原因と群分け)
群の中のばらつきは偶然原因だけになるように群を分け、群と群の違いから異常原因を見つける。
