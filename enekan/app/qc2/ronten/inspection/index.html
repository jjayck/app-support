検査の種類と方法

実践品質保証:プロセス保証

ひとことで言うと

全数か抜取か、試験を省く無試験検査、壊す破壊検査、五感で判定する官能検査。

練習問題

空欄 A・B・C に入るものを答えてください。

検査の方法について、次の説明に当てはまるものを選べ。 (1) 測ることで対象物の機能が失われてしまう検査(サンプルを壊して調べる)。→ A (2) ロットからサンプルを抜き取って試験し、その結果でロットの合格・不合格を判定する。→ B (3) 品質情報や技術情報などにもとづき、サンプルの試験を省略してロットの合否を判定する。→ C
A解答群
  1. ア全数検査
  2. イ抜取検査
  3. ウ官能検査
  4. エ無試験検査
  5. オ破壊検査
B解答群
  1. ア全数検査
  2. イ抜取検査
  3. ウ無試験検査
  4. エ官能検査
  5. オ破壊検査
C解答群
  1. ア官能検査
  2. イ抜取検査
  3. ウ破壊検査
  4. エ無試験検査
  5. オ全数検査
答えと解説を見る
  • Aオ 破壊検査
  • Bイ 抜取検査
  • Cエ 無試験検査
A(1) 正解は「破壊検査」。取り違えやすい「官能検査」は人の五感で判定する検査で、壊すかどうかの分類ではない。
B(2) 正解は「抜取検査」。取り違えやすい「全数検査」は製品を一つ残らず調べる。
C(3) 正解は「無試験検査」。取り違えやすい「抜取検査」はサンプルを実際に試験して、その結果でロットの合否を判定する。
何個調べるか(全数・抜取)、試験を省くか(無試験)、壊すか(破壊)、何で測るか(官能)。 根拠:QC検定4級の手引き 4章*24。
