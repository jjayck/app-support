回帰の分散分析と寄与率

手法単回帰分析計算

ひとことで言うと

SR = Sₓᵧ²/Sₓₓ、残差の自由度 n − 2。寄与率 R² = SR/Sᵧᵧ。

練習問題

空欄 A・B・C・D・E に入るものを答えてください。

何を聞かれている?
回帰直線が意味のあるものかを分散分析で判定し、寄与率を出す問題。

記号と単位

  • SR … 回帰で説明できる平方和
  • Se … 残差平方和
  • R² … 寄与率(全体のうち説明できた割合)

解き方

1
SR = Sₓᵧ² ÷ Sₓₓ。
回帰による平方和 SR = Sₓᵧ²/Sₓₓ = 96²/160 = 57.6 → 57.6。
2
残りが Se。
Se = Sᵧᵧ − SR = 230.4 − 57.6 = 172.8 → 172.8。
3
自由度は回帰 1、残差 n − 2。Se を n − 2 で割ってから比をとる。
自由度:回帰 1、残差 n − 2 = 3。Ve = 172.8/3 = 57.6、F₀ = SR/Ve = 1 → 1.00。
4
F 表は (1, n − 2) の値。
F(1, 3; 0.05) = 10.13。F₀ < 10.13 → 有意でない。
5
SR ÷ Sᵧᵧ が寄与率。
寄与率 R² = SR/Sᵧᵧ = 57.6/230.4 = 0.25 → 25.0 %(相関係数 r の 2 乗と同じ)。
つまずきやすいところ
残差の自由度を n − 1 にしてしまう(直線は 2 つの値を決めるので n − 2)。
