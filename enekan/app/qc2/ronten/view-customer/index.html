マーケットイン・重点指向・三現主義

実践QC的ものの見方・考え方

ひとことで言うと

顧客の側から考え、影響の大きいものから、現場・現物・現実で確かめる。

練習問題

空欄 A・B・C に入るものを答えてください。

次の説明に最も当てはまる考え方を選べ。 (1) 結果への影響が大きい問題や要因に高い優先順位を与え、そこから重点的に取り組む。→ A (2) 現場・現物・現実の三つに、原理・原則の二つを加えて物事を考え、行動する。→ B (3) 顧客の側から見た論理よりも、提供する側の論理や都合を優先して製品を出す。→ C
A解答群
  1. ア三現主義
  2. イマーケットイン
  3. ウ5ゲン主義
  4. エ重点指向
  5. オプロダクトアウト
B解答群
  1. アプロダクトアウト
  2. イ5ゲン主義
  3. ウ重点指向
  4. エ三現主義
  5. オマーケットイン
C解答群
  1. アプロダクトアウト
  2. イ三現主義
  3. ウ5ゲン主義
  4. エマーケットイン
  5. オ重点指向
答えと解説を見る
  • Aエ 重点指向
  • Bイ 5ゲン主義
  • Cア プロダクトアウト
A(1) 正解は「重点指向」。取り違えやすい「三現主義」は現場・現物・現実を確かめてから判断する考え方で、取り組む順番の決め方ではない。
B(2) 正解は「5ゲン主義」。取り違えやすい「三現主義」は現場・現物・現実の三つだけで、原理・原則は含まない。
C(3) 正解は「プロダクトアウト」。取り違えやすい「マーケットイン」は顧客の側から見た論理を優先する考え方。
顧客から見るか作り手から見るか、何を優先するか、どこで確かめるかで見分ける。 根拠:QC検定4級の手引き 1.7/QC検定4級の手引き 3.4/QC検定4級の手引き 1.3。
