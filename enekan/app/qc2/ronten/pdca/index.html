PDCA・SDCA

実践管理の方法

ひとことで言うと

改善は PDCA、維持は SDCA。S は標準化。

練習問題

空欄 A・B・C に入るものを答えてください。

管理のサイクルについて、次の説明に当てはまる段階を選べ。 (1) 決めたとおりに実行する。→ A (2) 目標と、それを達成するための方法を決める。→ B (3) 維持を目的とする管理のサイクルで、最初に標準(やり方の決まり)を定める段階。→ C
A解答群
  1. アC(確認)
  2. イP(計画)
  3. ウA(処置)
  4. エD(実施)
  5. オS(標準化)
B解答群
  1. アP(計画)
  2. イC(確認)
  3. ウD(実施)
  4. エA(処置)
  5. オS(標準化)
C解答群
  1. アD(実施)
  2. イA(処置)
  3. ウP(計画)
  4. エS(標準化)
  5. オC(確認)
答えと解説を見る
  • Aエ D(実施)
  • Bア P(計画)
  • Cエ S(標準化)
AB(1) 正解は「D(実施)」。取り違えやすい「A(処置)」は結果に応じて手を打つ段階で、計画どおりに実行する段階ではない。
BC(2) 正解は「P(計画)」。取り違えやすい「S(標準化)」はSDCA の最初の段階で、決められた標準を定め、それに従うことが出発点。
C(3) 正解は「S(標準化)」。取り違えやすい「P(計画)」は改善を目的とするサイクルの最初で、目標と達成方法を決める段階。
改善は PDCA、維持は SDCA(S は標準化)。 根拠:QC検定4級の手引き 4章*11/JIS Q 9026:2016 4.1。
