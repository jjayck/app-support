何を聞かれている?
分散分析で効果があった条件について、いちばんよい水準の平均の範囲と、2 つの水準の差の範囲を出す問題。

記号と単位

  • Ve … 誤差分散
  • r … 1 水準のデータ数
  • t(φ_e, 0.05) … 誤差の自由度で読む t 表の値

解き方

1
水準の平均のばらつきは Ve/r。t 表は誤差の自由度の行を読む。
水準の平均は r = 6 個のデータの平均なので、その分散は Ve/r で推定する。t は誤差の自由度で読む:t(15, 0.05) = 2.131。
2
t × √(Ve/r) が幅の半分。
幅の半分 = t(φ_e, 0.05)√(Ve/r) = 2.131 × √(3.2/6) = 1.5563 → 1.56。
3
平均にその幅を足し引きする。
区間 = 78.5 ± 1.5563 → 76.9437 〜 80.0563 → 76.94 〜 80.06。
4
2 つの平均の差では分散が 2 倍になるので √(2Ve/r)。
差の分散は 2 つの平均の分散の和 = 2Ve/r。幅の半分 = 2.131 × √(2 × 3.2/6) = 2.2009 → 2.20。
5
差が幅の半分より大きければ、区間に 0 が入らず差がある。
差 78.5 − 78.0 = 0.5 は 2.2009 より小さい → 区間に 0 を含み、差があるとはいえない。
つまずきやすいところ
t 表を n − 1 の行で読む(誤差の自由度で読む)/差の推定で 2 を掛け忘れる。

同じ分野の論点

計算一元配置の分散分析
全体のばらつきを、因子のぶんと誤差のぶんに分け、F₀ = V_A/V_e を F 表と比べる。
計算繰返しのない二元配置
A と B のぶんを引いた残りが誤差。交互作用は誤差と分けられない。
計算繰返しのある二元配置と交互作用
組合せごとの平均のばらつき S_AB から A と B のぶんを引くと交互作用。
計算交互作用のプーリング
効果の小さい交互作用は、平方和と自由度を誤差に足し込んで、誤差分散を求め直す。
