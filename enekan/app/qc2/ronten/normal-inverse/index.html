ひとことで言うと

上から 5 % の点は K = 1.645。値に戻すときは μ + Kσ。

練習問題

空欄 A・B・C に入るものを答えてください。

何を聞かれている?
確率(上から何 %)が与えられて、それに当たる値を逆に求める問題。

記号と単位

  • KP … 上側確率が P になる点(正規分布表 P から KP)

解き方

1
上から 5 % なら P = 0.05 の行。表の KP を読む。
表で P = 0.05 の KP を読む:K = 1.645 → 1.645。
2
平均 + K × σ で、その値に戻す。
x = μ + Kσ = 300 + 1.645 × 3 = 304.935 → 304.9 g。
3
下から数える場合は、同じ K を平均から引く。
下側 10 % は対称なので K = 1.282 を引く:x = μ − Kσ = 300 − 1.282 × 3 = 296.154 → 296.2 g。
つまずきやすいところ
P と K の表の取りちがえ(確率から値を求めるときは「P から KP を求める表」)。

「確率分布」のイメージ

データのばらつき方には決まった形があり、その形を使うと「どのくらいの確率で起きるか」が計算できる。

同じ分野の論点

計算正規分布の確率
(x − μ)/σ で標準化すれば、正規分布表 1 枚でどんな正規分布の確率も読める。
計算二項分布の確率
n 個中 x 個が不良の確率。0 個は (1 − p)ⁿ、平均 np、分散 np(1 − p)。
計算ポアソン分布の確率
まれに起きることの回数。0 回の確率は e^(−λ)、平均も分散も λ。
計算期待値と分散の加法性
和でも差でも、独立なら分散は足し算。標準偏差は足さない。
計算平均値の分布と中心極限定理
n 個の平均のばらつきは σ/√n。平均はもとの分布によらずほぼ正規分布になる。
