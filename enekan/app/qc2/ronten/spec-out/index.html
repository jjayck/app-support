規格外れの割合(正規分布)

手法工程能力計算

ひとことで言うと

上と下をそれぞれ標準化して表を読み、足す。下側は対称性で同じ表を使う。

練習問題

空欄 A・B・C に入るものを答えてください。

ある製品の長さは、平均 μ = 75 mm、標準偏差 σ = 0.2 mm の正規分布に従っている。規格は 74.68 〜 75.45 mm である。上限規格を超える割合は A %、下限規格を下回る割合は B %、規格外れの合計は C % である。付表の正規分布表を用いよ。

何を聞かれている?
正規分布に従う製品のうち、規格の上限を超えるもの・下限を下回るものが何 % あるかを出す問題。

記号と単位

  • μ・σ … 平均・標準偏差
  • K … 標準化した値 (x − μ)/σ

解き方

1
上限までの距離を σ で割り(標準化)、正規分布表で上側の確率を読む。
上限側を標準化:K = (Sᵤ − μ)/σ = (75.45 − 75)/0.2 = 2.25。表から P = 0.0122 → 1.22 %。
2
下限も同じように距離を σ で割る。正規分布は左右対称なので、同じ表で読める。
下限側を標準化:K = (μ − Sₗ)/σ = (75 − 74.68)/0.2 = 1.60。正規分布は左右対称なので、下側も上側確率の表で読める。P = 0.0548 → 5.48 %。
3
上と下の割合を足すと規格外れの合計。
合計 = 0.0122 + 0.0548 = 0.0670 → 6.70 %。
つまずきやすいところ
下側をマイナスの K のまま表を探す(表は正の K だけ。対称性を使う)。

同じ分野の論点

計算工程能力指数 Cp・Cpk
Cp = 規格の幅/6s。平均のずれを考えると Cpk = 近いほうの規格までの距離/3s。1.33 以上で十分。
計算片側規格の工程能力と不適合品率
規格が片側だけなら (規格 − 平均)/3s。規格までの距離を s で割れば、正規分布表で外れる割合が読める。
