変化点管理・変更管理・工程能力調査

実践品質保証:プロセス保証

ひとことで言うと

4M などの変化に目を配るのが変化点管理。正式に承認された後の変更を管理するのが変更管理。

練習問題

空欄 A・B・C に入るものを答えてください。

プロセス保証について、次の説明に当てはまる用語を選べ。 (1) 人・設備・材料・方法などに起こりうる変化を明確にし、変化があったときに重点的に監視・処置する。→ A (2) 不規則さを生む可能性のある原因の種類や所在など、工程の出力に影響する要因を詳しく調べる。→ B (3) 製品の構成情報が正式に承認された後に、その変更を管理する活動。→ C
A解答群
  1. ア変化点管理
  2. イ工程能力調査
  3. ウ変更管理
  4. エ工程解析
  5. オトラブル予測
B解答群
  1. ア変化点管理
  2. イ工程解析
  3. ウ工程能力調査
  4. エ変更管理
  5. オトラブル予測
C解答群
  1. ア変更管理
  2. イ工程能力調査
  3. ウ変化点管理
  4. エトラブル予測
  5. オ工程解析
答えと解説を見る
  • Aア 変化点管理
  • Bイ 工程解析
  • Cア 変更管理
AC(1) 正解は「変化点管理」。取り違えやすい「変更管理」は製品の構成の正式な承認後に、その変更を管理する活動。
B(2) 正解は「工程解析」。取り違えやすい「工程能力調査」は工程が作り出す製品のばらつきの大きさを調べること。
C(3) 正解は「変更管理」。取り違えやすい「変化点管理」は意図しない変化も含め、工程の 4M などの変化を見張る管理。
変化への備え(変化点管理)・正式な変更(変更管理)・能力(工程能力調査)・関係(工程解析)。 根拠:JIS Q 9027:2018/JIS Z 9020-2:2016 11.2/JIS Q 9000:2015 3.3.10。
