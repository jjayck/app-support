管理項目・点検項目・管理水準・異常

実践日常管理

ひとことで言うと

結果を見るのが管理項目、原因を見るのが点検項目。管理水準は安定しているときの値の範囲。

練習問題

空欄 A・B・C に入るものを答えてください。

日常管理(JIS Q 9026)について、次の説明に当てはまる用語を選べ。 (1) 要求事項を満たしていないこと。→ A (2) 工程異常を防ぐため、結果への影響が大きく直接制御できる原因系の中から選び、定常的に監視する項目。→ B (3) 目標の達成を管理するために評価尺度として選んだ項目。→ C
A解答群
  1. ア不適合
  2. イ工程異常
  3. ウ点検項目
  4. エ管理水準
  5. オ管理項目
B解答群
  1. ア工程異常
  2. イ不適合
  3. ウ管理項目
  4. エ業務分掌
  5. オ点検項目
C解答群
  1. ア管理水準
  2. イ点検項目
  3. ウ不適合
  4. エ管理項目
  5. オ業務分掌
答えと解説を見る
  • Aア 不適合
  • Bオ 点検項目
  • Cエ 管理項目
A(1) 正解は「不適合」。取り違えやすい「工程異常」はプロセスが管理状態にないことで、要求事項との比較ではない。
BC(2) 正解は「点検項目」。取り違えやすい「管理項目」は目標の達成を管理するための評価尺度として選ぶ項目(結果の側)。
C(3) 正解は「管理項目」。取り違えやすい「点検項目」は工程異常を防ぐため、結果に影響が大きく直接制御できる原因系の中から選んで監視する項目。
項目(管理項目=結果、点検項目=原因)と、その値の範囲(管理水準)。異常はプロセス、不適合は製品の要求事項との比較。 根拠:JIS Q 9026:2016 3.7/JIS Q 9026:2016 3.4/JIS Q 9026:2016 3.3。
