方針管理と日常管理の違い

実践方針管理

ひとことで言うと

重点的に取り組むのが方針管理、分掌業務を安定して回すのが日常管理。

練習問題

空欄 A・B・C に入るものを答えてください。

方針管理と日常管理について、次の説明に当てはまるものを選べ。 (1) 目標の達成状況など、仕事の結果を見る管理項目(上位の職位が主に用いる)。→ A (2) 方策や実施計画の実施状況など、結果を生む要因の側を見る管理項目(下位の職位が多く用いる)。→ B (3) 組織の各部門で日常的に行う分掌業務について、その目的を効率的に達成するために必要な全ての活動。→ C
A解答群
  1. ア期末のレビュー
  2. イ結果系管理項目
  3. ウ日常管理
  4. エすり合わせ
  5. オ要因系管理項目
B解答群
  1. ア要因系管理項目
  2. イ方針管理
  3. ウ結果系管理項目
  4. エすり合わせ
  5. オ期末のレビュー
C解答群
  1. ア期末のレビュー
  2. イ要因系管理項目
  3. ウすり合わせ
  4. エ方針管理
  5. オ日常管理
答えと解説を見る
  • Aイ 結果系管理項目
  • Bア 要因系管理項目
  • Cオ 日常管理
AB(1) 正解は「結果系管理項目」。取り違えやすい「要因系管理項目」は方策や実施計画の実施状況など、結果を生む要因の側を見る管理項目。
B(2) 正解は「要因系管理項目」。取り違えやすい「結果系管理項目」は目標の達成状況など、結果の側を見る管理項目。
C(3) 正解は「日常管理」。取り違えやすい「方針管理」は方針にもとづいて重点課題を定め、重点的に取り組む活動。
重点的な取組みが方針管理、分掌業務の維持向上が日常管理。管理項目は結果系と要因系に分けて使う。 根拠:JIS Q 9023:2018/JIS Q 9026:2016 3.1。
