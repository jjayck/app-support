回帰直線の推定と残差

手法単回帰分析計算

ひとことで言うと

傾き Sₓᵧ/Sₓₓ、直線は平均の点を通る。残差 = 実際 − 予測。

練習問題

空欄 A・B・C・D に入るものを答えてください。

温度 x(℃)と収量 y(kg)の 12 組のデータから、x̄ = 40、ȳ = 120、Sₓₓ = 160、Sₓᵧ = 240 を得た。y の x への回帰直線 ŷ = β̂₀ + β̂₁x の傾きは β̂₁ = A、切片は β̂₀ = B である。x = 44 のときの y の推定値は C kg である。また、データのうち x = 36、y = 110.8 の点の残差は −D である。
A数値(4桁・□.□□□)
B数値(5桁・□□□.□□)
C数値(5桁・□□□.□□)
D数値(3桁・□.□□)
答えとやさしい解き方を見る
  • A1.500
  • B060.00
  • C126.00
  • D3.20

数値の答えは本番と同じ「桁ごとのマーク」です。桁が余るときは先頭に 0 を入れます。

何を聞かれている?
データの要約から回帰直線(y を x で予測する直線)を作り、予測値と残差を出す問題。

記号と単位

  • β̂₁ … 傾き Sₓᵧ/Sₓₓ
  • β̂₀ … 切片
  • 残差 … 実際の値 − 直線の値

解き方

1
傾き = Sₓᵧ ÷ Sₓₓ。
最小二乗法の傾き β̂₁ = Sₓᵧ/Sₓₓ = 240/160 = 1.5 → 1.500。
2
直線は必ず平均の点を通るので、切片 = ȳ − 傾き × x̄。
直線は必ず (x̄, ȳ) を通るので β̂₀ = ȳ − β̂₁x̄ = 120 − 1.5 × 40 = 60 → 60.00。
3
x を入れて予測値を出す。
ŷ = 60 + 1.5 × 44 = 126 → 126.00。
4
残差は「実際 − 予測」の順に引く。
残差 = 実際の y − 直線の値 = 110.8 − (60 + 1.5 × 36) = 110.8 − 114 = −3.2 → 空欄は 3.20。

あわせて覚える

  • 残差を x の順や時間の順に並べて、くせ(曲がり・広がり)がないかを見るのが回帰診断。
つまずきやすいところ
傾きを Sₓᵧ/Sᵧᵧ にしてしまう(割るのは x の平方和)。
