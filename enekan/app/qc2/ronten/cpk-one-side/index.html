片側規格の工程能力と不適合品率

手法工程能力計算

ひとことで言うと

規格が片側だけなら (規格 − 平均)/3s。規格までの距離を s で割れば、正規分布表で外れる割合が読める。

練習問題

空欄 A・B・C に入るものを答えてください。

ある製品の不純物の含有率には上限規格 Sᵤ = 0.5 % だけが決められている。工程の平均は 0.365 %、標準偏差は 0.05 % で、正規分布に従っているとみなせる。上限規格は平均から標準偏差の A 倍離れており、工程能力指数は B である。上限規格を超える製品の割合は、付表の正規分布表から C % と見込まれる。

何を聞かれている?
上限だけが決まっている特性で、工程能力指数と、規格を超える製品の割合を出す問題。

記号と単位

  • K … 平均から規格までの距離が、標準偏差の何倍か
  • P … 正規分布表で K を超える確率

解き方

1
規格 − 平均 を標準偏差で割る。これが K。
規格までの距離を標準偏差の何倍かで表す:K = (Sᵤ − x̄)/s = (0.5 − 0.365)/0.05 = 2.7 → 2.70。
2
片側規格の工程能力指数は K を 3 で割るだけ。
片側規格の工程能力指数 = (Sᵤ − x̄)/(3s) = K/3 = 2.7/3 = 0.9 → 0.90。
3
正規分布表の K の行を読む。表の値が「規格を超える割合」。
正規分布表で KP = 2.70 の P を読むと 0.0035。
4
割合を % にするので 100 を掛ける。
上限を超える割合 = 0.0035 × 100 = 0.35 → 0.35 %。
つまずきやすいところ
片側なのに 6s で割る/表の値を % に直し忘れる。
