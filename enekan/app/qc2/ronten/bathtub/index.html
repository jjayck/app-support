手法信頼性工学

ひとことで言うと

初期(減少)はスクリーニング、偶発(一定)は冗長化、摩耗(増加)は予防保全。

練習問題

空欄 A・B・C に入るものを答えてください。

故障率の時間的な変化を表すバスタブ曲線について答えよ。 (1) 摩耗故障期の対策としては、A のがよい。 (2) 故障率がほぼ一定の時期を B という。 (3) 初期故障期の故障率は C。
A解答群
  1. ア故障が起きてから修理する事後保全だけで十分である
  2. イ寿命が来る前に部品を交換する予防保全(時間計画保全)を行う
  3. ウスクリーニングやデバッギング(エージング)で早めに故障を出し切る
  4. エ予測しにくいので、冗長化や余裕のある設計で備える
B解答群
  1. ア初期故障期
  2. イ偶発故障期
  3. ウ摩耗故障期
  4. エ安定期
C解答群
  1. ア時間とともに増加したあと減少する
  2. イほぼ一定である
  3. ウ時間とともに増加する
  4. エ時間とともに減少する
答えとやさしい解き方を見る
  • Aイ 寿命が来る前に部品を交換する予防保全(時間計画保全)を行う
  • Bイ 偶発故障期
  • Cエ 時間とともに減少する
何を聞かれている?
故障率の時間変化(バスタブ曲線)の 3 つの時期の特徴と対策を答える問題。

記号と単位

  • DFR・CFR・IFR … 故障率が減少・一定・増加する型

解き方

1
初めは製造の欠陥で故障が多いが、だんだん減る。
故障率の形は初期=減少・偶発=一定・摩耗=増加。対策は初期=スクリーニング・デバッギング、偶発=冗長化・余裕のある設計、摩耗=予防保全。
2
真ん中は偶然の故障で、故障率は一定。
初期故障期:故障率は時間とともに減少(DFR 型)。設計・製造の欠陥による故障を、スクリーニングやデバッギングで出荷前に取り除く。
3
最後は摩耗で増える。寿命前に交換する。
偶発故障期:故障率はほぼ一定(CFR 型)。偶然の故障なので予測しにくい。指数分布で表せる。

あわせて覚える

  • 摩耗故障期:故障率は時間とともに増加(IFR 型)。劣化・摩耗によるので、予防保全で寿命前に交換する。
つまずきやすいところ
偶発故障期の対策を予防保全にしてしまう(予防保全は摩耗故障期)。

「信頼性工学」のイメージ

製品がどれだけ長く故障せずに働けるかを、確率と時間で表す。

信頼性工学の要点と全論点を見る ›

同じ分野の論点

計算直列系・並列系の信頼度
直列は掛け算、並列は 1 − (壊れる確率の積)。
計算故障率・MTBF と指数分布
故障率 = 故障数/動作時間。一定なら MTBF = 1/λ、信頼度は e^(−λt)。
計算MTBF・MTTR とアベイラビリティ
使える時間の割合 = MTBF/(MTBF + MTTR)。壊れにくく、直しやすく。
信頼性・保全性の用語
故障しても安全=フェールセーフ、人の誤りに強い=フールプルーフ、予備の持ち方=冗長、負荷を下げる=ディレーティング。
