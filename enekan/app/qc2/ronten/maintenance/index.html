設備の保全

実践品質管理周辺の実践活動

ひとことで言うと

故障の前の予防保全(時間計画か状態基準か)と、故障の後の事後保全。

練習問題

空欄 A・B・C に入るものを答えてください。

設備の保全(JIS Z 8115 の用語)について、次の説明に当てはまるものを選べ。 (1) フォールトを検出した後に、アイテムを要求どおりの実行状態に修復させるために行う保全。→ A (2) アイテムの物理的な状態の評価にもとづいて行う予防保全。→ B (3) 与えられた運用と保全の条件のもとで、要求どおりに遂行できる状態に保たれる、又は修復される能力。→ C
A解答群
  1. ア耐久性
  2. イ時間計画保全
  3. ウ保全性
  4. エ予防保全
  5. オ事後保全
B解答群
  1. ア保全性
  2. イ時間計画保全
  3. ウ事後保全
  4. エ耐久性
  5. オ状態基準保全
C解答群
  1. ア耐久性
  2. イ保全性
  3. ウ予防保全
  4. エ事後保全
  5. オ時間計画保全
答えと解説を見る
  • Aオ 事後保全
  • Bオ 状態基準保全
  • Cイ 保全性
A(1) 正解は「事後保全」。取り違えやすい「予防保全」は故障の前に、決めた間隔や基準で行う保全。
B(2) 正解は「状態基準保全」。取り違えやすい「時間計画保全」は状態に関係なく、決めた時間間隔で行う予防保全。
C(3) 正解は「保全性」。取り違えやすい「耐久性」は有用寿命の終わりまで要求どおりに実行し続ける能力。
故障の前(予防保全:時間か状態か)、故障の後(事後保全)。保全のしやすさが保全性。 根拠:JIS Z 8115:2019。
