二項分布の確率

手法確率分布計算

ひとことで言うと

n 個中 x 個が不良の確率。0 個は (1 − p)ⁿ、平均 np、分散 np(1 − p)。

練習問題

空欄 A・B・C・D に入るものを答えてください。

不適合品率 20 % の工程から、ランダムに 8 個を抜き取る。抜き取った中の不適合品の数を X とすると、X は二項分布に従う。P(X = 0) = A、P(X = 1) = B、P(X ≥ 2) = C である。また、X の分散は D である。
A数値(4桁・□.□□□)
B数値(4桁・□.□□□)
C数値(4桁・□.□□□)
D数値(3桁・□.□□)
答えとやさしい解き方を見る
  • A0.168
  • B0.336
  • C0.497
  • D1.28

数値の答えは本番と同じ「桁ごとのマーク」です。桁が余るときは先頭に 0 を入れます。

何を聞かれている?
不良率 p の工程から n 個とったとき、不良が 0 個・1 個・2 個以上になる確率を出す問題。

記号と単位

  • n … 抜き取る個数
  • p … 1 個が不良である確率
  • ₙCₓ … n 個から x 個を選ぶ組合せの数

解き方

1
式の形を確認する。x 個が不良、残り n − x 個が良品になる確率を、並び方の数だけ足し合わせる。
二項分布:P(X = x) = ₙCₓ pˣ (1 − p)ⁿ⁻ˣ、n = 8、p = 0.2。
2
0 個:全部が良品。(1 − p) を n 回掛ける。
P(X = 0) = 0.88 = 0.16777 → 0.168。
3
1 個:どれが不良かで n 通り。n × p × (1 − p)ⁿ⁻¹。
P(X = 1) = 8 × 0.2 × 0.87 = 0.33554 → 0.336。
4
2 個以上:全部(1)から 0 個と 1 個を引く。直接足すより早い。
P(X ≥ 2) = 1 − P(0) − P(1) = 1 − 0.16777 − 0.33554 = 0.49668 → 0.497。
5
平均は np、分散は np(1 − p)。
二項分布の平均は np = 1.6、分散は np(1 − p) = 8 × 0.2 × 0.8 = 1.28 → 1.28。
つまずきやすいところ
1 個の確率で n を掛け忘れる/2 個以上を P(2) だけにしてしまう。

同じ分野の論点

計算正規分布の確率
(x − μ)/σ で標準化すれば、正規分布表 1 枚でどんな正規分布の確率も読める。
計算確率から値を求める(正規分布)
上から 5 % の点は K = 1.645。値に戻すときは μ + Kσ。
計算ポアソン分布の確率
まれに起きることの回数。0 回の確率は e^(−λ)、平均も分散も λ。
計算期待値と分散の加法性
和でも差でも、独立なら分散は足し算。標準偏差は足さない。
計算平均値の分布と中心極限定理
n 個の平均のばらつきは σ/√n。平均はもとの分布によらずほぼ正規分布になる。
