QC七つ道具の使い分け

手法データのまとめ方

ひとことで言うと

件数の順ならパレート図、要因の整理なら特性要因図、ばらつきの形ならヒストグラム、2 つの関係なら散布図、分けて比べるなら層別。

練習問題

空欄 A・B・C に入るものを答えてください。

次の目的に最も適した QC 七つ道具を選べ。 (1) 母集団をいくつかの層(機械別・原材料別など)に分割して、層の間の違いからばらつきの原因を探る。→ A (2) 対になった 2 つの特性を、縦軸と横軸にとって点を打ち、関係を見る。→ B (3) 特性(結果)と、それに影響すると考えられる要因の関係を、魚の骨のような形で整理する。→ C
A解答群
  1. ア層別
  2. イヒストグラム
  3. ウチェックシート
  4. エ散布図
  5. オパレート図
B解答群
  1. ア層別
  2. イヒストグラム
  3. ウ特性要因図
  4. エ散布図
  5. オチェックシート
C解答群
  1. ア層別
  2. イヒストグラム
  3. ウ特性要因図
  4. エパレート図
  5. オ散布図
答えと解説を見る
  • Aア 層別
  • Bエ 散布図
  • Cウ 特性要因図
A(1) 正解は「層別」。取り違えやすい「チェックシート」はデータを取るための用紙。
BC(2) 正解は「散布図」。取り違えやすい「特性要因図」は結果と要因の関係を言葉で整理する図で、2 つの数値の関係を点で見るものではない。
C(3) 正解は「特性要因図」。取り違えやすい「パレート図」は項目別の件数を多い順に並べて、重点を見つける図。
件数の順=パレート図、要因の整理=特性要因図、記録用紙=チェックシート、ばらつきの形=ヒストグラム、2 変数=散布図、分ける=層別。 根拠:QC検定4級の手引き 2.3。

同じ分野の論点

計算基本統計量の計算
平均で真ん中、平方和→分散→標準偏差でばらつき。分散の分母は n − 1。
計算データの変換(数値変換)
u = (x − 基準)× 倍率。平均は「ずらし+目盛り」を戻し、平方和は目盛りの 2 乗だけ戻す。
計算パレート図の累積比率
件数の多い順に並べ、「その他」は最後。上位の数項目で全体の大部分を占めることを見る。
サンプリングの種類と性質
層ごとに抜く=層別、選んだまとまりを全部=集落、選んだまとまりからさらに抜く=2 段、一定間隔=系統。
データの種類
測ったデータが計量値、数えたデータが計数値、文章のデータが言語データ。全体が母集団、取り出した一部がサンプル。
