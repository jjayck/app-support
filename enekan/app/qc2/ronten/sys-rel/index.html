直列系・並列系の信頼度

手法信頼性工学計算

ひとことで言うと

直列は掛け算、並列は 1 − (壊れる確率の積)。

練習問題

空欄 A・B・C に入るものを答えてください。

部品 A(信頼度 0.92)と B(0.8)を直列につないだ系に、部品 C(0.92)を並列に追加したシステムがある。各部品は互いに独立に故障する。A・B の直列部分の信頼度は A、システム全体の信頼度は B である。一部が故障しても全体の機能が保たれるように、同じ働きの部品を並べておく構成を C という。
A数値(5桁・□.□□□□)
B数値(5桁・□.□□□□)
C解答群
  1. ア直列系
  2. イ冗長系(並列冗長)
  3. ウ直交系
  4. エ分岐系
答えとやさしい解き方を見る
  • A0.7360
  • B0.9789
  • Cイ 冗長系(並列冗長)

数値の答えは本番と同じ「桁ごとのマーク」です。桁が余るときは先頭に 0 を入れます。

何を聞かれている?
部品を直列・並列に組み合わせたシステムの信頼度(故障しない確率)を出す問題。

記号と単位

  • R … 信頼度(故障しない確率)
  • 1 − R … 故障する確率

解き方

1
直列は全部が動く必要があるので掛け算。
冗長系:同じ働きの部品を並列に置き、一部が故障しても機能を保つ構成(並列冗長)。
2
並列は全部が壊れたときだけ止まるので、1 −(壊れる確率の積)。
直列:全部が動いて初めて動く → 信頼度を掛ける。
3
まず内側のかたまりを 1 つの部品にまとめる。
並列:全部が壊れたときだけ止まる → 1 − (壊れる確率の積)。
4
まとめた部品と残りをつなぐ。
A と B の直列部分:RAB = RA·RB = 0.92 × 0.8 = 0.736 → 0.7360。

あわせて覚える

  • それと C の並列:R = 1 − (1 − RAB)(1 − RC) = 1 − 0.264 × 0.08 = 0.9789 → 0.9789。
つまずきやすいところ
並列の信頼度を足してしまう(1 を超えることもあり得ない)。

「信頼性工学」のイメージ

製品がどれだけ長く故障せずに働けるかを、確率と時間で表す。

信頼性工学の要点と全論点を見る ›

同じ分野の論点

計算故障率・MTBF と指数分布
故障率 = 故障数/動作時間。一定なら MTBF = 1/λ、信頼度は e^(−λt)。
計算MTBF・MTTR とアベイラビリティ
使える時間の割合 = MTBF/(MTBF + MTTR)。壊れにくく、直しやすく。
バスタブ曲線と故障のタイプ
初期(減少)はスクリーニング、偶発(一定)は冗長化、摩耗(増加)は予防保全。
信頼性・保全性の用語
故障しても安全=フェールセーフ、人の誤りに強い=フールプルーフ、予備の持ち方=冗長、負荷を下げる=ディレーティング。
