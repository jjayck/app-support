OC 曲線とロットの合格確率

手法抜取検査計算

ひとことで言うと

不良率ごとのロットの合格の確率。よいロットを落とす α と、悪いロットを通す β で評価する。

練習問題

空欄 A・B・C・D に入るものを答えてください。

ロットから n = 80 個をランダムに抜き取り、不適合品が 1 個以下ならロットを合格とする抜取検査(n = 80、c = 1)を考える。ポアソン分布で近似すると、不適合品率 1 % のロットが合格する確率は A で、このロットが不合格になる確率(生産者危険)は B である。また、不適合品率 4 % のロットが合格してしまう確率(消費者危険)は C である。c を一定にして n を大きくすると、OC 曲線は D。ただし e−0.8 = 0.4493、e−3.2 = 0.0408 とする。

B数値(5桁・□.□□□□)
C数値(5桁・□.□□□□)
D解答群
  1. ア傾きが急になり、良いロットと悪いロットを見分けやすくなる
  2. イ形は変わらない
  3. ウ合格する確率がどの p でも 1 に近づく

  • A0.8087
  • B0.1913

数値の答えは本番と同じ「桁ごとのマーク」です。桁が余るときは先頭に 0 を入れます。

何を聞かれている?
抜取検査の方式(n, c)で、ある不良率のロットが合格する確率を出す問題。

記号と単位

  • n … 抜き取る数
  • c … 合格にできる不良の最大数
  • m … 抜き取った中の平均の不良数 np
  • α・β … 生産者危険・消費者危険

解き方

1
合格の確率は、不良が 0〜c 個になる確率の合計。
c を一定にして n を大きくすると、OC 曲線の傾きが急になり、良いロットと悪いロットを見分ける力(識別力)が上がる。
2
良いロット(p₀)で m = np を出して、0〜c 個の確率を足す。
合格する確率 L(p) = P(不適合品数 ≤ c)。ポアソン近似では m = np として L = e−m+m·e−m。
3
良いロットなのに不合格になる確率が α。
p = 0.01:m = 80 × 0.01 = 0.8。L = 0.4493 + 0.8 × 0.4493 = 0.80874 → 0.8087。
4
悪いロット(p₁)で同じように計算した合格の確率が β。
生産者危険 α = 1 − L = 1 − 0.80874 = 0.19126 → 0.1913(良いロットが不合格にされる確率)。

あわせて覚える

  • p = 0.04:m = 80 × 0.04 = 3.2。L = 0.0408 + 3.2 × 0.0408 = 0.17136 → 0.1714(消費者危険 β)。
つまずきやすいところ
c 個までを足すのに、c 個ちょうどの確率だけにしてしまう。

測った値の平均で判定する。正規分布表の値から n と k を決め、平均 ≤ Sᵤ − kσ なら合格。
