ひとことで言うと

A と B のぶんを引いた残りが誤差。交互作用は誤差と分けられない。

練習問題

何を聞かれている?
2 つの条件を組み合わせて 1 回ずつ実験したデータから、それぞれの効果を分散分析で判定する問題。

記号と単位

  • SA・SB … 各因子の平方和
  • Se … 残り(誤差)

解き方

1
CT と総平方和は一元配置と同じ。
CT = T²/N = 298²/12 = 7400.3333、ST = Σx² − CT = 7470 − 7400.3333 = 69.6667。
2
A の行の合計を 2 乗して足し、B の水準数で割ってから CT を引く。
SA = Σ(A の各水準の合計²)/b − CT = (77² + 72² + 65² + 84²)/3 − 7400.3333 = 64.3333 → 64.33。
3
B の列の合計を 2 乗して足し、A の水準数で割ってから CT を引く。
SB = Σ(B の各水準の合計²)/a − CT = (98² + 98² + 102²)/4 − 7400.3333 = 2.6667 → 2.67。
4
残りが誤差。自由度は (a − 1)(b − 1)。
繰返しがないので、交互作用と誤差は分けられない。Se = ST − SA − SB = 2.6667 → 2.67、φ_e = (a − 1)(b − 1) = 6 → 6。
5
A の分散 ÷ 誤差の分散を F 表と比べる。
VA = 64.3333/3 = 21.4444、Ve = 2.6667/6 = 0.4444、F₀(A) = 48.25 → 48.3。F(3, 6; 0.05) = 4.76 → 有意。

あわせて覚える

  • (参考)B は F₀ = 3、F(2, 6; 0.05) = 5.14 → 有意でない。
つまずきやすいところ
A の平方和で A の水準数で割ってしまう(割るのは 1 つの合計に入っているデータ数 = B の水準数)。

計算一元配置の分散分析
全体のばらつきを、因子のぶんと誤差のぶんに分け、F₀ = V_A/V_e を F 表と比べる。
計算一元配置の母平均の推定
水準の平均 ± t(φ_e, 0.05)√(V_e/r)。差の推定では √(2V_e/r)。
計算繰返しのある二元配置と交互作用
組合せごとの平均のばらつき S_AB から A と B のぶんを引くと交互作用。
計算交互作用のプーリング
効果の小さい交互作用は、平方和と自由度を誤差に足し込んで、誤差分散を求め直す。
