MTBF・MTTR とアベイラビリティ

手法信頼性工学計算

ひとことで言うと

使える時間の割合 = MTBF/(MTBF + MTTR)。壊れにくく、直しやすく。

練習問題

空欄 A・B・C・D に入るものを答えてください。

ある設備の 1 年間の記録で、動いていた時間の合計は 600 時間、故障は 4 回、修理に要した時間の合計は 24 時間であった。MTBF は A 時間、MTTR は B 時間、アベイラビリティ(稼働率)は C % である。アベイラビリティを上げるには D とよい。
A数値(3桁・□□□)h
B数値(2桁・□.□)h
C数値(3桁・□□.□)%
D解答群
  1. アMTBF を長くするか、MTTR を短くする
  2. イMTBF を短くするか、MTTR を長くする
  3. ウMTTR だけを長くする
  4. エ故障の回数を増やす
答えとやさしい解き方を見る
  • A150 h
  • B6.0 h
  • C96.2 %
  • Dア MTBF を長くするか、MTTR を短くする

数値の答えは本番と同じ「桁ごとのマーク」です。桁が余るときは先頭に 0 を入れます。

何を聞かれている?
動いた時間・故障回数・修理時間から、設備が使える状態にある割合(アベイラビリティ)を出す問題。

記号と単位

  • MTBF … 平均故障間動作時間
  • MTTR … 平均修復時間

解き方

1
動いた時間 ÷ 故障回数。
MTBF(平均故障間動作時間)= 動作時間の合計/故障回数 = 600/4 = 150 → 150 時間。
2
修理時間 ÷ 故障回数。
MTTR(平均修復時間)= 修理時間の合計/故障回数 = 24/4 = 6 → 6.0 時間。
3
MTBF ÷ (MTBF + MTTR)。
アベイラビリティ A = MTBF/(MTBF + MTTR) = 150/(150 + 6) = 0.9615 → 96.2 %。

あわせて覚える

  • 故障しにくくする(信頼性)と、直しやすくする(保全性)の両方で上がる。
つまずきやすいところ
分母を MTBF だけにする/MTTR を引いてしまう。

「信頼性工学」のイメージ

製品がどれだけ長く故障せずに働けるかを、確率と時間で表す。

信頼性工学の要点と全論点を見る ›

同じ分野の論点

計算直列系・並列系の信頼度
直列は掛け算、並列は 1 − (壊れる確率の積)。
計算故障率・MTBF と指数分布
故障率 = 故障数/動作時間。一定なら MTBF = 1/λ、信頼度は e^(−λt)。
バスタブ曲線と故障のタイプ
初期(減少)はスクリーニング、偶発(一定)は冗長化、摩耗(増加)は予防保全。
信頼性・保全性の用語
故障しても安全=フェールセーフ、人の誤りに強い=フールプルーフ、予備の持ち方=冗長、負荷を下げる=ディレーティング。
