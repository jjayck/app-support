何を聞かれている?
不良の項目を件数の多い順に並べ、上位いくつかで全体の何 % を占めるか(累積比率)を出す問題。

記号と単位

  • 累積比率 … 上から順に足していった件数が、合計の何 % か

解き方

1
表の件数を「その他」も含めて全部足す。これが 100 % になる。
合計 = 67 + 64 + 27 + 24 + 11(その他)= 193 → 193 件。
2
件数の多い順に並べ替える(「その他」は件数に関係なく最後)。
多い順:色むら 67、汚れ 64、打痕 27、バリ 24。上位 3 項目の合計 = 158 件。
3
上位の件数を足して合計で割り、100 を掛ける。
累積比率 = 158/193 × 100 = 81.865 → 81.9 %。

あわせて覚える

  • 「その他」は件数にかかわらず最後に置く。累積比率の折れ線で、上位の数項目で全体の大部分を占めることを見る(重点指向)。
つまずきやすいところ
「その他」を件数の順に混ぜてしまう/合計に「その他」を入れ忘れる。

同じ分野の論点

計算基本統計量の計算
平均で真ん中、平方和→分散→標準偏差でばらつき。分散の分母は n − 1。
計算データの変換(数値変換)
u = (x − 基準)× 倍率。平均は「ずらし+目盛り」を戻し、平方和は目盛りの 2 乗だけ戻す。
サンプリングの種類と性質
層ごとに抜く=層別、選んだまとまりを全部=集落、選んだまとまりからさらに抜く=2 段、一定間隔=系統。
データの種類
測ったデータが計量値、数えたデータが計数値、文章のデータが言語データ。全体が母集団、取り出した一部がサンプル。
QC七つ道具の使い分け
件数の順ならパレート図、要因の整理なら特性要因図、ばらつきの形ならヒストグラム、2 つの関係なら散布図、分けて比べるなら層別。
