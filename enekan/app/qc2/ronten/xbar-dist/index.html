平均値の分布と中心極限定理

手法確率分布計算

ひとことで言うと

n 個の平均のばらつきは σ/√n。平均はもとの分布によらずほぼ正規分布になる。

何を聞かれている?
何個かの平均値は、1 個の値よりばらつきが小さいことを使って確率を出す問題。

記号と単位

  • σ/√n … 平均 x̄ の標準偏差(標準誤差)

解き方

1
平均値の標準偏差は σ を √n で割る。9 個なら 3 で割る。
中心極限定理:母集団が正規分布でなくても、n が大きければ平均 x̄ の分布は正規分布に近づく。
2
平均値の確率は、この小さい標準偏差で標準化して表を読む。
x̄ の標準偏差 = σ/√n = 6/√4 = 6/2 = 3 → 3.00 g。
3
1 個のときは元の σ で標準化する。
x̄ > 1006:u = (1006 − 1000)/3 = 2.00。表から P = 0.0228 → 0.0228。

あわせて覚える

  • 1 個のとき:u = (1006 − 1000)/6 = 1.00。表から P = 0.1587 → 0.1587。
  • 平均をとるとばらつきが 1/√n になるので、同じ値を超える確率は小さくなる。
つまずきやすいところ
x̄ の確率なのに σ のまま標準化する/√n ではなく n で割る。

「確率分布」のイメージ

データのばらつき方には決まった形があり、その形を使うと「どのくらいの確率で起きるか」が計算できる。

同じ分野の論点

計算正規分布の確率
(x − μ)/σ で標準化すれば、正規分布表 1 枚でどんな正規分布の確率も読める。
計算確率から値を求める(正規分布)
上から 5 % の点は K = 1.645。値に戻すときは μ + Kσ。
計算二項分布の確率
n 個中 x 個が不良の確率。0 個は (1 − p)ⁿ、平均 np、分散 np(1 − p)。
計算ポアソン分布の確率
まれに起きることの回数。0 回の確率は e^(−λ)、平均も分散も λ。
計算期待値と分散の加法性
和でも差でも、独立なら分散は足し算。標準偏差は足さない。
