ひとことで言うと

良いロットを落とす確率(α)と悪いロットを通す確率(β)の両方を、決めた値以下にする n と c を選ぶ。

何を聞かれている?
抜取検査の方式(n, c)ごとの合格の確率から、生産者危険と消費者危険を出し、条件に合う方式を選ぶ問題。

記号と単位

  • L(p) … 不適合品率 p のロットが合格する確率
  • α(生産者危険)… 良いロット(p₀)が不合格になる確率 = 1 − L(p₀)
  • β(消費者危険)… 悪いロット(p₁)が合格する確率 = L(p₁)

解き方

1
良いロットの合格の確率を 1 から引くと、良いロットが落とされる確率 α。
生産者危険 α = 不適合品率 p₀ の良いロットが不合格になる確率 = 1 − L(p₀)。方式ア:1 − 0.9670 = 0.033 → 0.0330。
2
悪いロットの合格の確率は、そのまま β(通してしまう確率)。
消費者危険 β = 不適合品率 p₁ の悪いロットが合格してしまう確率 = L(p₁)。方式エ:0.0356 → 0.0356。
3
全部の方式で α と β を並べる。
各方式の α と β:方式ア α = 0.033・β = 0.0113、方式イ α = 0.1821・β = 0.1887、方式ウ α = 0.0647・β = 0.0017、方式エ α = 0.331・β = 0.0356。
4
α ≤ 0.05 と β ≤ 0.10 を両方満たす方式を選ぶ。
α ≤ 0.05 と β ≤ 0.10 を両方満たすのは 方式ア。n を大きくすると両方の危険を同時に小さくできる(OC 曲線が急になる)。
つまずきやすいところ
α を L(p₀) そのものにしてしまう(α は不合格になる確率なので 1 から引く)。
