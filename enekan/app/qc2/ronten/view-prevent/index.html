応急処置・再発防止・未然防止

実践QC的ものの見方・考え方

ひとことで言うと

応急処置は損失を止めるだけ。原因を除けば再発防止、起きる前に予測して防げば未然防止。

練習問題

空欄 A・B・C に入るものを答えてください。

不具合への手の打ち方について、次の説明に当てはまるものを選べ。 (1) プロセスを実施する前に起こりうるトラブルを予測し、容認できないものにあらかじめ対策をとる。→ A (2) ある不具合の原因を除いた対策を、類似の原因をもつほかのプロセスや製品にも広げる。→ B (3) 起きた不具合の原因を取り除き、同じ原因で二度と起きないように対策する。→ C
A解答群
  1. ア見える化
  2. イ再発防止
  3. ウ応急処置
  4. エ未然防止
  5. オ水平展開
B解答群
  1. ア見える化
  2. イ未然防止
  3. ウ応急処置
  4. エ再発防止
  5. オ水平展開
C解答群
  1. ア未然防止
  2. イ水平展開
  3. ウ応急処置
  4. エ見える化
  5. オ再発防止
答えと解説を見る
  • Aエ 未然防止
  • Bオ 水平展開
  • Cオ 再発防止
AC(1) 正解は「未然防止」。取り違えやすい「再発防止」はすでに起きた不具合の原因を取り除く活動で、起きる前に予測して手を打つものではない。
B(2) 正解は「水平展開」。取り違えやすい「再発防止」はその不具合が起きた所で同じ原因の再発を防ぐ対策で、ほかの所へ広げることまでは含まない。
C(3) 正解は「再発防止」。取り違えやすい「応急処置」は原因には手を付けず、損失の拡大を止めるためにとる処置。
起きた後に損失を止める/原因を除く/起きる前に防ぐ/ほかへ広げる、の区別。 根拠:JIS Q 9027:2018 4.3/JIS Q 9027:2018/JIS Q 9026:2016 3.9。
