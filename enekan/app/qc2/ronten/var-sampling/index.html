計量規準型一回抜取検査(σ 既知)

手法抜取検査計算

ひとことで言うと

測った値の平均で判定する。正規分布表の値から n と k を決め、平均 ≤ Sᵤ − kσ なら合格。

練習問題

空欄 A・B・C・D に入るものを答えてください。

上限規格 Sᵤ = 80 の特性について、標準偏差 σ = 0.8 が既知の計量規準型一回抜取検査(ロットの平均値ではなく不適合品率を保証する方式)を設計する。なるべく合格させたいロットの不適合品率 p₀ = 2 %(α = 0.05)、なるべく不合格にしたい不適合品率 p₁ = 10 %(β = 0.10)とする。n = ((K_α + K_β)/(Kp₀ − Kp₁))²(小数は切り上げ)、k = (Kp₀·K_β + Kp₁·K_α)/(K_α + K_β) で求めると、n = A、k = B(小数 2 桁に丸める)である。上限合格判定値 X̄ᵤ = Sᵤ − kσ は C であり、抜き取った n 個の平均が 78.38 だったので、D。付表の正規分布表を用いよ。

何を聞かれている?
標準偏差が分かっている特性で、抜き取る数 n と合格判定の係数 k を決め、ロットの合否を判定する問題。

記号と単位

  • K_α・K_β … α = 0.05、β = 0.10 の正規分布表の値
  • Kp₀・Kp₁ … p₀・p₁ の正規分布表の値
  • X̄ᵤ … 上限合格判定値

解き方

1
必要な 4 つの K を正規分布表で読む。
表から K_α = K₀.₀₅ = 1.645、K_β = K₀.₁₀ = 1.282、Kp₀ = K0.02 = 2.054、Kp₁ = K0.1 = 1.282。
2
式に入れて n を出し、小数は切り上げる(少ないと狙いの精度が出ない)。
n = ((1.645 + 1.282)/(2.054 − 1.282))² = (2.927/0.772)² = 14.3751 → 切り上げて 15 → 15。
3
k も式に入れて小数 2 桁に丸める。
k = (2.054 × 1.282 + 1.282 × 1.645)/2.927 = 1.6201 → 1.62。
4
上限規格から k × σ を引くと、合格判定値。
X̄ᵤ = Sᵤ − kσ = 80 − 1.62 × 0.8 = 78.704 → 78.70。
5
抜き取った平均が判定値以下なら合格。
平均 78.38 は X̄ᵤ 78.704 以下 → 合格。上限規格では「x̄ ≤ X̄ᵤ なら合格」。
つまずきやすいところ
n を四捨五入してしまう(切り上げ)/判定値を上限 + kσ にしてしまう。
