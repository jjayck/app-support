期待値と分散の加法性

手法確率分布計算

ひとことで言うと

和でも差でも、独立なら分散は足し算。標準偏差は足さない。

練習問題

空欄 A・B・C・D に入るものを答えてください。

穴の内径 X は平均 30.0312 mm・標準偏差 5 μm、軸の外径 Y は平均 30.0000 mm・標準偏差 12 μm の、互いに独立な正規分布に従う。ランダムに組み合わせたときのすきま Z = X − Y の平均は A μm、標準偏差は B μm であり、すきまが負(はまらない)になる割合は C % である。Z の分散は D で求める。付表の正規分布表を用いよ。

何を聞かれている?
2 つの部品を組み合わせたときのすきま(差)の平均とばらつきを出し、はまらない確率を求める問題。

記号と単位

  • E( ) … 平均(期待値)
  • V( ) … 分散(標準偏差の 2 乗)

解き方

1
平均は、差なら差、和なら和。単位(mm と μm)をそろえる。
平均は差をとる:E(Z) = E(X) − E(Y) = 30.0312 − 30.0000 = 0.0312 mm = 31.2 μm → 31.2。
2
分散は、差でも和でも足す(独立なとき)。ここが最大のポイント。
分散は差でも足す(独立なとき):V(Z) = σ_X² + σ_Y² = 5² + 12² = 169。
3
足した分散の √ が標準偏差。
標準偏差 σ_Z = √169 = 13 → 13 μm。
4
すきま 0 を標準化して表を読む。マイナス側は対称性で読む。
Z < 0 を標準化:K = (0 − 31.2)/13 = −2.40。対称なので表の KP = 2.40 を読み P = 0.0082 → 0.82 %。
つまずきやすいところ
差だから分散も引いてしまう/標準偏差をそのまま足してしまう(足すのは 2 乗した分散)。

同じ分野の論点

計算正規分布の確率
(x − μ)/σ で標準化すれば、正規分布表 1 枚でどんな正規分布の確率も読める。
計算確率から値を求める(正規分布)
上から 5 % の点は K = 1.645。値に戻すときは μ + Kσ。
計算二項分布の確率
n 個中 x 個が不良の確率。0 個は (1 − p)ⁿ、平均 np、分散 np(1 − p)。
計算ポアソン分布の確率
まれに起きることの回数。0 回の確率は e^(−λ)、平均も分散も λ。
計算平均値の分布と中心極限定理
n 個の平均のばらつきは σ/√n。平均はもとの分布によらずほぼ正規分布になる。
