先に答え

Webエントリーや履歴書の写真データの条件は、応募先(企業・エントリーサイト)ごとに違います。このページでは特定の数値は載せません。応募先の案内にある形式・容量・ピクセル数・縦横比を確かめて、そのとおりに合わせてください。

案内に書かれやすい項目

  • 形式: JPEG、PNG など。iPhoneの写真は HEIC のことがあるので注意(HEICをJPEGにする)。
  • 容量: 「○KB以下」「○MB以内」。下限があることもあります。
  • ピクセル数: 「縦○×横○ピクセル」。「以内」なら枠に収める、ちょうどの指定ならその大きさにします(ピクセル数を指定サイズにする)。
  • 縦横比: 「縦4:横3」など(縦横比を合わせる)。

縦と横を取り違えない

「450×350」のように書かれているとき、どちらが縦かは案内によって違います。「縦450×横350」なら縦長です。迷ったら、案内の見本画像の向きを見てください。

アプリでやる場合

応募先の条件の文章を貼りつけると、形式・容量・ピクセル数・縦横比を読み取って入力します。

  1. 応募先の写真の条件の文章をコピーする。
  2. 要項を貼りつけ → 貼りつけ → 条件を読み取る。
  3. 「いまの条件」が案内と合っているか見比べる。違っていたら 手動で直す で直す。
  4. 写真を選んで変換 → 写真に保存 か 共有・ファイル保存。

読み取りは文章の書き方によって外れることがあります。変換の前に、かならず条件を見比べてください。

写真は端末の中だけで処理され、位置情報などのメタデータは変換後の写真に引き継がれません。明るさや肌などの見た目は変えず、形式・容量・ピクセル数・縦横比だけを合わせます。

あわせて読む

iPhoneで写真を200KB以下(○KB以下)にする方法標準の「プレビュー」でも縮められるが、KBの指定はできない。指定どおりにするならアプリで。写真のピクセル数を「縦○×横○」の指定サイズにする方法(iPhone)「以内」なら枠に収める、ちょうどなら縦横比を合わせて切り取ってから縮める。写真の縦横比(縦4:横3など)を合わせる方法(iPhone)写真アプリの切り取りで比率を選ぶ。顔の位置を見ながら切れるのは標準機能の強み。
