iPhoneで写真を200KB以下(○KB以下)にする方法

2026-11-18 更新

先に答え

iPhoneの標準の「プレビュー」アプリでも、書き出すときに容量を小さくできます。ただしスライダで調整するので、200KB以下になったかは保存してから確かめる必要があります。KBの数字を指定して1回で収めたいなら、指定した容量に合わせて縮めるアプリを使うのが早いです。

標準の「プレビュー」アプリで縮める

  1. プレビューアプリで画像を開く。
  2. ファイル名の横のボタン → 「書き出す」。
  3. フォーマットで JPEG(または HEIC)を選び、「サイズ」のスライダを左へ動かすとファイルサイズが小さくなる。
  4. 保存先を選んで「保存」。

保存したファイルの容量を見て、200KBを超えていたらスライダをさらに左にしてやり直します。プレビューアプリの「サイズを調整」で画像の大きさを小さくする方法もあります。

容量を見る方法

写真アプリでは、写真を開いて上にスワイプ(または情報ボタン)するとファイルサイズが表示されます。詳しくは 写真の容量を確かめる方法。

200KBを下回らせるときのこつ

  • 画質を下げるだけで収まらないときは、ピクセル数も小さくする必要があります。
  • 提出先が「1KB = 1000バイト」で数えている場合もあるので、上限ちょうどより少し下を狙うと安心です。

アプリでやる場合

「ぴったり写真」は、指定したKBに収まる範囲で画質をできるだけ保って圧縮し、それでも収まらなければピクセル数も縮めます。

  1. 提出先から選ぶ の保存形式を選ぶ(提出先がJPEG指定なら JPEG)。
  2. 「容量だけ指定」から 200KB以下 を選ぶ(100KB・500KB・1MB・2MB・5MBもあります)。ほかの数字は 手動で直す の容量の上限に入れます。
  3. 写真を選んで変換。複数枚まとめて選べます。
  4. 結果の画面で、変換前と変換後の容量を確かめて 写真に保存。

アプリは 1KB = 1024バイトで数えます。気になるときは上限を少し下げて(例: 190KB)変換してください。

写真は端末の中だけで処理され、位置情報などのメタデータは変換後の写真に引き継がれません。明るさや肌などの見た目は変えず、形式・容量・ピクセル数・縦横比だけを合わせます。
