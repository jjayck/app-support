iPhoneで写真の容量(KB・MB)を確かめる方法

2026-11-18 更新

先に答え

写真アプリで写真を開き、上にスワイプするか情報ボタンをタップすると、撮影したデバイスやレンズなどといっしょにファイルサイズが表示されます。

KBとMBの換算

1MB はおよそ 1000KB です。ただし、1KB を 1000バイトで数えるか 1024バイトで数えるかで少し差が出ます。「600KB以内」のように上限ぎりぎりの指定では、少し余裕を持たせると安心です。

表示される容量と、送られる容量

メールなどで送るときに、相手の環境に合わせて JPEG に変換されて送られることがあります。その場合は容量も変わります。提出するファイルそのものの容量を確かめてください。

アプリでやる場合

「ぴったり写真」で変換すると、結果の画面に変換前と変換後の容量・ピクセル数・形式が並んで出ます。

  1. 条件を選ぶ(容量だけ縮めるなら「容量だけ指定」から)。
  2. 写真を選んで変換。
  3. 結果の画面で「変換前 → 変換後」の容量と、ピクセル数・形式を確かめる。条件どおりなら「条件にぴったり」と出ます。

写真は端末の中だけで処理され、位置情報などのメタデータは変換後の写真に引き継がれません。明るさや肌などの見た目は変えず、形式・容量・ピクセル数・縦横比だけを合わせます。

App Store で「ぴったり写真」を見る(無料)

あわせて読む

iPhoneで写真を200KB以下(○KB以下)にする方法標準の「プレビュー」でも縮められるが、KBの指定はできない。指定どおりにするならアプリで。iPhoneのHEIC写真をJPEG(jpg)にする方法これから撮る写真は「互換性優先」でJPEGに。撮った写真は書き出しで変換。マイナンバーカードのオンライン申請で使う顔写真のサイズと容量jpeg・20KB〜7MB・幅と高さ480〜6000ピクセル。iPhoneのHEICは変換が必要。
